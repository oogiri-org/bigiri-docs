対象バージョン: **1.138.3**（2026年9月19日公開）

bǃgǃrǃ（ビギリ）は、ブラウザーだけで大喜利を開けるサイトです。このマニュアルは、2017年6月のα版公開から最新版までの更新情報と、いま画面に出ている操作を突き合わせて、**いま使えるやり方**だけを利用者向けに整理したものです。パッケージの更新や内部処理の変更など、画面の使い方に影響しない告知は省いています。

公式サイトは <https://bigiri.oogiri.org/> です。

## 1. bǃgǃrǃとは

### 1.1 サービスの位置づけ

キャッチフレーズは「**For Beautiful Oogiri Life**」です。誰でも部屋を開き、ルールを部屋ごとに組み立ててネット大喜利を催せます。ロゴの「ǃ」は歯茎吸着音（クリック音）を表す記号で、Wikipedia の解説へリンクしています。読みは「ビギリ」です。

1回の大喜利は、次の4段階を繰り返します。

1. **出題** — お題を投稿する
2. **回答** — お題に答える
3. **投票** — 面白いと思った回答に票を入れる
4. **結果** — 得票と順位が公開され、コメントやリアクションで振り返る

同じサイトのまま、少人数のゆるい部屋から、制限時間・匿名・一斉公開・グループ対抗まで切り替えられます。ルールは部屋を作るときに決め、作ったあとでは変えられません。運用で変えるのは、入室者ごとの役割とグループだけです。

### 1.2 使う前に知っておくこと

- トップ画面の部屋一覧は、サインインしなくても閲覧できます。部屋を作る、入る、出題する、回答する、投票する、コメントするにはサインインが必要です。
- 部屋には存続期間があります。**最終更新日時から 11.5 日**で終了します。
- **過去の結果**と**ログ（CSV）**に残るのは、**34.5 日以内の出題**です。記録が要るときは、そのあいだに保存してください。
- 部屋の中の作品で、独自の注記がないものは **クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）** の下で提供されます。この掲示はトップ画面の部屋一覧の上にもあります。
- 出題に著作物を使うときは、現行の著作権の範囲で許される形にしてください。出典欄があります。サイトの判断で、違反者のアクセスを止める場合があります。
- 画面には広告が出ることがあります。
- スマートフォンなど、幅の狭い画面でも操作できます。

### 1.3 問い合わせ先

トップ画面の見出しの下に、次の連絡先があります。

| 種類 | 宛先 |
|---|---|
| メール | bigiri@oogiri.org |
| Bluesky | @bigiri.oogiri.org |
| Twitter | @bigirichan |

使い方の質問や提案は、GitHub のディスカッションで受け付けています。トップ画面の「使用方法」から開けます。同じ欄から、AI が試験的に生成したユーザーマニュアル集へのリンクもあります。

新着の部屋は Atom フィードでも追えます。トップ画面の部屋一覧の上に、フィードのアドレスが表示されています。フィードには部屋作成者名も入ります。

Discord の公式サーバーと、部屋作成を Discord へ通知する機能は廃止されています。

### 1.4 用語

| 用語 | 意味 |
|---|---|
| **部屋** | 大喜利の単位。設定、入室者、出題の履歴を持ちます |
| **部屋作成者** | その部屋を作った人。締め切り、役割の指定、受刑者の指定、グループの作成と削除、部屋コメント、部屋の削除ができます |
| **入室者** | その部屋に入ったことがある人。退室した人も一覧に残ります |
| **出題** | お題の投稿。回数は「第n回」と数えます |
| **回答** | お題への答え。カード右上に回答番号が付きます |
| **投票** | 回答へ入れる票。1票とは限らず、数値で持てます。0票も投票です |
| **フェーズ** | 回答・投票・結果の進行段階 |
| **グループ** | 部屋の中で入室者を分ける単位 |
| **Zスコア** | その回の回答の得票を、平均と標準偏差で見た値。以前の更新情報では「標準化変量」と呼んでいました |
| **ユニコーン** | Zスコアが 2 以上の回答に付く印。メニューバーには、その部屋で自分が獲得した累計も出ます |
| **アイスクリーム** | Zスコアが −2 以下の回答に付く印 |
| **受刑者** | 部屋作成者が強制退室させた入室者。一覧では取り消し線が付きます |
| **トークン** | 入室者ごとに割り当てられ、一覧の右側に出る 8 文字。ログではディスクリミネーターとも呼びます |
| **サインオーバー** | サインイン状態を、別のブラウザーへ 1 時間以内に引き継ぐ機能 |
| **ソーシャルサインイン** | Twitter または Bluesky のアカウントで入ること |
| **首位回答者** | 出題優先時間の対象になる、その回で最も評価の高い回答の作者。以前の表記は「投票者首位」です |

## 2. 遊び方の全体像

### 2.1 最短の流れ

1. トップ画面で「サインイン」を押す。
2. 部屋一覧から「入室する」を押す。パスワード付きの部屋では、パスワードを聞かれます。
3. 出題待ちなら、出題が許されている人が「出題する」を押す。
4. 回答フェーズで「回答する」。
5. 投票フェーズで「投票する」。
6. 結果フェーズで順位を見て、必要ならコメントする。
7. 次のお題が出ると、また回答フェーズに戻る。

ボタンが押せない、他の人の回答が見えない、というときは、いまのフェーズ、制限時間、役割、グループ、表示設定のどれかが原因です。第20章に切り分けをまとめました。

### 2.2 フェーズ

部屋は常に次のどれかです。フェーズ名はアニメーション付きのバッジで出ます。

| フェーズ | 画面の表示 | 主な操作 |
|---|---|---|
| 出題待ち | 「出題はありません」 | 出題する |
| 回答フェーズ | 「回答フェーズ」（青系） | 回答する。設定によっては回答の変更・削除 |
| 処理中 | バッジがスピナーになる | 回答の公開処理。操作は待ってください |
| 投票フェーズ | 「投票フェーズ」（緑系） | 投票する、投票を変更する、投票を削除する、投票を見る |
| 集計中 | バッジがスピナーになる | 集計が終わるまで待ってください |
| 結果フェーズ | 「結果フェーズ」（赤系） | 順位と Zスコアを見る、コメントする、次を出題する |

フェーズが進むきっかけは2つです。

- **制限時間** — 「回答時間制限」「投票時間制限」「出題優先時間」が設定されていれば、時間切れで次へ進みます。
- **部屋作成者の手動締め切り** — 次のボタンで途中締め切りできます。それぞれ確認のダイアログが出ます。
  - 「回答を締め切る」
  - 「投票を締め切る」
  - 「出題優先を締め切る」

締め切りのあと、サーバー側で公開や集計が行われます。完了するまでバッジはスピナーのままです。ログのダウンロードのように時間がかかる処理では、サーバーが処理中であることを示す表示も出ます。

### 2.3 いつ他の人の投稿が見えるか

部屋設定の「回答表示」「投票表示」で決まります。

- **即時** — 投稿されるたびに反映されます。回答数もリアルタイムで増えます。
- **一斉** — 締め切りのあと、まとめて出ます。
  - 回答表示「一斉（投票フェーズまで非表示）」では、他の人の回答は投票フェーズに入るまで見えません。自分の回答は回答フェーズ中も見えます。
  - 投票表示「一斉（結果フェーズまで非表示）」では、他の人の投票は結果フェーズまで見えません。

自分の回答者名と、自分の投票者名は、匿名設定にかかわらず常に表示されます。

### 2.4 残り時間

制限時間があるフェーズでは、残り時間が円形のリングで出ます。出る場所は次のとおりです。

- フェーズ名のバッジ（大きく表示）
- 「回答する」ボタンの横
- 回答ダイアログ、投票ダイアログの下部
- 投票フェーズでは、各回答カード

表示は秒、分:秒、時:分:秒と切り替わります。通常は緑、終了間際や自分がその操作を許されていないときは赤です。

投票の起算時刻は設定の組み合わせで変わります。詳しくは第10章です。

### 2.5 処理中のボタン

実行ボタンは、処理中にスピナーがボタンそのものに重なります。完了するまで連打しないでください。二重送信は防止されています。

## 3. サインインと名前

### 3.1 サインイン画面

未サインインのまま部屋を開こうとすると、サインイン画面へ案内され、完了後に元の画面へ戻ります。トップ画面で「部屋を作成する」を押したときも、先にサインインのダイアログが開きます。

ダイアログは2段です。

| 区分 | 操作 |
|---|---|
| サインイン | 「**新規サインイン**」を押し、名前を設定する |
| ソーシャルサインイン | 「Twitterでサインイン」または「Blueskyでサインイン」 |

通常のサインインは、名前を直接打つのではなく、まず「新規サインイン」を押す形です。名前の初期値は「お客さん」です。同じブラウザーで以前に使った名前があれば、そちらが入ります。

通常のサインインでは、reCAPTCHA による確認が入ります。サインアウト後にすぐ入り直せない、といった最短時間の制限はありません。

### 3.2 Twitter でサインイン

Twitter でサインインすると、入室者一覧の名前にリンクが付き、メニューにはプロフィール画像が出ます。画像を読み込めないときは、既定の画像に差し替わります。

Twitter でサインインするときの画面遷移は、暫定の措置が入っています。この措置は予告なく終わることがあります。うまく入れないときは、いったんキャンセルしてからやり直してください。

### 3.3 Bluesky でサインイン

「Blueskyでサインイン」を押すと、ハンドルの入力ダイアログが開きます。`@` は欄の外に付いているので、ハンドル本体（例: `alice.bsky.social`）を入れます。ハンドルの形式が合わないと「ハンドルが有効ではありません」と出ます。

Bluesky サインインは OAuth で、当面は試験稼動です。認証から戻ったあとの画面遷移で入れないときは、もう一度サインイン画面からやり直してください。

### 3.4 名前のルール

名前は 1〜20 文字です。先頭と末尾の空白は使えません。長すぎると「名前は最大20文字です」、形式が合わないと「名前が有効ではありません」と出ます。

名前の末尾に `#` と任意の文字列を付けると、`#` より後ろは暗号学的ハッシュの先頭 8 文字に置き換わって表示されます。同じ秘密でも、`#` より前の名前が違えばハッシュは別になります。計算方法は 2020 年に変わっているので、それより前の更新情報に出ているハッシュの例は、いまの表示と一致しません。

例（いまの計算）:

- `びぎりちゃん` → `びぎりちゃん`（`#` が無ければそのまま）
- `びぎりちゃん#abc` → `びぎりちゃん#6L-vdcLV`
- `風祭ビギリマナ春子#abc` → `風祭ビギリマナ春子#qtOytdmD`

ハッシュを付けていても、ソーシャルリンクは表示されます。以前はハッシュ付きの名前や、部屋の中だけで変えた名前ではリンクを隠していましたが、その扱いは廃止されています。

### 3.5 名前を変える

サインアウトせずに名前を変えられます。場所が2つあり、効く範囲が違います。

| どこで変えるか | ダイアログ | 効く範囲 |
|---|---|---|
| トップ画面のメニューに出ている自分の名前 | 「名前を変更する」 | サインイン全体。このあと入る部屋の初期の名前になる |
| 部屋画面のメニューに出ている自分の名前 | 「名前やリンクを変更する」 | その部屋だけ |

部屋の中のダイアログでは、リンクの有無も選べます。

- **無し** — 入室者一覧にソーシャルリンクを出さない
- **有り（URL）** — 指定した URL を出す。`http://` または `https://` で、空も許されます

部屋の中で変えた名前は、その部屋の表示だけが変わります。トップ画面の名前は別です。各ダイアログに、もう一方はどこで変えるかの注記があります。

### 3.6 サインアウト

メニューの「サインアウト」で確認ダイアログが開きます。

> サインオーバーまたはソーシャルサインインしていない場合はこのサインイン状態に戻ることはできません。

通常のサインインだけの状態は、サインアウトすると同じ入室者としては戻れません。別の端末でも同じ状態を使いたいときは、サインアウトの前にサインオーバーするか、ソーシャルサインインを使ってください。

### 3.7 サインオーバー

サインインした状態を、別のウェブブラウザーへ引き継げます。トップ画面または部屋画面のメニューから「サインオーバー」を開きます。

- リンクと QR コードが出ます。引き継ぎ先で、**1 時間以内**に開いてください。
- 「URLをコピーする」でリンクをコピーできます。コピー済みになるとアイコンの見た目が変わります。
- 引き継ぎ先では「サインオーバー元からサインイン状態を引き継いでサインインします」と出るので、「サインイン」を押します。

発行元のダイアログは「閉じる」で終わります。引き継ぎ先の確認は「キャンセル」で中止できます。

## 4. トップ画面と部屋一覧

### 4.1 画面の構成

上から、メニュー、サービスの紹介、更新情報、使用方法、部屋一覧、の順です。

メニューの右上は、サインイン前は「サインイン」、サインイン後は自分の名前、プロフィール画像、「サインオーバー」「サインアウト」です。名前を押すと名前の変更ダイアログが開きます。自分の名前は、部屋一覧の入室者名の中でも色が変わり、どれが自分か分かります。

「更新情報」には最新の数件が出ます。「全更新情報を見る」で履歴をダイアログに出せます。「使用方法」には、この種のユーザーマニュアルへのリンクと、GitHub ディスカッションへのリンクがあります。

### 4.2 部屋一覧でできること

各部屋はカードです。次の情報が並びます。

- 部屋名。Twitter と Bluesky の投稿ボタン、および部屋名での検索リンクが付きます。投稿文には部屋名と、説明の1行目、部屋のアドレスが入ります。
- 説明。説明の中の URL は自動でリンクになります。
- アイコン画像（設定している場合）
- 作成者、作成日時、入室制限、および出題・回答・投票の設定の要約
- 更新日時
- 入室者名。自分の名前は色が変わります
- 「入室する」。作成者には「部屋を削除する」も出ます

部屋が1つもないときは「部屋はありません」と出ます。読み込み中はスピナーです。

### 4.3 表示順と自入室フィルター

一覧の右上に2つの操作があります。

| 操作 | 意味 |
|---|---|
| ドロップダウンの「作成順」「更新順」 | どちらも日時の新しい順です。選んだ順は、そのブラウザーに残ります |
| spock の手のボタン | **自入室フィルター**。オンにすると、自分が入室している部屋だけが残ります。オンのときはアイコンが塗りつぶされます |

### 4.4 入室する

「入室する」を押します。未サインインなら、先にサインインします。

入室制限が「有り（パスワード）」の部屋では、「部屋のパスワードを入力する」が開きます。合わないパスワードでは入れません。入室制限の判定の実装は更新されていますが、利用者から見る手順はパスワードの入力のままです。

入室すると部屋画面へ移ります。別の画面から部屋を開いたときは、部屋のデータを読み直すため、ページが再読み込みされることがあります。

### 4.5 未更新の部屋はいくつ作れるか

ソーシャルサインインをしていない場合、自分が作り、まだ一度も更新されていない部屋は **1 つまで**です。その状態の部屋があるあいだ、「部屋を作成する」は押せません。出題などの活動が入って更新日時が付くと、次の部屋を作れます。

Twitter または Bluesky でサインインしている場合は、未更新の部屋を複数作れます。

### 4.6 部屋を削除する

削除できるのは部屋作成者だけです。操作は部屋の中ではなく、**トップ画面の部屋カード**にある「部屋を削除する」です。確認ダイアログで部屋名を見てから「削除する」を押します。削除は取り消せません。

## 5. 部屋を作る

### 5.1 開く

トップ画面の「部屋を作成する」を押します。未サインインなら、先にサインインします。ダイアログの項目は多く、作成後には変更できません。同じ設定を繰り返すときは、履歴を使ってください。

前回そのブラウザーで作った部屋の設定は、次に開いたときの初期値になります。アイコン画像も、直近の設定が初期値になります。

### 5.2 履歴

部屋名の横の「履歴を見る」から、同じブラウザーで作った部屋の一覧を出せます。履歴が無いときはボタンは押せません。

- 「履歴を読み込む」で、そのときの設定をフォームへ戻します。
- 「履歴を削除する」で、その履歴だけを消します。実在の部屋は消えません。
- 一覧には作成日時が出ます。
- 同じ部屋名で再度作ると、履歴には最新の設定だけが残ります。

履歴はブラウザーの中に保存されます。別の端末や別のブラウザーには引き継がれません。

### 5.3 基本の項目

| 項目 | 内容 | 制限 |
|---|---|---|
| 部屋名 | 必須 | 1〜150 文字 |
| 説明 | 任意。空欄のプレースホルダーは「（無し）」。URL は部屋画面で自動リンクになる | 最大 1500 文字 |
| アイコン画像 | 任意。部屋の右下と、部屋一覧に出る | 面積が 180×180 ピクセルを超える画像は縮小される。容量を超えると「容量制限を超えているまたは有効ではありません」 |
| カラースキーム | 無し / ライト / ダーク | 無しは、ブラウザーや OS の設定に従う |
| 入室制限 | 無し / 有り（パスワード） | パスワードは空白を含まない 1〜15 文字 |

アイコンは選んだあと「削除する」で外せます。

### 5.4 作ったあとに変えてよいこと、いけないこと

変えられません。

- 部屋名、説明、アイコン、カラースキームの初期値、パスワードの有無
- 出題・回答・投票の各設定（時間、匿名、一斉、票数、グループ投票など）

変えられます。

- 入室者を出題者・回答者・投票者・受刑者に入れる、外す
- グループの作成、削除、自分の所属
- 部屋コメントの投稿と、最新1件の削除
- その部屋の中だけの自分の名前とリンク
- セッション中のカラースキーム（保存はされません）

「出題者制限（初期値）」などが「有り」の部屋は、作成者が入室者一覧で人を指定するまで、誰もその役割を使えません。作成者自身も自動では入りません。作った直後に自分を追加するのを忘れないでください。

### 5.5 入力エラー

文字数や形式が合わない項目は、欄の下に赤字で出ます。ダイアログ上部には "Some input values are invalid." という警告も出ることがあります。時間や票数は数字だけ、パスワードは空白なし、です。直してから「部屋を作成する」を押し直してください。処理中はボタンにスピナーが重なります。

## 6. 部屋設定リファレンス

作成画面の並びのまま説明します。一覧カードと部屋画面の上部には、同じ設定の要約が出ます。要約では「一斉（投票フェーズまで非表示）」は「一斉」のように短くなります。

数値の欄は、有効にしたときだけ入力できます。秒数や票数や回答数は最大 6 桁です。投票時間の「回答毎」だけ、小数第1位まで入れられます。空のプレースホルダーは `0.0` です。

### 6.1 出題

#### 出題優先時間

結果フェーズに入った直後、一定秒数だけ出題できる人を限る設定です。

| 値 | 動作 |
|---|---|
| 無し | 結果が出たら、出題が許されている人はすぐ次を出せる |
| 有り（部屋作成者）（秒） | その秒数のあいだ、出題できるのは部屋作成者だけ |
| 有り（首位回答者）（秒） | その秒数のあいだ、出題できるのは首位回答者だけ |

首位回答者は、その回の回答を得点順に見て、投票していない回答者を飛ばした先頭です。投票していない回答者は優先されません。該当者がいないときは、出題が許されている人なら誰でも出せます。

優先時間のあいだ、該当する回答の**回答者名が明滅**します。以前は優先された人の「出題する」ボタンが明滅していましたが、その表示は廃止されています。

部屋作成者は「出題優先を締め切る」で、残り時間を待たずに優先を終われます。タイマーは「出題する」の横にも出ます。自分が優先対象でないときは赤です。

以前の「有り（禁止）」は、部屋作成者だけが出題できる「有り（部屋作成者）」に変わっています。古い部屋を履歴から読み込んだときは、選び直してください。

#### 出題者制限（初期値）

| 値 | 誰が出題できるか |
|---|---|
| 無し | 入室者なら誰でも |
| 有り | 入室者一覧で出題者に追加された人だけ。追加するまで誰も出題できない |
| 有り（ソーシャルサインイン） | Twitter または Bluesky でサインインしている入室者 |

入室者一覧で出題者を1人でも指定すると、この初期値は無視され、指定した人だけが出題できます。指定を全員外すと、初期値に戻ります。

サーバーは、出題優先時間や回答数制限や投票数制限に従わないアクセスをブロックします。画面のボタンが押せない状態を、別の手段で迂回しても通りません。

#### 出題画像制限

| 値 | 動作 |
|---|---|
| 無し | 出題に画像を付けられる |
| 有り（禁止） | 「画像有り」が出ない |

#### 出題コメント制限

結果フェーズで、お題そのものへコメントできる人です。

| 値 | 動作 |
|---|---|
| 無し | 入室者なら誰でも |
| 有り（部屋作成者） | 部屋作成者だけ |

### 6.2 回答

#### 回答表示

| 値 | 動作 |
|---|---|
| 即時 | 回答は投稿と同時に全員へ見える。回答数もリアルタイム |
| 一斉（投票フェーズまで非表示） | 他の人の回答は投票フェーズまで見えない。自分の回答は見えるので、締め切り前なら変更・削除できる |

#### 回答時間制限

| 値 | 動作 |
|---|---|
| 無し | 部屋作成者が「回答を締め切る」まで回答フェーズが続く |
| 有り（秒） | 出題時刻からその秒数で自動締め切り |

#### 回答シャッフル時間

投票フェーズでの、初期の並び（「設定順」）に影響します。結果フェーズの順位には影響しません。

| 値 | 動作 |
|---|---|
| 無し | シャッフルしない |
| 有り（秒）に数値 | 出題時刻からその秒数以内に投稿された回答だけを、入室者ごとに違う順で混ぜる |
| 有り（秒）を空にする | すべての回答がシャッフル対象。一覧の表示は「∞秒」 |

シャッフルの範囲が出題の制限時間以上のときは、期限を超えた回答も含めて混ぜます。並びは入室者ごとに違うので、投票中に「上にある回答が有利」にはなりにくいです。結果フェーズで「設定順」を選ぶと、得点順になります。

#### 回答数制限

| 値 | 動作 |
|---|---|
| 無し | 1人何答でも投稿できる |
| 有り（答） | 1人あたり、その回数まで。達すると「回答する」が押せなくなる |

#### 回答者名表示

| 値 | 動作 |
|---|---|
| 表示 | 回答者名を出す |
| 非表示 | 回答者名を出さない |
| 一斉（結果フェーズまで非表示） | 結果フェーズまで回答者名を出さない |

自分の回答には、設定にかかわらず自分の名前が出ます。名前をクリックすると、トークンの表示に切り替わります。もう一度押すと名前に戻ります。

#### 回答者制限（初期値）

出題者制限と同じ3択です。入室者一覧で回答者を指定すると、初期値よりそちらが優先されます。「有り」だけを選んで誰も追加しないと、誰も回答できません。

#### 回答コメント制限

結果フェーズで、各回答へコメントできる人です。出題コメント制限と同じく、「無し」か「有り（部屋作成者）」です。以前あった「有り（自回答）」は、この二択に整理されて残っていません。

#### 回答描画制限

| 値 | 動作 |
|---|---|
| 無し | 回答に手描きの線画を付けられる |
| 有り（禁止） | 「描画有り」が出ない |

### 6.3 投票

#### 投票表示

| 値 | 動作 |
|---|---|
| 即時 | 投票は入るたびに見える |
| 一斉（結果フェーズまで非表示） | 他の人の投票は結果フェーズまで見えない。自分の投票者名は見える |

#### 投票時間制限

表記は「有り（出題毎+回答毎×）（秒）」です。2つの数を足します。

```
投票に使える秒数 = 出題毎の秒数 + 回答毎の秒数 × 回答数
```

- 出題毎は整数の秒です。
- 回答毎は小数第1位までです。空なら 0 として扱われます。
- 投票グループ制限が有効で、グループが実際にあるときは、ここでの回答数は全体ではなく、**表示される回答数が最も多いグループの回答数**です。
- グループが1つも無いときは、投票グループ制限が有っても、制限が無いときと同じ計算です。

タイマーの起点は次のとおりです。

| 回答表示 | 投票表示 | 起点 |
|---|---|---|
| 即時 | 即時 | その回答が投稿された時刻。回答ごとに締切が違う |
| それ以外 | — | 投票フェーズが始まった時刻 |

投票時間制限が無いときは、部屋作成者が「投票を締め切る」まで投票できます。

#### 投票数制限（出題毎）

1回の出題に対して、1人が入れられる票の合計です。

| 値 | 動作 |
|---|---|
| 無し | 合計の上限なし |
| 有り（票） | その票数まで。達すると、まだ投票していない回答の「投票する」は「投票を見る」に変わる |
| 有り（超過可）（票） | ボタンの見た目は「有り」と同じく、上限に達すると「投票を見る」に変わる。すでに入れた投票を「投票を変更する」から開くと、画面の上では上限を超えて票を足せる |

「投票を見る」の末尾には、使った票数と上限が `使用 / 上限` の形で出ます。投票数制限（出題毎）が有る部屋では、投票を見る画面の合計の横にも上限が出ます。

#### 投票数制限（回答毎）

1つの回答に対して、1人が入れられる票数です。「無し」か「有り（票）」です。出題毎の「超過可」とは別です。回答毎の上限は、投票画面の「＋」がそこで止まります。

両方を同時に設定できます。

#### 投票者名表示

回答者名表示と同じ3択です。自分の投票には、設定にかかわらず自分の名前が出ます。

#### 投票者制限（初期値）

出題者制限・回答者制限と同じ3択です。一覧で投票者を指定すると、初期値よりそちらが優先されます。

#### 投票グループ制限

投票フェーズで、どのグループの回答が見え、投票できるかを限る設定です。グループを1つも作らなければ、この設定は無いときと同じです。

| 値 | 投票フェーズで見える回答 |
|---|---|
| 無し | すべての回答 |
| 有り（自グループに投票） | 自分と同じグループの回答だけ |
| 有り（次グループに投票） | 自分のグループの直後に作られたグループの回答だけ。自分のグループが最後なら、最初に作られたグループ。グループ未選択なら、グループの付いていない回答だけ |

結果フェーズと過去の結果では、この制限は外れ、すべての回答が見えます。

## 7. 部屋の中の画面

### 7.1 メニュー

左端のロゴを押すとトップ画面へ戻ります。戻るときは部屋を読み直すため、再読み込みになることがあります。

| 項目 | 動作 |
|---|---|
| 自分の名前 | 「名前やリンクを変更する」を開く。グループに入っていれば、名前の横に `@グループ名` が出る |
| ユニコーン | その部屋で獲得した累計。名前の右に並ぶ |
| サインオーバー | 第3.7節 |
| 退室する | 確認のあと、その部屋を退室してトップへ戻る。退室しても、入室者一覧には残る |
| 太陽 / 月 / 半円のボタン | カラースキーム。オート、ライト、ダーク。この選択は保存されない |
| メイン | いまの出題 |
| 過去の結果 | 34.5 日以内の出題 |
| ログ（CSV） | 同じ範囲のダウンロード |

部屋のカラースキームをライトまたはダークにしていても、このメニューでセッション中は上書きできます。オートは、ブラウザーや OS の設定に従います。

タブを切り替えると、メニューと設定表の下、つまりそのタブの中身の先頭までスクロールします。

### 7.2 部屋のヘッダー

部屋名、説明、設定の3つの表、アイコン画像が出ます。説明の URL はリンクになります。部屋名の横には、トップ画面と同じ Twitter / Bluesky の投稿ボタンと検索リンクがあります。

設定表の下に、次の2つのボタンがあります。

- **グループを選択する** — 常に押せます。グループが無くても開けます。
- **入室者を見る** — 入室者の一覧と、作成者向けの役割指定です。

### 7.3 部屋コメント

設定表の下、出題の上に、部屋作成者のコメントが出ます。これは出題コメントや回答コメントとは別で、フェーズに関係なく、部屋作成者だけが投稿できます。

- 「コメントする」で追加します。最大 150 文字。空のコメントも投稿できます。
- 「コメントを削除する」は、**最新の1件だけ**を消します。古いコメントを個別には消せません。
- 本文中の URL はリンクになります。

出題コメントと回答コメントは、結果フェーズだけで、各カードの側に付きます。第12章です。

### 7.4 フッター

左下にサイト名、右下に部屋のアイコン画像と部屋名が出ます。アイコンは部屋の目印として、スクロールしても右下に残ります。

## 8. 出題する

### 8.1 ボタンが出る条件

「出題する」が出るのは、出題が許されている人だけです。さらに、結果フェーズの出題優先時間中は、優先された人以外は押せません。出題待ち（「出題はありません」）のときと、結果フェーズのときに押せます。回答フェーズと投票フェーズの途中では、次の出題はできません。

### 8.2 出題ダイアログ

| 欄 | 内容 | 制限 |
|---|---|---|
| 出典 | 任意。お題の上に「出典」として出る。URL はリンクになる | 最大 150 文字 |
| 画像 | 「画像有り」でファイルを選ぶ。出題画像制限が禁止の部屋では出ない。選んだあとは「削除する」で外せる。背景は白 | 画像が無い状態に戻すと、出典が画像のファイル名だけだった場合は出典も空に戻る |
| 出題 | 本文。画像だけにして本文を空にすると、本文は「🖌️」になる | 1〜1500 文字 |

画像お題で本文を空のまま送ると、以前はファイル名が本文の初期値でしたが、いま空の本文は絵筆の絵文字になります。著作物を使うときは、出典を入れてください。

送信は「出題する」ボタンのほか、本文欄で **Ctrl+Enter** または **Command+Enter**（Windows キーや Command キーと改行）でもできます。Enter 単独では送信しません。Esc でダイアログを閉じます。

複数行の入力欄は、行数に合わせて伸びます。

### 8.3 出題がぶつかったとき

ほぼ同時に2人が出題すると、一方だけが採用されます。競合したときは、画面の表示が落ち着くまで待って、自分の出題が残っているかを確認してください。

### 8.4 出題の表示

採用されると「第n回」と出題者名が出ます。名前をクリックするとトークンに切り替わります。出典、画像、本文の順です。本文が 10 行を超えるか 150 字を超えると、折りたたまれ、隠れた文字数のボタンが出ます。押すと全文、もう一度押すと折りたたみに戻ります。画像はクリックで拡大できます。

## 9. 回答する

### 9.1 ボタンが出る条件

「回答する」は、回答フェーズで、回答が許されている人に出ます。回答数制限に達していると押せません。ボタンの横には、回答時間制限のタイマーが出ることがあります。

### 9.2 回答ダイアログ

ダイアログの見出しの下に、お題の要約と、画像があれば画像が出ます。

| 欄 | 内容 | 制限 |
|---|---|---|
| 描画 | 「描画有り」でキャンバスが開く。回答描画制限が禁止の部屋では出ない。240×180 の線画。元に戻す、やり直すが使える。点の間隔はおよそ毎秒 30 点まで | 要素数の上限あり。空の本文で描画だけ送ると、本文は「🖊️」になる |
| 回答 | 本文 | 1〜1500 文字 |

送信は「回答する」、または本文欄の Ctrl+Enter / Command+Enter です。ダイアログの下には回答の残り時間が出ます。

グループに入っている状態で回答すると、その回答にグループが付きます。投票グループ制限や、結果画面のグループ名は、この付いたグループを見ます。回答したあとにグループを変えても、既に付いたグループは変わりません。

### 9.3 回答を変更する、削除する

変更と削除のボタンが出るのは、次のすべてを満たすときだけです。

- まだ回答フェーズである（締め切り前）
- 回答表示が「一斉」である
- その回答が自分のものである

「回答を変更する」を送ると、回答時刻も更新されます。シャッフル時間や、即時投票のタイマーの起点が動くことがあります。

回答表示が「即時」の部屋では、一度送った回答の変更・削除ボタンは出ません。送る前に本文を確認してください。

### 9.4 回答カード

各回答はカードです。

- ヘッダー左: 回答者名。設定で隠されているときは空き、または結果まで出ません。自分の名前は色が違います。首位回答者の優先時間中は、その名前が明滅します。名前をクリックするとトークンに切り替わります。
- ヘッダー右: 回答番号
- 本文と、あれば描画。長い本文は出題と同じく折りたたまれます。
- 得票数。親指のアイコンと数値です。結果が出る前でも、投票表示が即時なら増えていきます。

画面の一番下には、手のアイコンと回答数が出ます。投票グループ制限が有効で、まだ結果フェーズでないときは `そのグループの数/全体の数` です。投票グループ制限が無いときは、グループごとの数は出さず、全体の数だけです。

## 10. 投票する

### 10.1 自分の回答には投票できない

自分が出した回答には、「投票する」も「0」も出ません。他の人の回答にだけ投票できます。

### 10.2 ボタンが出るタイミング

投票フェーズが終わるまでが投票期間です。ボタンが見える条件は、投票時間制限の有無と、表示設定の組み合わせで変わります。

- **投票時間制限が無い** — 回答が見えているあいだ、投票の締め切りまで投票できます。
- **回答表示が即時、投票表示が一斉** — 回答フェーズのあいだから投票ボタンが出ます。他の人の票は結果まで見えません。
- **回答表示も投票表示も即時** — その回答が投稿された時刻から、その回答ごとの残り時間のあいだ投票できます。回答が遅いと、その回答の投票締切も遅れます。
- **回答表示が一斉** — 投票フェーズに入ってから、投票フェーズの開始時刻を起点に、制限時間のあいだ投票できます。

時間切れの回答からはボタンが消えます。部屋作成者が「投票を締め切る」と、すべての回答で投票が終わります。

### 10.3 投票ダイアログ

「投票する」または「投票を変更する」で開きます。お題の要約、回答の本文と描画、票数の操作が並びます。

- 「−」で 1 減らし、「＋」で 1 増やします。0 より下にはなりません。
- 開いた直後、票数の操作にフォーカスがあります。
- **Space** で増票、**Delete** で減票、**Enter** で送信です。
- 新規の投票の初期値は、まだ票を足せるなら 1、上限に達しているなら 0 です。変更のときは、いまの票数が初期値です。
- 回答毎の上限、または超過不可の出題毎の上限に達すると「＋」が止まります。
- ダイアログの下に、その回答の投票残り時間が出ることがあります。

マウスで票数ボタンを上下にドラッグして増減する操作は、廃止されています。

### 10.4 0票のクイック投票

まだその回答に投票していないとき、「投票する」の横に「0」ボタンが出ます。押すと、ダイアログを開かずに 0 票を投票できます。0 票は「投票した」という記録になり、投票者名の表示設定によっては名前だけが並びます。得点には入りません。

0 票を入れたあとは、その回答は「投票を変更する」と「投票を削除する」に変わります。

### 10.5 投票を変更する、削除する

投票の締め切り前なら、自分の投票を変更できます。いったん削除しなくても、票を減らせます。

「投票を削除する」は確認ダイアログを出さず、ボタンを押すと削除します。処理中はスピナーが重なります。削除したあとは、再び「投票する」と「0」に戻ります。

### 10.6 票を使い切ったとき

投票数制限（出題毎）に達すると、まだ投票していない回答のボタンは「投票を見る」になります。ここから新しい回答へ票を振るには、既存の投票を削除するか、超過可の部屋なら既存の投票を変更して票を移してください。

超過可でない部屋では、合計が上限を超える投票は送れません。

### 10.7 投票の見え方

回答カードの得票数の下に、投票者が並びます。並びは **票数の多い順** です。票数が同じときは、投票が早い方が先です。

- 1票は名前と親指のアイコンです。
- 2票以上は、そのあとに数値が付きます。
- 0票は、名前が出る設定なら名前だけです。
- 名前をクリックするとトークンに切り替わります。
- 自分の投票は名前の色が変わります。

得票数（親指と数値）を押すと、**その回答だけの自投票フィルター**がオンになります。もう一度押すと戻ります。オンのときはアイコンが塗りつぶされます。

### 10.8 投票を見る

投票フェーズでは、投票が許されている人の回答一覧の上に「投票を見る」が出ます。自分が 1 票以上、または 0 票を入れていると押せます。まだ1件も投票していないあいだは押せません。機能としては、自分が投票した回答だけを集めた一覧です。

各回答からも、票を使い切ったときの「投票を見る」で同じ画面を開けます。画面の末尾に、使った票数の合計が出ます。出題毎の上限がある部屋では、その横に上限も出ます。

以前は、最後に投票した回答へ自動でスクロールしていました。そのスクロールは廃止されています。

## 11. 結果・順位・Zスコア

### 11.1 順位の決まり方

結果フェーズの初期の並びは得点順です。順位は次の順で決まります。

1. 得票数が多い回答が上です。得票数は、その回答に入った票の合計です。0票は合計に入りません。
2. 得票数が同じときは、回答者の投票量から求めた補正が大きい方が上です。補正は、その回答者が他の回答へ入れた票の合計を、自分以外の回答数で割った値です。回答していない人、またはその回の回答が自分だけだった人には付きません。投票していない回答者は、この補正が 0 です。
3. それでも同じときは、回答が早い方が上です。

カードに出る数値そのものは、補正を足す前の得票数です。順位と Zスコアの計算には、得票数に補正を足した値を使います。

### 11.2 Zスコア

その回の回答について、補正後の得票の平均と、母標準偏差（個数 n で割る標準偏差）から計算します。偏差が 0 のとき、つまり全員が同じ値のときは、Zスコアは 0 です。

順位の数字をクリックすると、Zスコアが小数第4位まで出ます。もう一度クリックすると順位に戻ります。

| Zスコア | 見た目 |
|---|---|
| 1 以上 | 順位に下線 |
| 2 以上 | ユニコーンが 1 つ。小数点以下を切り捨てた値から 1 を引いた個数。2.9 なら 1 つ、3.0 なら 2 つ |
| −1 以下 | 順位に上線 |
| −2 以下 | アイスクリームが 1 つ。同様に、切り捨てた絶対値から 1 を引いた個数 |

ユニコーンの累計は、Zスコアが 2 以上だった回答について、上の個数を足したものです。入室者一覧の右、部屋画面のメニューの自分の名前の右、に出ます。以前は低い Zスコアにモアイ像を出していましたが、いまはアイスクリームです。

### 11.3 結果フェーズでできること

- 順位と Zスコアを見る
- グループ名を押して、そのグループだけに絞る
- 目のアイコンで、その回答だけをピックアップする
- コメントする、リアクションする
- 出題優先時間があれば、そのあいだに次の出題をする。部屋作成者は優先を途中で締め切れる

結果フェーズのコメントは、出題の下と、各回答カードのフッターに分かれます。過去の結果でも、同じコメントが読めます。過去の結果では、コメントの新規投稿はできません。

## 13. グループ

### 13.1 何のための機能か

グループは、入室者を部屋の中で分ける単位です。使い道は次のとおりです。

- 回答に、回答した時点のグループ名を残す
- 結果フェーズと過去の結果で、グループ名を押して絞る
- 投票グループ制限と組み合わせて、投票対象を自グループまたは次グループに限る
- ログのグループ名の列に出す

グループ分離という独立した部屋設定は廃止されています。投票フェーズで他グループの回答を隠すかどうかは、投票グループ制限で決めます。回答フェーズでは、回答表示の即時 / 一斉が、他の人の回答が見えるかを決めます。

### 13.2 グループを作る、消す

「グループを選択する」を開きます。部屋作成者には「グループを作成する」が出ます。

| 欄 | 制限 |
|---|---|
| グループ名 | 1〜20 文字。先頭と末尾の空白は不可 |
| 説明 | 任意。最大 1500 文字。空欄のプレースホルダーは「（無し）」 |

グループ名の横の「履歴を見る」は、部屋の履歴と同じ考え方です。同じブラウザーで作ったグループを読み込めます。同じグループ名で再度作ると、履歴には最新の設定だけが残ります。履歴を消しても、部屋に実在するグループは消えません。

作成者は、各グループの「グループを削除する」で消せます。そのグループを選んでいた入室者は所属が外れ、選択画面が再び開きます。

### 13.3 グループを選ぶ

一覧のラジオボタンを選ぶと、すぐに所属が変わります。説明と、所属人数、所属者名が出ます。名前をクリックするとトークンに切り替わります。人数のアイコンは、入室者一覧と同じ spock の手です。

次のときは、選択画面が自動で開きます。

- グループが追加され、まだ自分はどのグループにも入っていない
- 入室した時点で、すでにグループがある
- 選んでいたグループが削除された

キャンセルして閉じることもできます。未所属のままでも入室は続きます。投票グループ制限が「次グループに投票」のとき、未所属の人が投票フェーズで見るのは、グループの付いていない回答だけです。

初期グループを自動で割り当てる機能は廃止されています。所属は各自が選びます。

### 13.4 グループ名の色とフィルター

結果フェーズと過去の結果では、回答の上にグループ名が出ます。名前を押すと、そのグループの回答だけが残ります。これはセカンダリーフィルターです。自回答・自投票・自コメントのプライマリーフィルターを新しくオンにすると、グループの絞り込みは外れます。プライマリーをオンにしたあとにグループ名を押せば、両方を重ねられます。

## 14. 絞り込みと並べ替え

### 14.1 回答の表示順

回答一覧の右上のドロップダウンです。選んだ順は、その画面を見ているあいだの並びです。

| 表示順 | 使えるフェーズ | 意味 |
|---|---|---|
| 設定順 | すべて | 部屋設定による初期の並び。シャッフルが有る投票フェーズでは、入室者ごとに違う順。結果フェーズでは得点順 |
| 先着順 | すべて | 回答が早い順 |
| 後着順 | すべて | 回答が遅い順 |
| 上位順 | すべて | 得点が高い順。同点は第11章の順位と同じ |
| 下位順 | すべて | 得点が低い順 |
| 多コ順 | 結果フェーズと過去の結果 | コメントが多い順 |
| 少コ順 | 結果フェーズと過去の結果 | コメントが少ない順 |

「多コ順」「少コ順」は、以前の更新情報では「コ多順」「コ少順」でした。画面の表記はいま「多コ順」「少コ順」です。

フィルターのボタンは、スクロールしても一覧の上に残ります。

### 14.2 プライマリーフィルターとセカンダリーフィルター

プライマリーフィルターは、一覧右上の3つのボタンです。オンのときはアイコンが塗りつぶされ、オフのときは輪郭だけです。このオンとオフの見た目は、途中で入れ替わっています。塗りつぶしがオンです。

| ボタン | 意味 | 併記される数 |
|---|---|---|
| 挙手（手のひら） | 自回答だけ | 回答フェーズでは、自分の回答数 |
| 親指 | 自分が投票した回答だけ | 投票フェーズでは、自分が入れた票の合計 |
| 指さし | 自分がコメントした回答だけ | 結果フェーズでは、自分のコメント数 |

投票フェーズの一覧上部にある「投票を見る」は、自投票フィルターと同じ範囲をダイアログで見る操作です。

セカンダリーフィルターは次の2つです。

- 結果フェーズと過去の結果で、グループ名を押す
- 結果フェーズと過去の結果で、目のアイコンを押してその回答だけを見る。オンのときは目が塗りつぶされます

プライマリーを切り替えると、セカンダリーは外れます。プライマリーをオンにした状態でセカンダリーを押すと、絞った結果にさらに重なります。目のアイコンをもう一度押すと、ピックアップだけが外れます。

回答カードの得票数を押す自投票フィルターは、その回答の中の投票者一覧に対する操作で、上の回答フィルターとは別です。

トップ画面の部屋は「作成順」と「更新順」です。どちらも新しい順です。spock の手で、自分が入っている部屋だけにできます。

入室者一覧の順は第15章です。

## 15. 入室者の確認と役割

### 15.1 一覧の見方

「入室者を見る」で開きます。ダイアログの外をクリックしても閉じます。

各行には、名前、ソーシャルリンクとプロフィール画像、その部屋のユニコーン、トークンが出ます。

- いま部屋にいない人は、薄い文字です。退室した出題者・回答者・投票者も一覧に残ります。
- 受刑者は取り消し線です。
- 自分の名前とトークンは色が変わります。
- 画像を読み込めないときは、既定の画像になります。
- 新規登録者を示す印は廃止されています。
- 末尾の spock の手の横が、一覧の人数です。

名前のリンクは、Twitter、Bluesky、その他の URL でアイコンが変わります。部屋の中でリンクを「無し」にしている人には出ません。

### 15.2 表示順

| 表示順 | 意味 |
|---|---|
| 先入順 / 後入順 | 入室日時 |
| 多🦄順 / 少🦄順 | その部屋で獲得したユニコーンの数 |
| 昇名順 / 降名順 | 名前の Unicode 順 |
| 昇Di順 / 降Di順 | ディスクリミネーター（トークン）の Unicode 順 |
| 古サ順 / 新サ順 | サインイン日時。古い順、新しい順 |

### 15.3 部屋作成者が指定できる役割

幅の広い画面では、各入室者の下にボタンが並びます。狭い画面では「…」で開閉します。処理中は、その人の行にスピナーが重なります。

| ボタン | 効果 |
|---|---|
| 出題者へ追加する / 出題者から削除する | 出題できる人を個別に指定する |
| 回答者へ追加する / 回答者から削除する | 回答できる人を個別に指定する |
| 投票者へ追加する / 投票者から削除する | 投票できる人を個別に指定する |
| 受刑者へ追加する / 受刑者から削除する | 強制退室。自分自身は追加できない |

ある役割を1人でも追加すると、部屋作成時の「無し」「有り（ソーシャルサインイン）」はその役割について無視され、追加した人だけが使えます。全員を削除すると、作成時の初期値に戻ります。

「有り」だけで人を追加していない役割は、誰も使えません。作成者も例外ではありません。

### 15.4 受刑者

受刑者に追加された入室者は強制退室になります。一覧には取り消し線で残ります。「受刑者から削除する」で解除できます。

同じ発信元から出題・回答・投票・コメントしようとした入室者も、あわせて受刑者になることがあります。出題優先、回答数制限、投票数制限に従わないアクセスはブロックされ、不正なアクセスをした入室者が自動で受刑者になることもあります。

### 16.1 過去の結果

部屋メニューの「過去の結果」です。対象は **34.5 日以内の出題**です。それより古い回は、画面にもログにも出ません。以前は 11.5 日以内でしたが、範囲は広がっています。直近の結果だけを見る別画面は、この画面に統合されて廃止されています。

「ログ（CSV）」タブに、ダウンロード用のアドレスが出ます。リンクを押すまでダウンロードは始まりません。入室している必要があります。退室した状態のアドレスを開いても取得できません。

ダウンロード中は、サーバーが処理中であることを示すスピナーが出ます。ファイルの先頭には、表計算ソフトが文字化けしにくいように BOM が付きます。

対象は過去の結果と同じく、34.5 日以内の出題です。部屋が 11.5 日で消える前に、必要なログを保存してください。

| 10 以降 | 投票者名と票数が、投票が早い順に交互に並ぶ。ディスクリミネーター付きのときは投票者名にもトークンが付く |

描画そのものは CSV には入りません。コメントも入りません。

## 17. キーボードと画面の小技

### 17.1 ダイアログ

- **Esc** でダイアログを閉じます。処理の送信中は閉じません。
- タイトルバーをドラッグすると、ダイアログを移動できます。

- 複数行の欄は、中身の行数に合わせて伸びます。

### 17.2 送信

| 場所 | キー |
|---|---|
| 出題の本文、回答の本文 | Ctrl+Enter、または Command+Enter で送信。Enter だけでは改行 |
| 投票の票数 | Space で増やす、Delete で減らす、Enter で送信 |
| 投票の「0」ボタン | クリックだけで 0 票を送る |

### 17.3 クリックで切り替わる表示

| クリックする場所 | 切り替わるもの |
|---|---|
| 出題者・回答者・投票者・コメントした人の名前 | 名前とトークン |
| 結果の順位 | 順位と、小数第4位までの Zスコア |
| 長い本文の文字数ボタン | 折りたたみと全文 |
| 回答の得票数 | その回答の自投票だけを表示 |
| グループ名、目のアイコン、一覧右上のフィルター | 第14章の絞り込み |

画像と描画は、拡大表示できます。

### 17.4 処理中

ボタンにスピナーが重なっているあいだは、同じ操作を連打しないでください。二重送信は防止されていますが、完了前にダイアログを閉じようとしても送信中は閉じません。

## 18. 表示と動作環境

### 18.1 カラースキーム

部屋を作るときの「カラースキーム」は、その部屋を開いたときの初期値です。無し、ライト、ダークから選べます。無しは、ブラウザーや OS の設定に従います。

部屋に入ったあとのメニューでは、オート、ライト、ダークをセッションのあいだだけ切り替えられます。この選択は保存されません。ページを開き直すと、部屋の初期値に戻ります。

ダークモードは試験的な導入から始まり、いまは部屋ごと、セッションごとに選べます。

### 18.2 文字と絵文字

日本語の本文、見出し、回答文には専用のフォントが使われます。絵文字はカラー絵文字のフォントで揃えて表示します。端末によって字形が少し違うことはあります。

プロフィール画像が読み込めないときは、既定のシルエット画像に落ちます。

### 18.3 ブラウザー

古い Internet Explorer は対象外です。言語仕様の対象は ECMAScript 2022 です。普段更新されている Chrome、Edge、Firefox、Safari の現行版を使ってください。

Safari 26.4 および 26.5 では、データの取得が不定期に遅れることへの暫定の通信変更が入っています。表示が遅いときは、いったん再読み込みしてください。

幅の狭い画面では、入室者一覧の役割ボタンが折りたたまれます。部屋のタブやフィルターは折り返して表示されます。

### 18.4 部屋の寿命と記録

| もの | 期間 |
|---|---|
| 部屋そのもの | 最終更新日時から 11.5 日 |
| 過去の結果 | 34.5 日以内の出題 |
| ログ（CSV） | 34.5 日以内の出題 |
| サインオーバーのリンク | 発行から 1 時間 |
| 部屋とグループの作成履歴 | そのブラウザーに残る。サーバーには保存されない |

11.5 日のあいだ更新が無い部屋は終了します。終了前にログが要る場合は、入室した状態で CSV を保存してください。

## 20. うまくいかないとき

### 20.1 ボタンが無い、押せない

| 症状 | 確認すること |
|---|---|
| 「回答する」が無い | 回答フェーズか。回答者制限で自分が外れていないか。入室者一覧で回答者が1人でも指定されていると、指定された人だけが回答できる |
| 「回答する」が押せない | 回答数制限に達していないか。タイマーが赤なら、時間切れか、自分は回答できない状態 |
| 「投票する」が無い | 自分の回答には投票できない。投票フェーズ前で、回答表示が一斉なら、まだ投票できない。投票時間制限が回答ごとに尽きていないか |
| 「投票する」が「投票を見る」になっている | 出題毎の投票数制限に達している。既存の投票を削除するか、超過可なら既存の投票を変更する |
| 「出題する」が無い、または押せない | 出題者制限。結果フェーズの出題優先時間中は、部屋作成者または首位回答者以外は押せない。回答フェーズと投票フェーズの途中では次の出題はできない |
| 「部屋を作成する」が押せない | ソーシャルサインイン無しで、未更新の自作部屋が既に1つある |
| 変更・削除が回答に無い | 回答表示が即時の部屋では、送った回答を変更・削除できない。一斉の部屋でも、回答フェーズが終わるとできない |
| コメントボタンが無い | 出題コメントと回答コメントは結果フェーズだけ。制限が部屋作成者のみなら、作成者以外には出ない。過去の結果では新規コメントできない |
| 描画や画像のボタンが無い | 回答描画制限、出題画像制限が「有り（禁止）」 |

### 20.2 他の人の投稿が見えない

- 回答表示が一斉なら、投票フェーズまで他の人の回答は出ません。自分の回答だけが見えます。
- 投票表示が一斉なら、結果フェーズまで他の人の票は出ません。
- 回答者名、投票者名の「非表示」と「一斉」では、自分以外の名前が隠れます。自分の名前は出ます。
- 投票グループ制限が有効で、グループが存在する投票フェーズでは、自グループまたは次グループの回答だけが見えます。結果フェーズに入ると全員分が見えます。
- 自回答、自投票、自コメント、グループ、ピックアップのどれかがオンになっていないか。オンのアイコンは塗りつぶしです。もう一度押すと外れます。

### 20.3 サインインと入室

- 通常のサインインだけでサインアウトすると、同じ状態には戻れません。戻す必要があるときは、サインアウト前にサインオーバーするか、ソーシャルサインインを使います。
- サインオーバーのリンクは 1 時間で無効です。期限が切れたら、元のブラウザーで発行し直してください。
- パスワード付きの部屋は、パスワードが一致しないと入れません。パスワードは作成後に変更できません。
- 受刑者に追加されていると、強制退室になります。解除できるのは部屋作成者だけです。
- Twitter または Bluesky の画面遷移で戻ってこないときは、サインイン画面からやり直してください。Twitter 側の暫定措置は、予告なく終わることがあります。
- Bluesky のハンドルは、`@` を付けずに、ドメインを含む形で入れてください。

### 20.4 表示が古い、遅い

- フェーズの境目では「処理中」「集計中」のスピナーが出ます。終わるまで待ってください。
- Safari 26.4 / 26.5 では、取得が遅れることがあります。再読み込みしてください。
- 別の部屋から移動したときは、データを読み直すためページが再読み込みされます。
- 部屋は最終更新から 11.5 日で終了します。作成者が削除した場合も一覧から消えます。
- 過去の結果と CSV は 34.5 日以内の出題だけです。それより前の回は、このサイト上では戻せません。

### 20.5 入力が拒否される

| メッセージの要旨 | 対処 |
|---|---|
| 最大n文字 | 部屋名 150、説明と出題と回答 1500、出典とコメント 150、名前とグループ名 20、パスワード 15 |
| 有効ではありません | 名前とグループ名の前後の空白、パスワードの空白、時間や票数の数字以外、URL の形式、ハンドルの形式、画像の容量を確認する |
| アイコン画像が容量制限を超えている | 別の画像にする。大きい画像は自動で縮小されるが、縮小後も形式が合わないことがある |

時間、票数、回答数は 6 桁までです。投票の「回答毎」だけ小数第1位までです。

### 20.6 記録を残したい

1. 部屋が動いているあいだに入室する。
2. 「ログ（CSV）」を開く。
3. トークンまで要るなら「ディスクリミネーター付き」をオンにする。
4. リンクを押して保存する。処理中の表示が終わるまで待つ。

描画とコメントは CSV に入りません。それらが要るときは、結果画面を別に保存してください。部屋の寿命は 11.5 日、ログに出る出題は 34.5 日以内です。

## 付録: 目的別の設定例

作成後に設定は変えられません。始める前に、近い例を選んで調整してください。履歴に残しておけば、次回は読み込めます。

### ゆるく、リアルタイムに

- 回答表示: 即時
- 投票表示: 即時
- 時間制限: 無し
- 回答数制限、投票数制限: 無し
- 名前: 表示
- 出題者・回答者・投票者制限: 無し

部屋作成者が、区切りのいいところで「回答を締め切る」「投票を締め切る」を押します。回答は送ったあとに変更できません。

### 見せずに集めて、一斉に開く

- 回答表示: 一斉（投票フェーズまで非表示）
- 投票表示: 一斉（結果フェーズまで非表示）
- 回答時間制限: 有り
- 投票時間制限: 出題毎だけ、または出題毎+回答毎
- 回答シャッフル時間: 空（∞）にして、投票中の並びを入室者ごとに混ぜる

回答フェーズ中は自分の回答だけが見え、締め切り前なら変更・削除できます。他の人の票は結果まで見えません。

### 持ち票を決めた大会

- 投票数制限（出題毎）: 有り（票）。移動を許すなら超過可
- 投票数制限（回答毎）: 必要なら有り
- 回答数制限: 有り
- 出題者制限: 有り。作った直後に、出題者を入室者一覧へ追加する
- 出題優先時間: 有り（首位回答者）。勝った人が次のお題を出す

超過可にしても、上限に達したあとの新しい回答には「投票する」ではなく「投票を見る」が出ます。票を移すときは、既存の投票を変更します。

### グループ対抗

1. 投票グループ制限を「有り（自グループに投票）」または「有り（次グループに投票）」にして部屋を作る。
2. 入室後、部屋作成者がグループを作る。
3. 各自がグループを選ぶ。選んでから回答すると、回答にグループが付く。
4. 投票フェーズでは、設定どおりのグループの回答だけが見える。
5. 結果フェーズで全員分が開き、グループ名で絞れる。

グループを作らないあいだは、投票グループ制限は無効と同じです。

### 匿名

- 回答者名表示: 非表示、または一斉
- 投票者名表示: 非表示、または一斉
- 名前そのものに `#` と秘密の文字列を付けて、表示名をハッシュ化する

自分の名前と、自分の投票者名は、匿名設定でも自分の画面には出ます。ハッシュは秘密が同じでも、前半の名前が違えば別の 8 文字になります。
