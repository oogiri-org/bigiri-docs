## 初めて参加する

まずは、次の手順で一つの部屋に参加してみましょう。

1. トップ画面の「サインイン」を押します。
2. 通常の参加では「新規サインイン」を選び、名前を入力して「設定する」を押します。ソーシャルサインインを利用する場合は、TwitterまたはBlueskyのボタンから進みます。
3. 部屋一覧で説明と設定を確認し、「入室する」を押します。
4. パスワードを求められたら入力します。グループの選択画面が出た場合は、参加するグループを選びます。
5. 「回答フェーズ」でお題を読み、「回答する」から回答を送信します。
6. 「投票フェーズ」では、気に入った回答の「投票する」を押し、票数を決めて送信します。
7. 「結果フェーズ」で順位や票数を見ます。コメントできる部屋では、感想やリアクションも送れます。

部屋ごとに参加資格、時間、回答数、票数、名前を公開する時期が異なります。参加前に部屋の説明を読み、部屋上部の設定表示を確認してください。途中から入った場合は、その時点のフェーズで可能な操作から参加します。

## サインイン・名前・引き継ぎ

### 通常のサインイン

1. トップ画面で「サインイン」を押します。
2. 「新規サインイン」を押します。
3. 「名前を設定する」画面で名前を入力し、「設定する」を押します。
4. 確認画面が表示された場合は案内に従い、サインインの完了を待ちます。
5. トップ画面上部に自分の名前が表示されたことを確認します。

以前の名前が保存されていない場合、初期の名前は「お客さん」です。同じ名前で新規サインインしても、以前の利用者として復帰する操作にはなりません。以前の参加状態を引き継ぐには、サインオーバーなどを利用します。

### Twitter・Blueskyでのサインイン

「サインイン」画面の「ソーシャルサインイン」から選びます。画面上の名称は「Twitterでサインイン」「Blueskyでサインイン」です。

| 方法 | 操作 |
| --- | --- |
| Twitter | 「Twitterでサインイン」を押し、遷移先の認証画面で案内に従います。 |
| Bluesky | 「Blueskyでサインイン」を押し、ハンドルを入力して「サインイン」を押します。その後、認証画面で案内に従います。 |

Blueskyのハンドル欄には、例えば `alice.bsky.social` のように入力します。入力欄の前に「@」が表示されています。

「有り（ソーシャルサインイン）」という出題者・回答者・投票者制限がある部屋では、対応する方法でサインインしていることが参加条件になります。部屋内のプロフィールリンクを設定する操作と、ソーシャルサインインは別のものです。

### 名前を変更する

サインアウトせずに名前を変えられます。変更を始める場所によって対象が異なります。

| 変更を始める場所 | 対象と操作 |
| --- | --- |
| トップ画面上部の自分の名前 | サインインで使う名前を変更します。名前を押して入力し、「変更する」を押します。 |
| 部屋画面上部の自分の名前 | その部屋で使う名前とリンクを変更します。「名前やリンクを変更する」で設定し、「変更する」を押します。 |

すでに入室している部屋の名前を変えたい場合は、その部屋で操作してください。現在は、上部メニューに並ぶ「名前を変更する」という項目を探す必要はなく、**表示中の自分の名前自体が操作の入口**です。

### 部屋内のリンクを設定する

1. 部屋画面上部の自分の名前を押します。
2. 「リンク」で「無し」または「有り（URL）」を選びます。
3. 表示したい場合はURLを入力し、「変更する」を押します。
4. 「入室者を見る」で表示を確認します。

部屋内の名前を変更した場合や、名前にハッシュ値を付けた場合でも、リンクが自動的に非表示になるわけではありません。表示したくない場合は「無し」を選びます。

### 名前のハッシュ値とディスクリミネーター

名前に `名前#任意の文字列` と入力すると、「#」以降が8文字のハッシュ値に変換されて表示されます。ハッシュ値の計算には名前の部分も使われるため、同じ「#」以降の文字列でも、名前を変えると表示が変わります。

これとは別に、入室者には識別用の8文字の文字列である**ディスクリミネーター**があります。出題者・回答者・投票者などの表示されている名前を押すと、名前と識別文字列を切り替えられます。「入室者を見る」でも確認できます。

名前に自分で付けるハッシュ値と、入室者のディスクリミネーターは別のものです。どちらも、それ自体を入力してサインインを復元する機能ではありません。

### 別のブラウザーへ引き継ぐ：サインオーバー

スマートフォンからパソコンへ移るときなどに、同じサインイン状態を引き継げます。

1. 引き継ぎ元のトップ画面または部屋画面で「サインオーバー」を押します。
2. URLとQRコードの表示を待ちます。
3. 必要なら「URLをコピーする」を押します。
4. **1時間以内**に、引き継ぎ先のブラウザーでそのURLを開くか、QRコードを読み取ります。
5. 引き継ぎ先の確認画面で「サインイン」を押します。
6. 自分の名前と、参加する部屋での状態を確認します。

このURLとQRコードは、サインイン状態を引き継ぐためのものです。部屋を紹介するURLとして他の参加者に配布しないでください。部屋やグループの作成履歴は同じブラウザーに保存される情報であり、サインオーバーによる移行を前提にしないでください。

### サインアウト

トップ画面の「サインアウト」を押し、確認画面で「サインアウト」を押します。部屋画面からは、左上のサービス名を押してトップ画面へ戻れます。

確認画面には、**サインオーバーまたはソーシャルサインインをしていない場合、元のサインイン状態に戻れない**旨が表示されます。参加状態や自分が作成した部屋の管理を継続したい場合は、先に引き継ぎ方法を確保してください。

## 部屋を探す・入室する・退室する

### 部屋一覧を見る

トップ画面の「部屋一覧」には、部屋名、説明、作成者、作成日時、設定、入室者名などが表示されます。設定されている部屋ではアイコン画像も表示されます。

並べ替えのドロップダウンでは、次の表示順を選べます。

| 表示順 | 意味 |
| --- | --- |
| 作成順 | 新しく作成された部屋から表示します。 |
| 更新順 | 更新日時の新しい部屋から表示します。 |

部屋一覧の先頭にある手の形のボタンは**自入室フィルター**です。オンにすると、自分が入室している部屋だけを表示します。もう一度押すと解除します。一覧から部屋が消えたように見えたときは、このフィルターを確認してください。

### 入室する

1. 部屋名と説明を読み、参加したい部屋の「入室する」を押します。
2. 未サインインの場合は、表示される案内からサインインします。
3. 「部屋のパスワードを入力する」が表示されたら、主催者から案内されたパスワードを入力し、「入力する」を押します。
4. グループの選択を求められたら、主催者の案内に従って選びます。
5. 部屋上部で、自分の名前と現在のフェーズを確認します。

部屋のURLから直接開く場合も、サインインや入室制限の確認が必要です。パスワードが設定されていることと、部屋名や説明が一覧に表示されることは別なので、説明欄にパスワードを書き込まないようにします。

### 退室する

部屋画面上部の「退室する」を押し、確認画面でも「退室する」を押します。退室は、その部屋から出る操作です。サービス全体の「サインアウト」とは区別してください。

ブラウザーのタブを閉じたり、トップ画面を開いたりするだけで、明示的な退室操作をしたことにはなりません。また、退室しても、出題者・回答者・投票者として記録された名前が入室者の一覧などに残る場合があります。

## 部屋の画面と進行

### 上部メニュー

| 項目 | 用途 |
| --- | --- |
| メイン | 現在のお題と、回答・投票・結果を表示します。 |
| 過去の結果 | 終了した回を選んで見返します。 |
| ログ（CSV） | 記録をCSVとしてダウンロードします。 |
| 自分の名前 | 部屋内の名前とリンクを変更します。グループ名や獲得した🦄も近くに表示されます。 |
| サインオーバー | 別のブラウザーへの引き継ぎを始めます。 |
| 退室する | その部屋から退室します。 |
| カラースキームのボタン | オート・ライト・ダークを切り替えます。 |

部屋情報には各種設定が表示され、「グループを選択する」「入室者を見る」から参加者情報を確認できます。部屋作成者には、コメントや進行などの管理操作も表示されます。

### 一回のお題の流れ

**出題 → 回答フェーズ → 投票フェーズ → 結果フェーズ → 次の出題**という順で進みます。

| 状態 | 参加者の主な操作 | 部屋作成者の主な操作 |
| --- | --- | --- |
| 出題前 | 出題資格があれば「出題する」。まだお題がない場合は「出題はありません」と表示されます。 | 最初のお題を出す、出題資格を設定する。 |
| 回答フェーズ | 「回答する」。一斉表示の自分の未公開回答は変更・削除できます。 | 「回答を締め切る」。 |
| 投票フェーズ | 回答へ投票し、「投票を見る」で自分の票を確認します。 | 「投票を締め切る」。 |
| 結果フェーズ | 順位・得票・コメントを確認し、資格があれば次のお題を出します。 | 必要に応じて「出題優先を締め切る」。 |

回答と投票がどちらも「即時」の部屋では、回答フェーズ中にも公開された回答へ投票できます。「一斉」の部屋では公開時期や投票開始時期が異なります。詳しくは「部屋設定の詳しい説明」を参照してください。

時間制限がある場合は残り時間が表示されます。入力ダイアログを開いている間も時間は進みます。締切後の公開や集計の途中ではスピナーが表示されるため、結果が表示されるまで待ってください。

## 出題する

### 文章のお題

1. 出題前または結果フェーズで「出題する」を押します。
2. 必要に応じて「出典」を入力します。
3. 「出題」にお題の文章を入力します。
4. 内容を確認し、画面下の「出題する」を押します。
5. 回数、お題、出題者名が表示され、回答フェーズになったことを確認します。

お題は最大1,500文字、出典は最大150文字です。入力欄では改行できます。引用元や画像の由来を示したい場合は、出典欄に作品名や公開元などを記入します。

### 画像のお題

1. 出題画面の「画像有り」を押して画像を選びます。
2. プレビューを確認します。
3. 必要に応じてお題の文章と出典を入力します。
4. 「出題する」を押します。

添付をやり直すときは、プレビュー横の「削除する」を使います。画像の選択に伴って出典欄へ値が入る場合があるので、送信前に内容を確認してください。画像だけで文章を空欄にした場合は、本文に🖌️が補われます。

「出題画像制限」が「有り（禁止）」の部屋では画像を付けられません。出題画面に「画像有り」がない場合は、部屋の設定を確認してください。

### 次のお題を出せない場合

出題者として許可されていない場合や、出題優先時間中で自分が対象外の場合は出題できません。「有り（首位回答者）」の優先時間中は、対象の回答者名が明滅します。「出題する」ボタン自体は明滅しません。

出題後の文章や画像を編集・取り消す操作は、現在の出題画面にはありません。送信前にプレビューと本文を確認してください。

## 回答する

### 文章で回答する

1. 回答フェーズで、お題と出典を読みます。
2. 「回答する」を押します。
3. 「回答」に文章を入力します。
4. 画面下の「回答する」を押します。
5. 自分の回答が反映されたことを確認します。見つけにくいときは自回答フィルターを使います。

回答は最大1,500文字です。回答数制限がある部屋では、**一人が一つのお題に投稿できる回答数**が制限されます。例えば「2答」なら、その回に自分が投稿できるのは2回答までです。

一斉表示では、回答フェーズ中に他の人の回答が表示されなくても正常です。自分の回答は確認でき、他の人の回答は投票フェーズで公開されます。

### 手描きの回答

1. 回答画面で「描画有り」を押します。
2. 描画欄で、マウスやタッチ操作により線を描きます。
3. 必要に応じて、矢印ボタンで「元に戻す」「やり直す」を使います。
4. 文章を添える場合は「回答」に入力します。
5. 「回答する」を押します。

描画を付けない場合は「描画無し」に切り替えます。描画だけで文章が空欄の場合は、本文に🖊️が補われます。

描画の下にはデータ量の目安となる数値が表示されます。線を描きすぎて容量のエラーが出た場合は、元に戻す操作などで減らします。回答描画は最大1,500要素です。「回答描画制限」が「有り（禁止）」の場合は、この機能を使えません。

### 回答を変更・削除する

**回答表示が「一斉」で、回答がまだ締め切られていない場合**、自分の回答に「回答を変更する」「回答を削除する」が表示されます。

- 変更する場合：「回答を変更する」を押し、文章や描画を直して「回答する」を押します。
- 削除する場合：「回答を削除する」を押し、確認画面で削除します。

変更すると回答時刻も更新されます。先着順や同点時の順番、シャッフル対象となる時間を考える際は、この点に注意してください。

回答が即時表示の場合や、すでに回答を締め切った場合は、この変更・削除操作を利用できません。

## 投票する・投票を見直す

### 基本の投票

1. 投票できる回答の「投票する」を押します。
2. お題と回答を確認します。
3. 「＋」「−」で票数を調整します。
4. 画面下の「投票する」を押します。
5. 必要に応じて「投票を見る」で送信内容を確認します。

新しい投票では、増票できる場合は1票から始まります。制限の状況によっては0票が初期値になるため、送信前に表示された票数を確認してください。変更画面では既存の票数から調整します。

票数は0以上の整数です。出題毎の上限と回答毎の上限がある場合、両方を満たす範囲で投票します。

### 票数制限の例

「投票数制限（出題毎）」が5票、「投票数制限（回答毎）」が2票の場合、例えば、ある回答へ2票、別の回答へ2票、さらに別の回答へ1票という配分ができます。合計は5票以内で、同じ回答への合計は2票以内です。

出題毎の上限に達すると、新しい投票の入口が「投票を見る」に変わる場合があります。投票表示が一斉で、まだ受付中なら、投票一覧から既存の票を減らしたり削除したりして配分を見直せます。

「有り（超過可）」では、投票画面内で出題毎の上限を超える票数を指定できます。ただし、上限に達した後のボタン表示は変わり、回答毎の上限も引き続き適用されます。「超過可」を、すべての票数制限がなくなる設定と考えないでください。

### 0票クイック投票

回答の「投票する」の近くにある、親指のアイコンと「0」のボタンを押すと、**その回答へ0票を直接送信**します。通常の投票画面で0票にして送ることもできます。

0票も投票の記録として扱われますが、得票数は増えません。0票だけでは、首位回答者の出題優先を得るための正の投票量にもなりません。

### 自分の投票を見る

投票フェーズでは、回答一覧上部の「投票を見る」から自分が投票した回答を確認できます。合計票数の横には、設定されている出題毎の上限も表示されます。まだ投票していない場合は、上部のボタンを押せません。

投票先ごとに票数を確認し、合計が意図した配分になっているか見直してください。

### 投票を変更・削除する

投票表示が「一斉」で、対象の投票がまだ受付中の場合は、「投票を変更する」「投票を削除する」を使えます。

1. 対象の回答、または「投票を見る」を開きます。
2. 「投票を変更する」を押します。
3. 「＋」「−」で票数を変え、「投票する」を押します。
4. 記録そのものを取り消す場合は「投票を削除する」を押します。

票を減らすために一度削除する必要はありません。0票への変更と削除は、記録が残るかどうかが異なります。

即時表示の投票には変更・削除のボタンが表示されません。追加投票ができる場合でも、すでに送信した票を減らす操作とは異なるため、毎回票数を確認してください。締切後も投票は変更できません。

### 投票できる時間

投票表示が「一斉」の場合、投票は投票フェーズから開始します。回答・投票の両方が「即時」の場合は、公開された回答ごとに投票でき、時間制限も回答の投稿時刻を基準にする場合があります。

部屋全体のタイマーだけでなく、回答や投票画面のタイマーも確認してください。別の回答には投票できても、早く投稿された回答への投票は締め切られていることがあります。

## 結果・順位・ユニコーン

### 結果の見方

投票の締切後、集計が終わると「結果フェーズ」になります。各回答には順位、得票数、設定に応じた回答者名・投票者名、グループ名、コメントなどが表示されます。

回答に付いた投票は、票数の多いものから表示されます。票数が同じ場合は投票順です。匿名設定がある場合は、名前が表示されないことがあります。

順位は、まず得票数の多さで決まり、同じ得票数なら回答者の投票量に基づく補正値、さらに同じなら回答の早さが優先されます。回答者自身の回答数も補正の計算に関係するので、得票数が同じ回答が並んだ場合に、表示上の票数だけで順位を判断しないでください。

### Zスコアと記号

ユニコーンなどの表示には、回答者の投票量を考慮した**補正得票数のZスコア**が使われます。同じ回の回答全体と比べた位置を表す値です。

`Zスコア =（その回答の補正得票数 − 同じ回の平均）÷ 同じ回の標準偏差`

標準偏差が0の場合、画面上のZスコアは0になります。順位の表示を押すと小数値を確認でき、もう一度押すと順位表示に戻ります。

| Zスコア | 表示 |
| --- | --- |
| 1以上 | 順位に下線状の表示が付きます。 |
| 2以上 | 🦄が1個付きます。3以上で2個、4以上で3個と増えます。 |
| −1以下 | 順位に上線状の表示が付きます。 |
| −2以下 | 🍦が1個付きます。−3以下で2個、−4以下で3個と増えます。 |

🦄は単に「1位になった回数」を表すものではありません。その部屋で獲得した累計は、「入室者を見る」と部屋画面上部の自分の名前付近で確認できます。

### 名前の表示について

「回答者名表示」「投票者名表示」は、回答本文や票数の公開設定とは別です。「非表示」なら結果でも名前を隠し、「一斉（結果フェーズまで非表示）」なら結果で公開します。

現在の回では、自分の回答者名や自分の投票者名は、匿名の設定でも自分から確認できます。公開されていない他の人の名前が、自分の画面だけに表示されるという意味ではありません。

## 並べ替えとフィルター

### 回答を並べ替える

回答一覧の上部にあるドロップダウンで選びます。並べ替えは自分の表示に適用され、確定した順位を書き換える操作ではありません。

| 表示順 | 内容 | 利用できる場面 |
| --- | --- | --- |
| 設定順 | 部屋設定とフェーズに従う順番。結果では順位順です。 | 各フェーズ・過去の結果 |
| 先着順 | 回答が早い順。 | 各フェーズ・過去の結果 |
| 後着順 | 回答が遅い順。 | 各フェーズ・過去の結果 |
| 上位順 | 得票などの順位基準で上位から。 | 各フェーズ・過去の結果 |
| 下位順 | 上位順の逆。 | 各フェーズ・過去の結果 |
| 多コ順 | コメントの多い順。 | 結果・過去の結果 |
| 少コ順 | コメントの少ない順。 | 結果・過去の結果 |

結果が出る前の上位順・下位順は、画面で取得できる票の情報に基づきます。一斉投票で未公開の票まで含めた最終順位が先に分かるわけではありません。

### 自分に関係する回答を絞る

| フィルター | 目印 | 表示するもの |
| --- | --- | --- |
| 自回答 | 開いた手のアイコン | 自分の回答。回答フェーズから使えます。 |
| 自投票 | 親指を立てたアイコン | 自分が投票した回答。投票フェーズ以降で使えます。 |
| 自コメント | 指差しのアイコン | 自分が回答コメントを付けた回答。結果・過去の結果で使えます。 |

オンになっているボタンをもう一度押すと解除できます。自回答・自投票・自コメントは、三つを同時に重ねるのではなく、主となるフィルターを一つ選びます。

回答フェーズの自回答ボタンには自分の回答数、投票フェーズの自投票ボタンには自分の投票数が表示されます。フィルターのボタンは、下へスクロールしても使いやすい位置に表示されます。

### グループフィルターと回答ピックアップ

結果と過去の結果では、さらに次の絞り込みを使えます。

- **グループフィルター**：回答に付いたグループ名を押すと、そのグループの回答を表示します。
- **回答ピックアップ**：回答の目のアイコンを押すと、その回答だけを表示します。

これらは、自回答・自投票・自コメントのいずれかと組み合わせられます。例えば自投票フィルターをオンにしてからグループ名を押すと、「自分が投票した、そのグループの回答」を見られます。

グループフィルターと回答ピックアップは、追加の絞り込みとして一つを使います。追加の絞り込み中に対応するグループ名や目のアイコンを押すと解除されます。別の対象を選びたい場合は、解除してから選び直します。主となる自回答・自投票・自コメントを切り替えると、この追加の絞り込みは解除されます。

### 一つの回答の投票だけを絞る

回答カード内の**得票数と親指のアイコン**を押すと、その回答に付いた投票のうち自分の投票だけを表示します。もう一度押すと戻ります。

これは「自分が投票した回答を一覧に残す」自投票フィルターとは別の操作です。表示する投票の内訳を絞る機能であり、回答自体の得票数は変わりません。

## コメントとリアクション

### 三種類のコメント

| 種類 | 投稿できる人・時期 | 削除 |
| --- | --- | --- |
| 部屋コメント | 部屋作成者が随時投稿できます。部屋上部のお知らせに使います。 | 部屋作成者が最新の1件ずつ削除できます。 |
| 出題コメント | 結果フェーズで、設定により許可された人が投稿できます。 | 投稿後の削除操作はありません。 |
| 回答コメント | メインの結果フェーズで、設定により許可された人が回答に投稿できます。 | 投稿後の削除操作はありません。 |

コメントは最大150文字です。空のコメントも送信できるため、送信前に本文を確認してください。回答や投票をしていない参加者でも、コメント制限に該当しなければコメントできます。

### コメントする

1. お題全体への感想なら出題側、特定の回答への感想ならその回答の「コメントする」を押します。
2. コメントを入力します。
3. 画面下の「コメントする」で確定し、表示を確認します。

「出題コメント制限」「回答コメント制限」が「有り（部屋作成者）」の場合、それぞれ部屋作成者だけが投稿できます。

### クイックコメント

「コメントする」の横にあるスマイルのボタンを押し、絵文字を選ぶと、その絵文字がコメントとして送信されます。出題コメントと回答コメントの両方で利用できます。

対象バージョンの選択肢は、😂・🤣・🥰・😅・🥺・😭・😱・😡・🫡です。絵文字を選ぶと投稿されるので、選択前に対象のお題・回答を確認してください。リアクションもコメント制限の対象です。

## 部屋を作成する

### 作成の手順

1. サインインし、トップ画面の「部屋を作成する」を押します。
2. 部屋名を入力します。
3. 説明に開催方法、参加条件、時間、票の配分などを書きます。
4. 必要に応じてアイコン画像、カラースキーム、入室パスワードを設定します。
5. 出題・回答・投票の設定を確認します。
6. 画面下の「部屋を作成する」を押します。
7. 作成した部屋に入り、表示されている設定を確認してから参加者を案内します。

設定の履歴がない状態では、基本的に各制限は「無し」、回答と投票は「即時」、名前は「表示」です。ただし、**同じブラウザーで以前に作成した設定が初期値として読み込まれる**ため、毎回表示を確認してください。

現在の画面には、作成済みの部屋について作成フォームを開き直してルールを編集する操作はありません。回答時間や票数などを変えて開催し直す場合は、履歴を利用して新しい部屋を作成します。作成後も操作できる参加者の権限、グループ、部屋コメントとは区別してください。

### 作成履歴を利用する

1. 部屋作成画面で、部屋名の横の「履歴を見る」を押します。
2. 使用したい履歴の「読み込む」を押します。
3. 設定、説明、画像などを確認し、必要な項目を変えます。
4. 「部屋を作成する」を押します。

履歴は同じブラウザーで作成した部屋の設定です。同じ部屋名で作成した場合、履歴には最新の設定だけが残ります。「削除する」は、その履歴を消す操作であり、公開中の部屋を削除する操作とは別です。

### 未出題の部屋数

通常のサインインでは、未出題の部屋の作成は一つまでに制限されます。作成ボタンを使えない場合は、自分が作成した未出題の部屋がないか確認します。ソーシャルサインインでは、未出題の部屋を複数作成できます。

## 部屋設定の詳しい説明

### 基本情報

| 項目 | 内容 |
| --- | --- |
| 部屋名 | 部屋一覧と部屋画面に表示する名前。最大150文字です。 |
| 説明 | 開催案内やルール。最大1,500文字で、改行できます。文章中のURLはリンクになります。 |
| アイコン画像 | 部屋一覧や部屋画面に表示する画像。容量制限があるため、エラー時は画像を小さくするか簡略化します。 |
| カラースキーム | 「無し」「ライト」「ダーク」。部屋の初期表示を設定します。 |
| 入室制限 | 「無し」または「有り（パスワード）」。パスワードは空白を含まない1〜15文字です。 |

### 出題に関する設定

| 項目 | 選択肢と意味 |
| --- | --- |
| 出題優先時間 | 「無し」「有り（部屋作成者）（秒）」「有り（首位回答者）（秒）」。結果が出てから指定時間の間、次の出題を優先できる人を決めます。 |
| 出題者制限（初期値） | 「無し」「有り」「有り（ソーシャルサインイン）」。出題できる人を制限します。 |
| 出題画像制限 | 「無し」なら画像付きのお題を使用できます。「有り（禁止）」なら使用できません。 |
| 出題コメント制限 | 「無し」なら参加者が出題にコメントできます。「有り（部屋作成者）」なら部屋作成者だけが投稿できます。 |

「有り（首位回答者）」の出題優先は、**前回の回答者のうち、正の投票量による補正がある人の最上位回答**が対象です。単に全体の1位を無条件に優先する設定ではありません。対象の回答者名が明滅します。対象となる回答がない場合には、首位回答者による優先制限はかかりません。

「有り（部屋作成者）」では、優先時間中は部屋作成者が次の出題を行えます。いずれの場合も出題者制限は別に適用されるので、優先対象者が出題資格を持つよう設定してください。部屋作成者は「出題優先を締め切る」で優先期間を途中終了できます。

### 回答に関する設定

| 項目 | 選択肢と意味 |
| --- | --- |
| 回答表示 | 「即時」は投稿した回答をその都度公開します。「一斉（投票フェーズまで非表示）」は、他の人の回答を投票フェーズまで公開しません。 |
| 回答時間制限 | 「無し」なら手動で締め切ります。「有り（秒）」なら出題から指定時間で回答を締め切ります。 |
| 回答シャッフル時間 | 「無し」または「有り（秒）」。指定時間内に投稿された回答を、投票時に参加者ごとにランダムな順番で表示します。 |
| 回答数制限 | 一人が一つのお題に出せる回答数。「無し」または「有り（答）」です。 |
| 回答者名表示 | 「表示」「非表示」「一斉（結果フェーズまで非表示）」。本文の公開時期とは独立しています。 |
| 回答者制限（初期値） | 「無し」「有り」「有り（ソーシャルサインイン）」。 |
| 回答コメント制限 | 「無し」または「有り（部屋作成者）」。 |
| 回答描画制限 | 「無し」なら手描き回答を使用できます。「有り（禁止）」なら使用できません。 |

**回答シャッフル時間**は、回答を禁止して待たせる時間ではありません。例えば30秒なら、出題からその時間内に投稿された回答がシャッフル対象になります。「有り」で秒数を空欄にすると、全回答が対象です。表示上は「∞」になります。

シャッフルは「設定順」での投票時の表示に使われ、結果の順位は通常の集計で決まります。明示的に「先着順」などを選んだ場合は、その表示順が使われます。

### 投票に関する設定

| 項目 | 選択肢と意味 |
| --- | --- |
| 投票表示 | 「即時」は票をその都度公開します。「一斉（結果フェーズまで非表示）」は結果まで他の人の票を公開しません。 |
| 投票時間制限 | 「無し」または「有り（出題毎+回答毎×）（秒）」。基本時間と回答数に比例する追加時間を指定します。 |
| 投票数制限（出題毎） | 一人が一つのお題に投じる合計票数。「無し」「有り（票）」「有り（超過可）（票）」です。 |
| 投票数制限（回答毎） | 一人が一つの回答に投じる合計票数。「無し」または「有り（票）」です。 |
| 投票者名表示 | 「表示」「非表示」「一斉（結果フェーズまで非表示）」。票数の公開時期とは独立しています。 |
| 投票者制限（初期値） | 「無し」「有り」「有り（ソーシャルサインイン）」。 |
| 投票グループ制限 | 「無し」「有り（自グループに投票）」「有り（次グループに投票）」。投票時に表示する回答のグループを指定します。 |

投票時間は次の式で計算します。

`投票時間 = 出題毎の秒数 + 回答毎の秒数 × 対象の回答数`

例えば「出題毎60秒」「回答毎3秒」で対象の回答数が20なら、投票時間は120秒です。回答毎の追加時間を空欄にした場合は、追加がありません。回答毎の秒数には小数第1位まで入力できます。

投票グループ制限を使い、グループを作成している場合は、全体の回答数ではなく、表示対象となる回答が最も多いグループの回答数を時間計算に使います。グループごとに別々の長さで締め切る設定ではありません。

### 回答表示と投票表示の組み合わせ

| 回答表示 | 投票表示 | 公開・投票の進み方 |
| --- | --- | --- |
| 即時 | 即時 | 回答を投稿すると公開され、その回答に投票できます。票も即時に公開されます。時間制限がある場合、個々の回答への投票時間は回答の投稿時刻を基準にします。 |
| 即時 | 一斉 | 回答は随時公開されますが、投票は投票フェーズからです。他の人の票は結果で公開されます。 |
| 一斉 | 即時 | 回答は投票フェーズでまとめて公開されます。その後の票は随時公開されます。 |
| 一斉 | 一斉 | 回答は投票フェーズ、票は結果フェーズでまとめて公開されます。 |

いずれの場合も、部屋全体の投票フェーズが終了すると投票は締め切られます。回答も投票も即時の場合は、回答ごとの受付終了と部屋全体の終了の両方に注意してください。

### 出題者・回答者・投票者制限の「有り」

三種類の制限は、それぞれ独立しています。

| 初期値 | 対象者を個別指定していないときの扱い |
| --- | --- |
| 無し | その操作についてサインイン方法による制限を設けません。 |
| 有り | 初期状態ではその操作を許可せず、部屋作成者が「入室者を見る」で対象者を追加して運用します。 |
| 有り（ソーシャルサインイン） | ソーシャルサインインしている参加者を対象にします。 |

「入室者を見る」で出題者などを個別指定すると、その種類の操作については指定された利用者の一覧が優先されます。例えば、出題者だけを主催者に指定し、回答者と投票者は制限しない運用ができます。

個別指定を全員分解除した場合は、初期値に応じた扱いに戻るため、初期値が「有り」なら誰も操作できない状態になり得ます。対象者の名前と設定表示を併せて確認してください。

### 開催例：時間を区切る一斉大喜利

次は、設定の組み合わせを理解するための例です。

| 項目 | 設定例 |
| --- | --- |
| 回答表示 | 一斉 |
| 回答時間制限 | 180秒 |
| 回答数制限 | 2答 |
| 回答者名表示 | 一斉 |
| 投票表示 | 一斉 |
| 投票時間制限 | 出題毎60秒＋回答毎3秒 |
| 投票数制限（出題毎） | 5票、超過不可 |
| 投票数制限（回答毎） | 2票 |
| 投票者名表示 | 一斉 |

この例では、参加者は3分間で最大2回答を投稿し、公開後に合計5票までを配分します。回答が20件なら投票時間は2分です。結果フェーズで名前と票が公開されます。主催者だけが出題する会にしたい場合は、出題者の個別指定も行います。

## グループを使う

### グループを作成する：部屋作成者

1. 部屋の「グループを選択する」を押します。
2. 「グループを作成する」を押します。
3. グループ名と、必要に応じて説明を入力します。
4. 作成を確定します。
5. 必要なグループ数だけ繰り返します。

グループ名は最大20文字、説明は最大1,500文字です。グループ一覧には説明、人数、参加者名が表示されます。部屋作成者は各グループの「グループを削除する」から削除できます。

### グループを選ぶ：参加者

1. 「グループを選択する」を開きます。
2. 希望するグループのラジオボタンを選びます。
3. 選択の反映を待ち、上部の自分の名前付近に表示されたグループ名を確認します。
4. 「閉じる」で戻ります。

グループの選択は、その場で反映されます。別途「選択する」ボタンを押す操作はありません。参加者は後から同じ画面を開いてグループを変更できますが、大会などでは主催者の割り当てに従ってください。

グループが追加されたときに所属していない人、新しく入室した人、所属先が削除された人には、選択画面が表示されます。現在は初期グループを指定して自動配属する設定はありません。回答には投稿時のグループが記録されるので、回答前に所属を確認します。

### 自グループ・次グループへの投票

投票グループ制限がある場合、投票フェーズの回答一覧は次のようになります。

| 設定 | 表示する回答 |
| --- | --- |
| 無し | 投票グループによる絞り込みを行いません。 |
| 有り（自グループに投票） | 自分と同じグループの回答を表示します。 |
| 有り（次グループに投票） | 自分のグループの直後に作成されたグループの回答を表示します。最後のグループからは最初のグループへ循環します。 |

例えば、A、B、Cの順にグループを作成した場合、「次グループに投票」は **Aの人はBへ、Bの人はCへ、Cの人はAへ**という関係になります。グループ名の五十音順ではなく、作成順で決まります。

次グループへの投票で、グループを選んでいない参加者には、グループ未選択の回答が表示されます。グループを一つも作成していなければ、投票グループ制限を設定していてもグループによる絞り込みは働きません。

結果フェーズでは全体の結果を確認でき、必要なら回答に付いたグループ名で絞り込みます。投票時のグループ制限と、結果表示のグループフィルターは別の機能です。

### グループの履歴

グループ作成画面の「履歴を見る」から、同じブラウザーで作成したグループの設定を読み込めます。同じグループ名の場合は最新の設定だけが保存されます。履歴の削除と、部屋内で運用しているグループの削除は別の操作です。

## 主催者の進行と入室者管理

### 回答・投票を手動で締め切る

時間制限がなくても、部屋作成者はフェーズを進められます。

1. 回答フェーズで「回答を締め切る」を押します。
2. 確認画面で「締め切る」を押します。
3. 回答の公開が完了し、投票フェーズになるのを待ちます。
4. 投票を終了するときは「投票を締め切る」を押します。
5. 確認画面で「締め切る」を押し、結果を待ちます。

時間制限を設定した場合でも、部屋作成者は手動で締め切れます。出題した人が部屋作成者とは限らないため、出題者というだけで締切操作ができるわけではありません。

締め切ったフェーズを再開するボタンはありません。予定より早く締め切る際は、参加者の状況を確認してください。

### 入室者の一覧と並べ替え

「入室者を見る」を押すと、名前、プロフィール情報、識別文字列、ユニコーン数などを確認できます。一覧には、退室済みでも出題者・回答者・投票者などに指定されている人が含まれる場合があります。

| 表示順 | 基準 |
| --- | --- |
| 先入順・後入順 | 入室日時が古い順・新しい順。 |
| 多🦄順・少🦄順 | ユニコーン獲得数が多い順・少ない順。 |
| 昇名順・降名順 | 名前の文字コード順・その逆順。読み仮名の五十音順とは限りません。 |
| 昇Di順・降Di順 | ディスクリミネーターの文字コード順・その逆順。 |
| 古サ順・新サ順 | サインイン日時が古い順・新しい順。 |

### 出題者・回答者・投票者を指定する

1. 部屋作成者として「入室者を見る」を開きます。
2. 対象者の名前とディスクリミネーターを確認します。
3. 「出題者へ追加する」「回答者へ追加する」「投票者へ追加する」のうち必要な操作を押します。
4. 部屋の設定表示と対象者の操作可否を確認します。
5. 指定を外すときは、それぞれの「〜から削除する」を押します。

スマートフォンなどの狭い画面では、管理ボタン群を開閉する操作が必要な場合があります。部屋作成者自身を出題者に限定したい場合も、この一覧で指定します。

### 受刑者の指定と解除

迷惑行為への対応などで、部屋作成者は対象者を「受刑者へ追加する」ことができます。追加された人は強制退室となり、参加が制限されます。一覧では取り消し線付きで表示されます。

解除する場合は「受刑者から削除する」を使います。この機能には同じ発信元の関連利用者にも制限が及ぶ仕組みがあるため、単に一時的な出題資格や回答資格を外す目的には、それぞれの役割の削除を使ってください。

### 部屋コメントで案内する

部屋上部の「コメントする」から、開始時刻や次の回の案内などを投稿できます。「コメントを削除する」は最新の部屋コメント1件を削除します。複数の古いコメントを整理するときは、削除対象を確認しながら一件ずつ操作します。

### 部屋を削除する

1. 必要な記録を「ログ（CSV）」で保存します。
2. トップ画面の部屋一覧に戻ります。
3. 自分の部屋の「部屋を削除する」を押します。
4. 確認画面で部屋名を確認し、「削除する」を押します。

部屋の削除を取り消す画面はありません。単に参加を終えるときは退室、設定を再利用したいときは作成履歴を使います。

## 過去の結果とCSV保存

### 過去の結果を読む

1. 部屋上部の「過去の結果」を押します。
2. 回数の番号を選びます。多くの回がある場合は、回数の範囲を選んでから目的の回へ進みます。
3. お題、出典、順位、回答、票、コメントを確認します。
4. 並べ替えや自回答・自投票・自コメント、グループフィルター、回答ピックアップで見やすくします。

最初は、直近の終了した回が表示対象になります。現在進行中で結果が出ていない回は「メイン」で確認します。「過去の結果」は閲覧用で、この画面から出題・回答に新しいコメントやリアクションを追加することはできません。匿名のまま公開されている過去のデータでは、利用者を特定する情報がないため、自回答・自投票フィルターで拾えない場合があります。

### CSVをダウンロードする

1. 記録を保存したい部屋へ入室します。
2. 上部の「ログ（CSV）」を押します。
3. 必要なら「ディスクリミネーター付き」を選びます。
4. 表示されたダウンロード用URLを押します。
5. 処理の完了を待ち、ブラウザーでダウンロードされた記録を確認します。

画面を開くだけではダウンロードは始まりません。URLを押す操作が必要です。処理中はスピナーが表示されます。

### CSVの内容

CSVには見出し行がなく、通常は一つの回答が一行になります。回答がない回では、お題の情報だけの行になります。

| 列 | 内容 |
| --- | --- |
| 1 | 部屋名 |
| 2 | 回数 |
| 3 | 出題者名 |
| 4 | お題。出典がある場合は、出典と改行に続いて本文が入ります。 |
| 5 | 回答の順位 |
| 6 | 回答者名 |
| 7 | 回答本文 |
| 8 | 得票数 |
| 9 | グループ名 |
| 10以降 | 投票者名と票数の組が、投票ごとに続きます。 |

投票件数により列数が変わります。CSVにはお題の画像、回答の線画そのもの、コメント本文は含まれません。これらも残したい場合は、別途表示内容を保存してください。

「ディスクリミネーター付き」では、名前と識別文字列が**同じ項目内で改行区切り**になります。名前にハッシュ値がある場合も、その後に別の識別文字列が付きます。文字コードはUTF-8で、改行を含む項目もあるため、表計算ソフトなどのCSV取り込み機能で開くと扱いやすくなります。

### 保存期間

更新情報では、**部屋の存続時間は最終更新から11.5日間**、**過去の結果とCSVの対象は34.5日以内の出題**と案内されています。部屋自体が削除された場合は、その部屋からの閲覧や保存を続けられません。

履歴を長期保管するサービスとしては扱わず、開催終了後など、必要な記録を閲覧できるうちに保存してください。作成フォームの履歴には設定が保存されるのであって、回答や投票の記録が保存されるわけではありません。

## 表示・キーボード操作・入力上限

### 長いお題や回答を展開する

長いお題や回答は、150文字や10行を超える位置で折りたたまれます。本文の途中にある四角い「＋」のボタンと残りの文字数を押すと、続きを表示できます。展開後に「−」側のボタンを押すと折りたたみます。

数字は得点ではなく、隠れている本文の残り文字数です。文章の一部がないように見える場合は、展開して確認してください。複数行の入力欄は、入力した行数に合わせて高さが伸びます。

### カラースキーム

部屋上部の太陽・月などのボタンから選びます。

| 選択 | 表示 |
| --- | --- |
| オート | ブラウザーやOSの明暗設定に従います。 |
| ライト | 明るい配色になります。 |
| ダーク | 暗い配色になります。 |

この場で選んだ表示は保存されません。部屋作成時に指定するカラースキームは、その部屋の初期設定です。出題画像の背景には、ダーク表示でも白い背景が使われます。

### キーボード操作

| 場所 | キー | 動作 |
| --- | --- | --- |
| 出題・回答の本文入力欄 | Enter | 改行します。 |
| 出題・回答の本文入力欄 | Ctrl＋Enter | 入力を送信します。 |
| 出題・回答の本文入力欄 | Command＋Enter、またはWindowsキー＋Enter | 入力を送信します。 |
| 投票数の操作部分にフォーカスがあるとき | Space | 1票増やします。 |
| 投票数の操作部分にフォーカスがあるとき | Delete | 1票減らします。0票より小さくはなりません。 |
| 投票数の操作部分にフォーカスがあるとき | Enter | 投票を送信します。 |
| ダイアログ | Esc | ダイアログを閉じます。送信処理中などは閉じられない場合があります。 |

投票画面を開くと、票数の操作部分に最初のフォーカスが置かれます。別のボタンなどへ移動した場合、キーの動作対象も変わります。送信のショートカットは確認用の操作ではなく、そのまま送信する操作です。

### 主な入力上限

| 項目 | 上限・条件 |
| --- | --- |
| サインイン名・部屋内の名前 | 1〜20文字。先頭・末尾の空白は避けます。 |
| グループ名 | 1〜20文字。先頭・末尾の空白は避けます。 |
| 部屋名 | 1〜150文字。 |
| 部屋・グループの説明 | 最大1,500文字。 |
| 出題本文・回答本文 | 最大1,500文字。画像・描画を付けない場合、本文が必要です。 |
| 出典 | 最大150文字。 |
| コメント | 最大150文字。空欄も送信できます。 |
| 部屋内のリンク | 最大150文字。有効なWebのURLを指定します。 |
| 入室パスワード | 空白を含まない1〜15文字。 |
| 回答描画 | 最大1,500要素。文字数や線の本数とは異なります。 |
| アイコン画像 | 容量制限があります。画面のエラー表示で確認します。 |

絵文字などは見た目の一文字と入力欄の数え方が一致しない場合があります。上限付近でエラーが出た場合は、少し短くして確認してください。

## 困ったとき

### 操作ボタンがない・押せない

| 症状 | 確認すること |
| --- | --- |
| 部屋が一覧に出ない | 自入室フィルターがオンでないか、部屋が削除されていないかを確認します。 |
| 入室できない | サインイン状態、パスワード、参加制限を確認します。 |
| 部屋を作成できない | 通常サインインで、未出題の自分の部屋がすでにないか確認します。 |
| 出題できない | 出題者の制限、現在のフェーズ、出題優先時間の対象者を確認します。 |
| 回答できない | 回答フェーズか、回答者に許可されているか、回答数の上限や締切に達していないか確認します。 |
| 回答を変更できない | 一斉表示の未公開回答か確認します。即時表示や締切後には変更できません。 |
| 投票できない | 投票開始前・締切後でないか、投票者の制限、出題毎・回答毎の票数上限を確認します。 |
| 「投票する」が「投票を見る」になった | 出題毎の票数上限に達していないか確認します。一斉投票なら受付中に配分を見直せます。 |
| 投票を変更・削除できない | 投票表示が一斉か、受付中かを確認します。即時表示では変更・削除できません。 |
| コメントできない | 結果が公開されているか、部屋作成者だけに制限されていないか確認します。 |
| 画像・描画のボタンがない | 出題画像制限・回答描画制限を確認します。 |

### 表示が予想と違う

| 症状 | 確認すること |
| --- | --- |
| 他の人の回答が見えない | 回答表示が一斉、投票グループ制限、自回答フィルターなどのいずれかが適用されていないか確認します。 |
| 投票フェーズで特定グループしか見えない | 自グループ・次グループへの投票設定と、自分の所属を確認します。 |
| 回答が一つだけになった | 目のアイコンによる回答ピックアップを解除します。 |
| 自分の投票しか見えない | 一斉投票の公開前でないか、回答の得票数を押して自投票だけに絞っていないか確認します。 |
| 名前が表示されない | 回答者名・投票者名の表示設定を確認します。 |
| 名前が英数字の文字列になった | 名前を押してディスクリミネーター表示へ切り替わっていないか確認します。もう一度押すと戻ります。 |
| お題や回答の途中が見えない | 四角い「＋」と残り文字数のボタンで展開します。 |
| 自分と他の人で回答順が違う | 回答シャッフルや各自の並べ替え設定を確認します。 |
| 1位なのに🦄がない | 🦄は順位ではなく、補正得票数のZスコアが基準です。 |
| 古い結果が見つからない | 回数の選択、保存対象期間、部屋の存続を確認します。 |

### 入力エラー・通信待ち

入力欄の下に日本語のエラーが表示された場合は、その項目の文字数や形式を直します。画像について容量や読み込みのエラーが出た場合は、小さい画像やブラウザーで読み込める別の画像で確認します。

送信中はボタンにスピナーが重なります。繰り返し押さず、完了またはエラー表示を待ちます。応答が戻らない場合は接続状態を確認し、再読込する前に入力途中の文章を控えてください。再読込後に回答や票が反映済みか確認してから、再送信を判断します。

CSVのタイムアウトが表示された場合も、先にブラウザーのダウンロード状況を確認し、部屋への入室状態を確認してから再試行します。

### 案内・問い合わせ先

トップ画面の「全更新情報を見る」で、過去の更新内容を確認できます。「使用方法」にはユーザーマニュアルとGitHubのディスカッションへの入口があります。質問や提案には、どの画面で何を操作し、どうなったか、部屋の表示設定やエラーメッセージを添えると状況が伝わりやすくなります。
