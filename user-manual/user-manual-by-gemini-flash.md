## 1. はじめに

### 1.1 bǃgǃrǃ とは
**bǃgǃrǃ（ビギリ）** は、リアルタイムで大喜利の出題・回答・投票・結果発表・コミュニケーションを行うことができるWebベースの大喜利プラットフォームです。

キャッチコピーは **"For Beautiful Oogiri Life"** 。

PC、タブレット、スマートフォンなどあらゆる端末のWebブラウザから特別なアプリのインストール不要でアクセスでき、プライベートな小規模ルームから多数の参加者が集まる大会形式の大規模ルームまで、柔軟かつ高度なルール設定に対応しています。

### 1.2 基本理念とライセンス方針
bǃgǃrǃ で投稿された作品（出題、回答、コメント等）は、各部屋内で個別に別段の定めがない限り、国際的なオープンライセンスである **Creative Commons Attribution 4.0 International (CC BY 4.0)** の下でライセンスされます。これにより、作者のクレジット表示を行うことで、二次利用や記録の共有が円滑に行える環境が整備されています。

## 3. アカウントとサインイン（認証システム）

bǃgǃrǃ では、匿名での気軽な参加からソーシャルアカウントと連携した確実な本人確認まで、用途に応じた複数のサインイン方法が提供されています。

```
                    ┌─────────────────────────┐
                    │      サインイン方法     │
                    └────────────┬────────────┘
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   新規サインイン │     │ Twitter (X) 連携 │     │  Bluesky 連携   │
│ (通常サインイン) │     │                 │     │  (AT Protocol)  │
└────────┬────────┘     └────────┬────────┘     └────────┬────────┘
         │                       │                       │
         └───────────────────────┼───────────────────────┘
                                 ▼
                    ┌─────────────────────────┐
                    │  ユーザー識別子生成     │
                    │  (8文字英数字 トークン) │
                    └────────────┬────────────┘
                                 ▼
                    ┌─────────────────────────┐
                    │  サインオーバー機能     │
                    │  (他端末へのセッション  │
                    │   1時間限定引き継ぎ)    │
                    └─────────────────────────┘
```

### 3.1 通常サインインと「新規サインイン」
トップ画面右上のメニュー、または部屋入室時のモーダルから「サインイン」を選択します。
- **新規サインイン:**
  - ボタンスタイル化された「新規サインイン」ボタンをクリックすると、名前設定フォームが開きます。
  - 任意の表示名を入力して登録します（初期値は「お客さん」などのデフォルト名が適用されます）。
  - スパム防止のため、自動的にバックグラウンドで認証チェック（reCAPTCHA）が行われます。

### 3.2 ソーシャルサインイン（Twitter/X, Bluesky）
外部ソーシャルメディアアカウントを利用してサインインできます。ソーシャルサインイン済みのユーザーは、入室制限や出題・回答・投票制限で「ソーシャルサインイン限定」が設定されている部屋にも参加できます。

1. **Twitter (X) でサインイン:**
   - ボタンをクリックするとOAuth連携画面へ遷移し、認証完了後に元の画面へ戻ります。
   - プロフィール画像およびTwitterプロフィールへのリンクアイコンが表示されるようになります。
2. **Bluesky でサインイン:**
   - AT Protocolを採用する分散型SNS「Bluesky」のアカウント（ハンドル名: 例 `user.bsky.social`、またはカスタムドメイン）とアプリパスワード（App Password）を入力して認証します。
   - Blueskyのプロフィールアイコンとリンクが表示されるようになります。

### 3.3 表示名・識別子（ディスクリミネーター）・名前ハッシュ機能

- **表示名 (DisplayName):**
  - 画面上に表示される名前です。全角・半角を含む任意の文字列が設定可能です。
- **識別子 (Discriminator / トークン):**
  - アカウントごとに内部で割り振られる8文字の英数字（例: `DnbJh2JQ`）です。
  - 同名ユーザーが存在する場合でも一意に識別できるように設計されています。
  - 画面上のユーザー名をクリック／タップすることで、表示名と識別子の表示を切り替えることができます。
- **名前ハッシュ機能（`#` による暗号学的トリップ）:**
  - 2ちゃんねる等のトリップと同様に、名前に `#パスフレーズ`（または `＃パスフレーズ`）を付与してサインインすると、SHA-256ハッシュ関数により計算された不可逆な8文字の固定識別子が名前に付加されます。
  - 例: `テスト名前#mysecretkey` $\rightarrow$ `テスト名前#a1B2c3D4`
  - これにより、パスワードを知らない第三者による名前の「なりすまし」を完全に防止できます。

### 3.4 サインオーバー（端末間・ブラウザ間の引き継ぎ）
現在サインインしているアカウント状態を、別のPC・スマートフォン・別ブラウザへ簡単に引き継ぐ機能です。

1. サインイン済みの端末で、ナビゲーションバーの「サインオーバー」を選択します。
2. 画面上に **専用URL** と **QRコード** が発行されます（URLコピー用ボタンも用意されています）。
3. 引き継ぎ先の端末でそのURLを開くかQRコードを読み取ります。
4. 有効期限は **1時間** です。期限内に引き継ぎ先で「サインイン」を実行すると、同一アカウントとしてログインが完了します。

### 3.5 部屋ごとの名前・リンク表示設定
部屋に入室後、ナビゲーションバーに表示されている自分の名前をクリックすることで「名前やリンクを変更する」ダイアログが開きます。
- **名前:** その部屋の中限定で適用される表示名を個別変更できます。
- **リンク:** 自分のプロフィールURL（Twitter/Bluesky等）を部屋内で公開するか、非表示（「無し」）にするかを切り替えられます。

### 3.6 サインアウト
トップ画面またはメニューの「サインアウト」から、現在の端末でのセッションを安全に終了できます。

## 4. 部屋（ルーム）の管理と参加

### 4.1 部屋一覧とロビー機能
トップ画面には、現在オープンしている部屋の一覧が表示されます。

- **並び順の切り替え（ソート）:**
  - **作成順:** 部屋が新規作成された日時が新しい順に並びます。
  - **更新順:** 部屋内で直近に出題・回答・投票等のアクションがあった順に並びます。
- **自入室フィルター（バルカン・サリュート / スポックハンドアイコン 🖖）:**
  - フィルターボタンをクリックすると、自分が過去に入室した履歴のある部屋のみを絞り込んで表示します。
- **Atom フィード (`/atom.xml`):**
  - 部屋の新規作成状況をRSS/Atomリーダーで購読するためのフィードURLが提供されています。

### 4.2 部屋の新規作成と各種パラメータ設定
トップ画面の「部屋を作成する」ボタンから、多岐にわたるルールを設定して部屋を立ち上げることができます。

| 設定項目 | 選択肢・パラメータ | 説明 |
| :--- | :--- | :--- |
| **部屋名** | 文字列（必須） | 部屋の名称。 |
| **説明** | 文字列（任意） | 部屋のルールや趣旨などの補足説明。 |
| **アイコン画像** | 画像ファイルアップロード | 部屋一覧やヘッダーに表示されるカスタムアイコン。 |
| **カラースキーム** | 無し / ライト / ダーク | 部屋全体のデフォルトテーマ。入室後にユーザー自身が切り替えることも可能。 |
| **入室制限** | 無し / 有り（パスワード） | パスワードを知っているユーザーのみが入室できるように制限。 |
| **出題優先時間** | 無し / 有り（部屋作成者）/ 有り（投票者首位） [秒] | 結果フェーズ後、指定秒数の間、特定のユーザーのみに出題ボタンの操作を限定する（グレースタイム）。 |
| **出題者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 出題を行える権限を「ホストが許可したユーザー」または「SNS連携ユーザー」に限定。 |
| **出題画像制限** | 無し / 有り（禁止） | 出題時における画像アップロードの利用を禁止する設定。 |
| **出題コメント制限** | 無し / 有り（部屋作成者） | 出題に対する全体コメントの投稿権限を制限。 |
| **回答表示** | 即時 / 一斉（投票フェーズまで非表示） | 投稿された回答を即座に全員に見せるか、回答締切まで伏せるか。 |
| **回答時間制限** | 無し / 有り [秒] | 出題開始から回答フェーズ終了までの制限時間。 |
| **回答シャッフル時間** | 無し / 有り [秒] | 投票フェーズ移行時、直近X秒以内に投稿された回答の表示順序をランダム化して先着有利を排除。 |
| **回答数制限** | 無し / 有り [答] | 1人のユーザーが1回のゲームで投稿できる最大回答数。 |
| **回答者名表示** | 表示 / 非表示 / 一斉（結果フェーズまで非表示） | 回答一覧における回答者名の表示タイミング。 |
| **回答者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 回答可能なユーザーを制限。 |
| **回答コメント制限** | 無し / 有り（部屋作成者） | 各回答への個別コメント投稿を制限。 |
| **回答描画制限** | 無し / 有り（禁止） | 手書きキャンバスによるお絵かき回答を禁止し、テキストのみに限定。 |
| **投票表示** | 即時 / 一斉（結果フェーズまで非表示） | 投票された途中経過（現在の獲得票数）の公開タイミング。 |
| **投票時間制限** | 無し / 有り（出題毎 + 回答毎×） [秒] | 出題基本時間 ＋（回答数 × 加算時間）の計算式で投票時間を自動算出。 |
| **投票数制限（出題毎）** | 無し / 有り（票） / 有り（超過可）（票） | 1ゲーム内で1人が投票できる総持ち票数。「超過可」の場合は上限を超えても投票可能。 |
| **投票数制限（回答毎）** | 無し / 有り [票] | 1つの回答に対して1人が投入できる最大票数。 |
| **投票者名表示** | 表示 / 非表示 / 一斉（結果フェーズまで非表示） | 誰がどの回答に何票入れたかの開示タイミング。 |
| **投票者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 投票可能なユーザーを制限。 |
| **投票グループ制限** | 無し / 自グループに投票 / 次グループに投票 | グループ制実施時、自チームに投票するか、対戦相手の次グループに投票するかを制御。 |

- **履歴を見る機能:**
  - 過去に作成した部屋の設定履歴をブラウザ内に保持しており、「履歴を見る」ボタンから以前の部屋設定をワンクリックで復元・適用できます。

### 4.3 部屋の退室と削除
- **退室:** ナビゲーションバーの「退室する」を選択すると、部屋から退出してロビーに戻ります。
- **部屋の自動削除:** 最後の操作（更新）から **11.5日間** 経過した部屋は、サーバー側で自動的にクローズ・消去されます。

## 5. ゲーム進行とフェーズ遷移

### 5.1 フェーズの流れの概要

```
┌─────────────────────────────────────────────────────────────┐
│                    出題待ちフェーズ                         │
│   ・出題者がお題（テキスト＋任意で出典・画像）を投稿        │
│   ・出題優先時間（グレースタイム）中は対象者のボタンが点滅  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                     回答フェーズ                            │
│   ・回答者がボケを投稿（テキストまたは手書き描画）          │
│   ・一斉表示設定の場合は他者のボケは非表示                  │
│   ・制限時間タイマー終了、またはホストが「回答を締め切る」  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                     投票フェーズ                            │
│   ・回答一覧が表示され、投票者が持ち票を投票                │
│   ・ショートカットキー（Space/Delete/Enter）や 👍0 送信      │
│   ・制限時間タイマー終了、またはホストが「投票を締め切る」  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                     結果フェーズ                            │
│   ・順位、得点、偏差値（Zスコア）、ユニコーン🦄 等の集計表示│
│   ・絵文字クイックリアクションやコメントによる感想戦        │
│   ・次の出題へ移行                                          │
└─────────────────────────────────────────────────────────────┘
```

> [!NOTE]
> **途中サインインの制限**  
> フェーズ進行中に新しくサインインしたユーザーは、公平性を保つため、そのフェーズ中の回答・投票・出題操作が自動的に制限されます。

### 5.2 出題待ちフェーズ
ゲームが終了している、または新規開始前の状態です。
- 出題権限を持つユーザー（出題者）に「出題する」ボタンが表示されます。
- **出題フォーム:**
  - **お題本文:** 最大文字数制限あり。改行や長文にも対応。
  - **出典:** お題の引用元URLやテキストを入力可能。
  - **画像添付:** 画像制限が無効の場合、画像をアップロードしてお題に設定可能。
- **出題優先時間（グレースタイム）:**
  - 設定されている場合、部屋作成者または前回の1位獲得者に出題優先権が与えられます。
  - 優先権保持者の画面では「出題する」ボタンがアニメーション点滅（Blink）し、カウントダウンタイマーが表示されます。

### 5.3 回答フェーズ
出題が完了すると即座に回答フェーズが開始します。
- 回答権限を持つユーザーに「回答する」ボタンが表示されます。
- **回答の形式:**
  - **テキスト回答:** 通常の文字入力によるボケ。
  - **お絵かき回答:** 手書きのベクター線画によるボケ。
- **一斉回答時の修正・削除:**
  - 「一斉回答」ルールの場合、自分が投稿したボケは締切前であれば「回答を変更する」「回答を削除する」から何度でも再編集が可能です。
- **回答シャッフル:**
  - 投票フェーズへ切り替わる際、シャッフル時間設定に応じて回答の並び順がランダム化され、先着順の有利不利が緩和されます。

### 5.4 投票フェーズ
回答フェーズが終了すると、回答一覧が開示され投票フェーズへ移行します。
- **投票操作:**
  - 各回答の「投票する」ボタンを押すと投票モーダルが表示されます。
  - `+` / `-` ボタンで投票数を指定します。
  - **👍0（ゼロ票送信）クイックボタン:** 票を入れずに投票済みフラグのみを立てたい場合、1クリックで0票送信が可能です。
  - **投票を見る:** 自分がすでにどの回答に何票入れたかを一覧モーダルで確認できます。

### 5.5 結果フェーズ
投票が集計されると自動的に結果フェーズに切り替わります。
- 各回答の順位、獲得票数、標準化変量（Zスコア）に基づく偏差値、ユニコーンやアイスクリームの記号が表示されます。
- **コメントとクイックリアクション:**
  - お題全体、または個別の回答に対してコメントを投稿できます。
  - コメントフォーム横の顔アイコンから、9種類のクイックリアクション絵文字（😂, 🤣, 🥰, 😅, 🥺, 😭, 😱, 😡, 🫡）をワンクリックで送信できます。

## 9. 統計・スコア計算ロジック

### 9.1 偏差値（Zスコア）の計算
bǃgǃrǃ では、単純な獲得票数の合計だけでなく、ゲーム内の得点分布に基づいた **標準化変量（Zスコア / Standard Score）** を自動計算します。

各回答 $i$ の獲得票数を $x_i$ 、全回答の平均得点を $\mu$ 、標準偏差を $\sigma$ としたとき、Zスコア $z_i$ は以下の数式で定義されます。

$$z_i = \frac{x_i - \mu}{\sigma}$$

- **平均得点 ($\mu$):** 全回答の獲得票数の相加平均
- **標準偏差 ($\sigma$):** 各回答の得点のばらつき度合い

> 画面上の順位・記号部分をクリック／タップすると、四捨五入された小数第4位までの厳密なZスコア（例: `2.4142`）が表示されます。

### 9.2 ユニコーン 🦄 と アイスクリーム 🍦 の判定基準
Zスコアの大きさに応じて、際立った高評価および低評価の回答に特別なアイコンが付与されます。

```
       🍦🍦         🍦        (通常表示)        🦄         🦄🦄
   ─────────────┬───────────┬──────────────┬───────────┬─────────────
   Z ≦ -3.0     │ Z ≦ -2.0  │ -1.0 < Z < 1.0│ Z ≧ 2.0   │ Z ≧ 3.0
   アイス2個     │ アイス1個  │              │ ユニコーン1個│ ユニコーン2個
                │ (上線ハイライト)          │ (下線ハイライト)
```

- **ユニコーン (🦄 - Unicorn):**
  - $Z \ge 2.0$ の回答に **🦄** が1つ付与されます。
  - 以降、Zスコアが $1.0$ 増えるごとに追加で1つ付与されます（$Z \ge 3.0$ で 🦄🦄、$Z \ge 4.0$ で 🦄🦄🦄）。
- **下線ハイライト (Over Sigma):**
  - $Z \ge 1.0$ の回答の順位表示に、淡いパープル（Resene Unicornカラー）の下線が適用されます。
- **上線ハイライト (Under Sigma):**
  - $Z \le -1.0$ の回答の順位表示に、淡いバニラカラーの上線が適用されます。
- **アイスクリーム (🍦 - Ice Cream):**
  - $Z \le -2.0$ の回答に **🍦** が1つ付与されます。
  - 以降、Zスコアが $-1.0$ 下がるごとに追加で1つ付与されます（$Z \le -3.0$ で 🍦🍦）。

### 9.3 順位決定ルール（タイブレーク）
複数の回答が同じ獲得票数となった場合、以下の厳密な優先度で自動的に順位付けが行われます。

1. **合計得点 (Score):** 得点が高い回答が上位。
2. **優先度 (Priority):** グループ設定やカスタム優先度が設定されている場合はその値に従う。
3. **投稿日時 (CreatedAt):** 同点・同優先度の場合は、**投稿日時が早い回答（先着）** を上位とする。

## 10. 過去の結果とデータエクスポート（ログCSV）

### 10.1 過去の結果の閲覧
部屋ナビゲーションの「過去の結果」タブから、その部屋で行われた過去の全ゲームを振り返ることができます。
- **ページネーション:** 上部のページ送りバーから第1回、第2回…と任意の回へ直接ジャンプ可能。
- 各回の出題内容、添付画像、全回答、投票詳細、コメント、順位・Zスコアが保存されています。

### 10.2 CSVログのダウンロード
「ログ（CSV）」タブから、部屋内の全対戦ログをCSVファイルとして一括ダウンロードできます。

- **ダウンロードURL:** ユーザーごとの認証ハッシュキーが付与されたセキュアURLが生成されます。
- **ディスクリミネーター付きスイッチ:**
  - チェックを入れると、ユーザー名の末尾に識別子（`#XXXXXXXX`）が付加された形式でCSVが出力され、同名ユーザーの厳密なデータ集計・分析が可能になります。
- **CSVに含まれるデータ項目:**
  - ゲーム回数、出題者、お題テキスト、出典URL
  - 回答番号、回答者名（+識別子）、回答本文、描画データ
  - 各投票者の名前、投票先、投じられた票数
  - 獲得総得点、順位、偏差値、投稿タイムスタンプ

### 10.3 データの保存期間（データ保持ポリシー）

| 対象データ | 保存期間 | 説明 |
| :--- | :--- | :--- |
| **部屋（Room）** | **11.5日間** | 部屋内での最終更新操作から11.5日経過すると、部屋データ全体が自動消去されます。 |
| **ゲーム結果・ログCSV** | **34.5日間** | 実施されたゲーム履歴およびログCSVは、最大34.5日間保持された後に自動パージされます。 |

## 11. モデレーションとセキュリティ（部屋作成者権限・受刑者システム）

健全で安心な部屋運営のため、部屋作成者（ホスト）には強力な管理機能が用意されています。

### 11.1 ロール管理（出題者・回答者・投票者）
部屋作成者は「入室者を見る」ダイアログから、各ユーザーに対して個別にロール（権限）の付与・剥奪をリアルタイムに行えます。
- **出題者へ追加 / 削除:** お題を投稿できる権限をコントロール。
- **回答者へ追加 / 削除:** ボケを投稿できる権限をコントロール。
- **投票者へ追加 / 削除:** 投票に参加できる権限をコントロール。

### 11.2 受刑者（Prisoners）システム
迷惑行為を行う悪質ユーザーを排除するための包括的なBAN機能です。

- **受刑者への追加:**
  - 部屋作成者がユーザーを「受刑者へ追加する」と、そのユーザーの名前に打ち消し線が引かれ、部屋内での一切の操作（出題、回答、投票、コメント、リアクション）が即座に遮断されます。
- **自動IP追跡・連動遮断:**
  - 受刑者に指定されたユーザーのIPアドレスおよび関連セッションがシステム内部で追跡され、別名義や再入室による荒らし行為を自動的に防ぎます。
- **自動スパム防止:**
  - 短時間の過剰リクエストや不正なパラメータ送信を行う接続に対しては、システムレベルで自動的にアクセス制限が発動します。

### 11.3 非同期処理と二重送信防止
- **スピナーオーバーレイ:**
  - 部屋作成、サインイン、回答・投票送信、CSV生成などの非同期処理中、ボタン上にスピナー（ローディングインジケーター）がオーバーレイ表示され、誤った連打や二重送信を物理的に防ぎます。

## 14. よくある質問とトラブルシューティング (FAQ)

### Q1. 部屋に入室したのに回答や投票ができません。
- **A.** 以下の原因が考えられます。
  1. フェーズ進行中に途中サインインした場合、そのフェーズ中は操作が制限されます。次のフェーズまたは次のゲーム開始までお待ちください。
  2. 部屋の設定で「回答者制限」または「ソーシャルサインイン限定」が有効になっている可能性があります。Twitter/Blueskyでサインインし直すか、部屋作成者にロール付与を依頼してください。
  3. 回答数上限や持ち票の上限に達している可能性があります。

### Q2. 手書きの絵がダークモードで反転して見えます。
- **A.** bǃgǃrǃ の描画機能は、線のベクターデータをそのまま保持し、ダークモード時はCSSにより背景と線を反転させています。ライトモードで見れば元の黒線・白背景で正しく表示されます。

### Q3. トリップ（名前ハッシュ）の付け方がわかりません。
- **A.** サインイン時の名前入力欄で `名前#任意のパスワード` と入力して決定してください。自動的にハッシュ値が計算され、`名前#a1B2c3D4` のような形式に変換されます。

### Q4. 部屋のデータが消えてしまいました。
- **A.** bǃgǃrǃ の部屋は最終更新から11.5日、過去ログは34.5日で自動消去されます。定期的な大会やイベントのログは、期間内に「ログ（CSV）」タブからダウンロードしてローカルに保存することをお勧めします。
