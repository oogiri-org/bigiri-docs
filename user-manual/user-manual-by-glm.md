## 1. はじめに

### 1.1 bǃgǃrǃ とは

**bǃgǃrǃ（ビギリ）** は、キャッチコピー **"For Beautiful Oogiri Life"** を掲げる、誰でも使えるスーパーフレキシブルなネット大喜利催行サイトです。ブラウザーさえあれば特別なアプリのインストールは不要で、以下のような一連の流れをリアルタイムで行うことができます。

1. **出題** — 出題者がお題（文章・画像）を投稿する
2. **回答** — 回答者がお題に対するボケを投稿する（文章・手描きの絵）
3. **投票** — 投票者が面白いと思ったボケに票を入れる
4. **結果** — 得票数に基づく順位・Zスコア・ユニコーン🦄が発表され、感想戦を行う

少数で楽しむプライベートな部屋から、大人数のイベント・大会形式の部屋まで、細かなルール設定（表示方法・時間制限・数の制限・名前の匿名性・グループ分けなど）に対応しています。

### 1.2 ライセンスについて

トップ画面にはクリエイティブ・コモンズ・ライセンスが掲示されています。部屋内に個別の注記がない限り、投稿された作品および著作物は **Creative Commons Attribution 4.0 International（CC BY 4.0）** の下でライセンスされます。二次利用の際は作者のクレジット表示を行ってください。

## 2. 動作環境

- **対応ブラウザー:** Google Chrome・Mozilla Firefox・Apple Safari・Microsoft Edge などの最新版
- **言語仕様:** ECMAScript 2022 に対応したモダンブラウザーが必要です
- **通信環境:** リアルタイム更新を行うため、安定したインターネット接続を推奨します
- PC・タブレット・スマートフォンのいずれでも利用できます。画面幅が狭い環境でも入室者一覧の操作ボタン群を開閉できるなどの最適化が行われています

> [!NOTE]
> 一部のブラウザー（特にSafariの特定バージョン）では、データ取得の遅延に対処するため通信機能が一時的に変更されている場合があります。

## 3. クイックスタート

初めてbǃgǃrǃを利用する方は、以下の手順で始めることができます。

1. **サインインする** — トップ画面右上の「サインイン」から「新規サインイン」を選び、名前を設定します（4.1節）
2. **部屋を探すか作成する** — トップ画面の部屋一覧から「入室する」を選ぶか、「部屋を作成する」で自分の部屋を立ち上げます（5.1節・6章）
3. **ゲームに参加する** — 部屋画面で出題・回答・投票を行います（8章）
4. **結果を見る** — 結果フェーズで順位とユニコーン🦄を確認し、コメントで感想戦を楽しみます（8.5節・9章）

## 4. サインインとユーザー

bǃgǃrǃでは、用途に応じて複数のサインイン方法が用意されています。

### 4.1 新規サインイン（通常のサインイン）

1. トップ画面右上の「サインイン」を選ぶとサインイン画面が表示されます
2. 「新規サインイン」ボタンを押すと名前の設定フォームが開きます
3. 「名前」欄に表示名を入力して「設定する」を選択します
   - 名前の初期値は「お客さん」です
   - 名前は最大20文字です
   - トップ画面のメニューからいつでも変更できます
4. スパム防止のため、reCAPTCHAによる自動確認が行われます

### 4.2 ソーシャルサインイン（Twitter・Bluesky）

外部のSNSアカウントを利用してサインインできます。ソーシャルサインインをすると、以下の特徴があります。

- 入室者一覧などでプロフィール画像やプロフィールへのリンクアイコンが表示されます
- 部屋設定の「出題者制限・回答者制限・投票者制限（初期値）」で「有り（ソーシャルサインイン）」が設定された部屋でも、出題・回答・投票ができます
- 未出題のまま複数の部屋を作成できます（通常のサインインでは未出題の部屋は1つまで）

**Twitterでサインイン:**

- 「Twitterでサインイン」ボタンを押すとTwitter（X）の認証画面に遷移し、認証後に戻ってきます
- 認証画面は常に表示されます。サインインに失敗する場合は、事前に同ブラウザーでTwitterからログアウトするか、ブラウザーからTwitterのCookieを削除してお試しください
- Twitterでのサインイン方法については、画面遷移を変更する暫定措置がとられている場合があります（予告なく終了する場合があります）

**Blueskyでサインイン:**

- 「Blueskyでサインイン」ボタンを押すと、ハンドル（例: `user.bsky.social` などのドメイン形式、最大253文字）を入力するフォームが表示されます
- ハンドルを入力して認証すると、Blueskyのプロフィールアイコンとリンクが表示されるようになります
- 当面の間、試験稼動となります

### 4.3 名前のハッシュ値（なりすまし防止）

電子掲示板のトリップと同様に、名前に `#` と任意の文字列（パスフレーズ）を付けてサインインすると、暗号学的ハッシュ関数によって計算された8文字の値が名前に付加されて表示されます。

```
例:
びぎりちゃん          → びぎりちゃん
びぎりちゃん#abc     → びぎりちゃん#DnbJh2JQ
風祭ビギリマナ春子#abc → 風祭ビギリマナ春子#C2GkNEL6
```

パスフレーズを知らない第三者が同じ名前を使っても同一のハッシュ値を再現することはできず、名前のなりすましを防ぐことができます。

### 4.4 トークン（ディスクリミネーター）

サインインすると、入室者毎に一意のトークン（8文字の英数字）が割り当てられます。トークンは入室者一覧の右側に表示され、同名の入室者を識別するために使われます。

- 出題者名・回答者名・投票者名・コメント者名・グループのメンバー名などをクリック（タップ）すると、名前の表示とトークンの表示が切り替わります
- ログ（CSV）では「ディスクリミネーター」と呼ばれ、名前に付加して出力することができます（14章）

### 4.5 サインオーバー（サインイン状態の引き継ぎ）

現在のサインイン状態を、別の端末・別のブラウザーへ引き継ぐ機能です。

1. トップ画面または部屋画面のメニューから「サインオーバー」を選択します
2. 専用のURLとQRコードが発行されます。「URLをコピーする」ボタンでURLをクリップボードにコピーすることもできます
3. 引き継ぎ先の端末でそのURLを開くかQRコードを読み取り、サインインします
4. **有効期限は1時間です。** 期限を過ぎるとURLは無効になります

> [!WARNING]
> サインオーバーもソーシャルサインインもしていないサインイン状態は、サインアウトすると戻ることはできません。引き継ぎが必要な場合は必ずサインオーバーを利用してください。

### 4.6 名前の変更とリンクの設定

**トップ画面（サインイン時の名前）の変更:**

- トップ画面のメニューに表示されている**名前そのものがメニュー**になっています。名前を押すと名前の変更フォームが開き、最大20文字で変更できます

**部屋内での名前・リンクの変更:**

- 部屋画面のメニューバーに表示されている**名前を押す**と「名前やリンクを変更する」フォームが開きます
- **名前:** その部屋の中だけで有効な表示名に変更できます（他の部屋やトップ画面の名前には影響しません）
- **リンク:** 入室者一覧に表示するソーシャルリンクについて、「無し」または「有り（URL）」から選び、URLを設定できます。Twitter・BlueskyのプロフィールURLなどが初期値として表示されます

### 4.7 サインアウト

トップ画面または部屋画面のメニューから「サインアウト」を選択すると、現在の端末でのサインイン状態を終了します。確認のダイアログが表示されるので「サインアウト」を選択してください。

## 5. トップ画面

### 5.1 部屋一覧

現在オープンしている部屋が一覧表示されます。各部屋のカードには以下の情報が表示されます。

- アイコン画像・部屋名・説明（説明中のURLは自動的にリンクになります）
- Twitter・Blueskyのポストおよび検索リンク（部屋名をハッシュタグとして利用）
- 部屋の設定一覧（作成者・作成日時・入室制限・各種ルール設定）
- 入室者の名前（自分の名前は強調表示されます）
- 更新日時
- 「入室する」ボタン（部屋作成者には「部屋を削除する」ボタンも表示されます）

**部屋の表示順:**

一覧上部のドロップダウンリストから以下を選べます（いずれも新しいものが上になります）。

| 表示順 | 並び方 |
| :--- | :--- |
| **作成順** | 部屋が作成された日時の降順 |
| **更新順** | 部屋が最後に更新された日時の降順 |

**自入室フィルター:**

部屋一覧の先頭にあるボタン（🖖）を押してオンにすると、自分が入室している部屋のみが表示されます。もう一度押すとオフに戻ります。

**入室制限（パスワード）がある部屋:**

「入室する」を選ぶとパスワードの入力を求められます。正しいパスワードを入力すると入室できます。パスワードは最大15文字です。

### 5.2 更新情報と使用方法

トップ画面には、更新情報と使用方法の2つのセクションがあります。

- **更新情報:** 本リリースノート（更新情報）の一覧が表示されます。「更新情報を見る」ボタンを押すと、過去の更新履歴をダイアログウィンドウで確認できます
- **使用方法:** 「bǃgǃrǃ ユーザーマニュアル」（本マニュアル）へのリンクと、GitHubディスカッションへのリンクが表示されます。機能についての質問や提案はディスカッションでも受け付けています

そのほか、以下の外部連携が用意されています。

| リンク | 内容 |
| :--- | :--- |
| **Atomフィード** | 新着部屋情報をRSS/Atomリーダーで購読できます |
| **Bluesky** | 公式アカウントのプロフィールへリンクします |
| **Twitter (X)** | 公式アカウントのプロフィールへリンクします |
| **メール** | お問い合わせ先のメールアドレスへリンクします |

## 6. 部屋を作成する

トップ画面の「部屋を作成する」ボタンから、詳細なルールを設定して部屋を立ち上げることができます。設定画面は「基本」「出題」「回答」「投票」の4つのセクションで構成されています。一度部屋を作成すると、その設定値（アイコン画像を含む）が次回作成時の初期値になります。

> [!NOTE]
> 通常のサインインの場合、未出題のままの部屋は1つまでしか作成できません。Twitterでサインインしている場合は、未出題のまま複数の部屋を作成できます。

### 6.1 基本設定

| 設定項目 | 設定値 | 説明 |
| :--- | :--- | :--- |
| **部屋名** | 最大150文字（必須） | 部屋の名称です |
| **説明** | 最大1500文字 | 部屋の趣旨やルールの説明です。書かれたURLは自動でリンクになります |
| **アイコン画像** | 画像ファイル | 部屋一覧や部屋画面に表示されるアイコンです。180×180ピクセル以内に自動縮小され、容量制限があります |
| **カラースキーム** | 無し / ☀ ライト / 🌙 ダーク | 部屋の既定の配色を固定します。「無し」の場合は各ユーザーの設定に従います |
| **入室制限** | 無し / 有り（パスワード） | 「有り」にするとパスワードを知っている入室者のみが入室できます（パスワードは最大15文字） |

### 6.2 出題に関する設定

| 設定項目 | 設定値 | 説明 |
| :--- | :--- | :--- |
| **出題優先時間** | 無し / 有り（部屋作成者）（秒） / 有り（投票者首位）（秒） | 結果フェーズ後、指定した秒数の間は特定の入室者のみが出題できます（8.6節） |
| **出題者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 出題できる入室者を制限します。「有り」は入室者一覧で追加された入室者のみ、「有り（ソーシャルサインイン）」はTwitter・Blueskyでサインインした入室者のみが出題できます |
| **出題画像制限** | 無し / 有り（禁止） | 出題時の画像添付を禁止します |
| **出題コメント制限** | 無し / 有り（部屋作成者） | 出題コメント（9章）を部屋作成者のみが投稿できるように制限します |

### 6.3 回答に関する設定

| 設定項目 | 設定値 | 説明 |
| :--- | :--- | :--- |
| **回答表示** | 即時 / 一斉（投票フェーズまで非表示） | 「即時」は回答が投稿された時点で他の入室者にも表示されます。「一斉」は投票フェーズまで回答が非表示になります |
| **回答時間制限** | 無し / 有り（秒） | 回答フェーズの制限時間を設定します |
| **回答シャッフル時間** | 無し / 有り（秒） | 出題からの経過時間を設定し、その間に投稿された回答の表示順を投票フェーズでランダムにします（8.7節）。空・0を指定すると全ての回答が対象になります |
| **回答数制限** | 無し / 有り（答） | 1人あたりの回答数の上限を設定します |
| **回答者名表示** | 表示 / 非表示 / 一斉（結果フェーズまで非表示） | 回答者名の表示方法を設定します。いずれの設定でも、自分自身の回答の回答者名は常に自分に表示されます |
| **回答者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 回答できる入室者を制限します |
| **回答コメント制限** | 無し / 有り（部屋作成者） | 回答コメント（9章）を部屋作成者のみが投稿できるように制限します |
| **回答描画制限** | 無し / 有り（禁止） | 手描きの描画による回答を禁止します |

### 6.4 投票に関する設定

| 設定項目 | 設定値 | 説明 |
| :--- | :--- | :--- |
| **投票表示** | 即時 / 一斉（結果フェーズまで非表示） | 「即時」は投票の途中経過がリアルタイムで表示されます。「一斉」は結果フェーズまで投票が非表示になり、投票フェーズ開始後に投票できるよう統一されます |
| **投票時間制限** | 無し / 有り（出題毎＋回答毎×）（秒） | 投票フェーズの制限時間を「出題毎の秒数＋回答毎の秒数×回答数」の計算式で設定します（16章） |
| **投票数制限（出題毎）** | 無し / 有り（票） / 有り（超過可）（票） | 1人あたりの総投票可能票数を設定します。「有り（超過可）」は制限に達した後も投票画面での投票を続けられます |
| **投票数制限（回答毎）** | 無し / 有り（票） | 1つの回答に対して1人が入れられる最大票数を設定します |
| **投票者名表示** | 表示 / 非表示 / 一斉（結果フェーズまで非表示） | 投票者名の表示方法を設定します。いずれの設定でも、自分自身の投票の投票者名は常に自分に表示されます |
| **投票者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 投票できる入室者を制限します |
| **投票グループ制限** | 無し / 有り（自グループに投票） / 有り（次グループに投票） | グループ分けされた部屋で、投票対象となる回答を制限します（10章） |

> [!TIP]
> 各制限（出題者制限・回答者制限・投票者制限）は、部屋作成者が入室者一覧から入室者毎に個別に追加・削除することもできます（12章）。入室者一覧で設定を行った場合、部屋作成時の初期値設定よりも優先されます。

### 6.5 設定の履歴機能

「部屋名」欄の横にある「履歴を見る」ボタンを押すと、同じブラウザーで過去に作成した部屋の一覧が表示されます。

- 「履歴を読み込む」ボタンで、その部屋の設定をフォームに読み込めます
- 「履歴を削除する」ボタンで、履歴を削除できます
- 一覧には部屋名と作成日時が表示されます
- 同一の部屋名で部屋を作成した場合、履歴には最新の設定のみが残されます

## 8. ゲームの進行

### 8.1 フェーズの流れ

bǃgǃrǃのゲームは、以下の4つのフェーズで進行します。

```
┌───────────────────────────────────────────────────────────┐
│                出題待ち（出題はありません）                │
│  ・出題者がお題（文章・画像・出典）を投稿                   │
│  ・出題優先時間中は優先される出題者のボタンが明滅           │
└────────────────────────────┬──────────────────────────────┘
                             ▼
┌───────────────────────────────────────────────────────────┐
│                       回答フェーズ                         │
│  ・回答者がボケ（文章・手描きの絵）を投稿                   │
│  ・「一斉」表示なら他の入室者の回答は非表示                 │
│  ・制限時間の経過または部屋作成者による締め切りで次へ       │
└────────────────────────────┬──────────────────────────────┘
                             ▼
┌───────────────────────────────────────────────────────────┐
│                       投票フェーズ                         │
│  ・回答一覧が表示され、投票者が票を入れる                   │
│  ・キーボード操作や👍0クイック投票に対応                    │
│  ・制限時間の経過または部屋作成者による締め切りで次へ       │
└────────────────────────────┬──────────────────────────────┘
                             ▼
┌───────────────────────────────────────────────────────────┐
│                       結果フェーズ                         │
│  ・順位・Zスコア・ユニコーン🦄・アイスクリーム🍦を表示      │
│  ・コメントやクイックコメントで感想戦                       │
│  ・次のお題の出題へ                                         │
└───────────────────────────────────────────────────────────┘
```

フェーズの進行は自動的に行われます。回答フェーズ中に回答が1つもないまま制限時間を過ぎるなどした場合は、出題がやり直しになる場合があります。また、公平性のため、フェーズの進行中にサインインした入室者には、そのフェーズ中の操作が制限される場合があります。

各フェーズ中、部屋作成者には以下の操作ボタンが表示されます。

| フェーズ | ボタン | 動作 |
| :--- | :--- | :--- |
| 回答フェーズ | **回答を締め切る** | 回答を締め切って投票フェーズへ進めます |
| 投票フェーズ | **投票を締め切る** | 投票を締め切って結果フェーズへ進めます |
| 結果フェーズ | **出題優先を締め切る** | 出題優先時間を途中で終了させます |

### 8.2 出題する

出題待ちの状態で、出題権限のある入室者には「出題する」ボタンが表示されます。ボタンを押すと出題フォームが開きます。

**出題フォームの項目:**

| 項目 | 制限 | 説明 |
| :--- | :--- | :--- |
| **出典** | 最大150文字 | お題の出典（引用元）を入力します。入力されたURLは自動的にリンク表示されます。著作物をお題に用いる場合は適切な出典の入力をお願いします |
| **画像** | — | 「画像無し」/「画像有り」を選択します。画像は320×320ピクセル以内に自動縮小されます。画像ファイルを選択すると、出典欄にファイル名が自動的に入力されます。部屋設定で出題画像制限が「有り（禁止）」の場合は画像を添付できません |
| **出題** | 1〜1500文字（必須） | お題の本文です。画像のみでお題とする場合は本文を空欄にできます |

- `Ctrl＋Enter`（Windows）または `Command（Windowsキー）＋Enter` で入力内容を送信できます
- 画像は明るい背景色で表示されます

出題が投稿されると「第N回」として回数が表示され、回答フェーズへ進みます。出題者名をクリックすると、名前とトークンの表示が切り替わります。

### 8.3 回答する

回答フェーズ中、回答権限のある入室者には「回答する」ボタンが表示されます（回答数制限に達している場合は押せません）。回答フォームのタイトルにはお題とお題画像が表示されます。

**回答フォームの項目:**

| 項目 | 制限 | 説明 |
| :--- | :--- | :--- |
| **描画** | 最大1500要素 | 「描画無し」/「描画有り」を選択します。描画キャンバス（黒の線画）にマウス・ペン・指で直接絵を描いてボケにできます。 undo（↩）/redo（↪）ボタンで描画の取り消し・やり直しができます。部屋設定で回答描画制限が「有り（禁止）」の場合は使用できません |
| **回答** | 1〜1500文字（必須） | ボケの本文です。描画のみで回答する場合は本文を空欄にできます |

- `Ctrl＋Enter` または `Command（Windowsキー）＋Enter` で入力内容を送信できます
- 複数行入力欄は行数に応じて自動的に伸びます

**回答の変更・削除:**

- 回答表示が「一斉」の場合、回答フェーズ中は自分の回答カードに「回答を削除する」ボタンと「回答を変更する」ボタンが表示されます
- 「回答を変更する」で内容を再編集できます。この場合、回答時刻も更新されます

**表示上の注意:**

- 回答表示が「一斉」の場合、投票フェーズまで他の入室者の回答は表示されません
- 150文字または10行を超える長文の回答は、超えた位置で折りたたまれ、「…（残文字数）」ボタンを押すと残りが表示されます

### 8.4 投票する

投票フェーズ中（または投票表示が「即時」かつ回答が即時表示の場合は回答の投稿直後から）、投票権限のある入室者には各回答に「投票する」ボタンが表示されます。

**投票画面の操作:**

1. 「投票する」ボタンを押すと投票フォームが開きます。お題と対象の回答が表示されます
2. 「−」ボタン・「＋」ボタン、またはキーボードで投票数を調整します
3. 「投票する」を選択すると投票が確定します

| キー操作 | 動作 |
| :--- | :--- |
| `スペース` | 投票数を1増やす |
| `デリート` | 投票数を1減らす |
| `エンター` | 入力内容を送信する |

- 投票フォームを開いた直後は自動的に投票数ボタンにフォーカスが当たっているため、すぐにキー操作で投票できます
- 投票数の初期値は1票です（投票数制限の残りがなければ0票になります）
- **0票の投票**も可能です。「投票する」ボタンの横にある「👍0」ボタンを押すと、票を入れずに投票だけをワンクリックで行うこともできます
- 0票を含む投票は、投票済みであることの記録や、投票を見る画面での確認に利用できます

**投票の変更・削除:**

- 投票表示が「一斉」の場合、投票済みの回答には「投票を変更する」ボタンと「投票を削除する」ボタンが表示されます。「投票を変更する」では、投票を削除しなくても投票数を減らすことができます
- 以前の投票を削除した直後に回答フォームを開くと、削除した内容が初期値として設定されます

**投票を見る:**

- 投票済みの場合は「投票を見る」ボタン（投票数制限を使い切った場合は投票一覧ボタン）で、自分のこれまでの投票の一覧を確認できます
- 一覧には投票数の合計と、投票数制限（出題毎）が「👍N/制限」の形式で併記されます

**投票の表示:**

- 回答毎の投票の表示順は、投票数の多い順です（同じ投票数の場合は投票した順）
- 投票表示が「即時」の場合、他の入室者の投票内容もリアルタイムで表示されます（投票者名表示の設定により名前は非表示の場合があります）
- 回答の得票数（👍n）を押すと、その回答について自分の投票のみが表示されます（11.4節）

### 8.5 結果フェーズ

投票が締め切られると自動的に集計され、結果フェーズに進みます。

- 各回答には**順位**・得票数・投票者（設定により表示）・コメントが表示されます
- 順位の横には、得票分布に基づく**Zスコア**に応じて以下の表示が現れます（9.1節参照）

| マーク・装飾 | 条件 | 意味 |
| :--- | :--- | :--- |
| 🦄（ユニコーン） | Zスコア ≥ 2 で1つ。1上がるごとに1つ増加 | 際立って高い評価 |
| 順位に**下線** | Zスコア ≥ 1 | 高評価 |
| 順位に**上線** | Zスコア ≤ −1 | 低評価 |
| 🍦（アイスクリーム） | Zスコア ≤ −2 で1つ。1下がるごとに1つ増加 | 際立って低い評価 |

- 順位部分をクリックすると、小数第4位までの正確なZスコア数値が表示されます
- 結果は「過去の結果」画面でも後から閲覧できます（13章）
- 結果フェーズでは、次のお題の出題（出題権限のある入室者）や、コメント・クイックコメントによる感想戦（9章）が行えます

**順位の決定ルール:**

得票数が同じ回答は、以下の順で順位が決まります。

1. 得票数（補正得票数）の多い方を上位とします
2. それも同じ場合は、回答者の投票数が多い方を上位とします（ゲームへの貢献度による優遇）
3. それも同じ場合は、回答の早い方を上位とします

### 8.6 出題優先時間

部屋設定の出題優先時間を設定すると、結果フェーズの開始から指定した秒数の間、出題できる入室者が制限されます。

| 設定値 | 優先される出題者 |
| :--- | :--- |
| **有り（部屋作成者）** | 部屋作成者のみが出題できます |
| **有り（投票者首位）** | 前回の出題で投票に参加した回答者のうち、最上位の回答を出した入室者が優先されます |

- 優先時間中は、優先される出題者の「出題する」ボタンが明滅して案内されます
- 優先時間はタイマーで表示され、経過すると誰でも（出題権限のある入室者は）出題できるようになります
- 部屋作成者は「出題優先を締め切る」ボタンで、優先時間を途中で終了させることができます

### 8.7 回答シャッフル

部屋設定の回答シャッフル時間を設定すると、出題からの経過時間と回答の投稿時刻の関係に応じて、投票フェーズでの回答の表示順が入室者毎にランダムになります。

- 出題からシャッフル時間内に投稿された回答が対象です。シャッフル時間を空（または0秒）に設定すると、全ての回答が対象になります
- これにより、回答の表示位置を先着順に固定することなく、投票の公平性を高めることができます
- 結果フェーズでの順位はこの設定と関係なく、得票数に基づいて計算されます

## 9. コメントとクイックコメント（リアクション）

bǃgǃrǃには3種類のコメントがあります。

| 種類 | 投稿できる人 | 投稿できるタイミング | 削除 |
| :--- | :--- | :--- | :--- |
| **部屋コメント** | 部屋作成者のみ | いつでも | 可能（最新の1つ） |
| **出題コメント** | 制限設定による（無し＝全員／有り＝部屋作成者のみ） | 結果フェーズ | 不可 |
| **回答コメント** | 制限設定による（無し＝全員／有り＝部屋作成者のみ） | 結果フェーズ | 不可 |

- コメントは最大150文字です（空のコメントも投稿できます）
- コメント中のURLは自動的にリンク表示されます
- コメント者名をクリックすると、名前とトークンの表示が切り替わります
- 部屋作成者は、部屋の「コメントする」「コメントを削除する」ボタンで部屋コメントを投稿・削除できます。「コメントを削除する」で削除されるのは最新の1つです
- 出題コメントはお題に対して、回答コメントは各回答に対して投稿します。結果フェーズの画面で各コメントボタンから投稿できます

**クイックコメント（リアクション）:**

コメントボタンの横にあるスマイルボタンを押すと、以下の絵文字（9種類）から選んでワンクリックでコメントできます。

```
😂  🤣  🥰  😅  🥺  😭  😱  😡  🫡
```

出題コメント・回答コメントの両方で利用できます。

## 10. グループ機能

大人数の部屋やチーム対抗戦などで、入室者を「グループ」に分けることができます。

**グループの作成・削除（部屋作成者のみ）:**

1. 部屋画面の「グループを選択する」ボタンを押します
2. 「グループを作成する」ボタンから、グループ名（最大20文字・重複可・空欄可）と説明（最大1500文字）を入力して作成します
3. 作成したグループはカードとして表示され、「グループを削除する」ボタンで削除できます
4. グループ作成画面にも履歴機能があり、同じブラウザーで作成したグループの設定を読み込む・削除できます（同一グループ名の場合は最新のみ残ります）

**グループの選択（全入室者）:**

- グループを選んでいない入室者には、グループ選択画面が自動的に表示されます
- グループが追加された以降に入室した入室者には、入室時にグループ選択画面が表示されます
- 所属グループが削除された入室者にも、再度グループ選択画面が表示されます
- ラジオボタンでグループを選ぶと、すぐにそのグループに入ることができます。好きなタイミングで「グループを選択する」からグループを変えることもできます

**グループの表示:**

- ナビゲーションバーの自分の名前の前に、入室中のグループ名が表示されます
- メイン画面・過去の結果画面で回答者名の前に、回答者のグループ名が表示されます
- 入室者一覧で入室者名の前に、入室者のグループ名が表示されます
- グループを選ぶ画面では、各グループのメンバー数とメンバー名が確認できます
- 部屋設定の投票グループ制限が「無し」の場合、部屋画面にグループ毎の回答数は表示されません

**投票グループ制限:**

部屋設定の「投票グループ制限」を設定すると、投票フェーズで表示される回答が制限されます。グループが1つもない場合は、設定していない場合と同じ動作になります。

| 設定値 | 投票フェーズでの表示 |
| :--- | :--- |
| **有り（自グループに投票）** | 自分と同じグループの回答だけが表示されます |
| **有り（次グループに投票）** | 自分のグループの直後に作成されたグループの回答だけが表示されます。自分のグループが最後の場合は最初に作成されたグループの回答だけ、グループを選んでいない場合はグループを選んでいない回答だけが表示されます |

投票グループ制限を設定した場合、投票時間制限の「回答毎×」には、全体の回答数ではなく、表示された回答数が最も多いグループの回答数が採用されます。

**グループフィルター:**

結果フェーズおよび過去の結果画面で、回答に表示されているグループ名を押すと、そのグループの回答だけが表示されます（11.3節）。

## 11. 並び替えとフィルター

多くの回答や入室者の中から目的の情報を探しやすくするため、多彩な並び替えとフィルターが用意されています。

### 11.1 回答の表示順

メイン画面上部のドロップダウンリストから、回答の並び順を選べます。フィルターと組み合わせて、全てのフェーズで利用できます。

| 表示順 | 並び方 |
| :--- | :--- |
| **設定順** | 部屋設定によるデフォルトの表示順（回答シャッフルの設定を反映） |
| **先着順** | 回答が投稿された日時の早い順 |
| **後着順** | 回答が投稿された日時の遅い順 |
| **上位順** | 得票数の多い順 |
| **下位順** | 得票数の少ない順 |
| **多コ順** | コメント数の多い順（結果フェーズ・過去の結果のみ） |
| **少コ順** | コメント数の少ない順（結果フェーズ・過去の結果のみ） |

### 11.2 プライマリーフィルター

回答一覧の先頭にある3つのボタンで、自分に関係する回答だけを絞り込めます。オン・オフはボタンのデザインで判別できます。

| フィルター | 表示される回答 | 利用できるフェーズ |
| :--- | :--- | :--- |
| ✋ **自回答フィルター** | 自分が投稿した回答（回答フェーズでは自回答数が併記されます） | 回答・投票・結果フェーズ、過去の結果 |
| 👍 **自投票フィルター** | 自分が投票した回答（投票フェーズでは自投票数が併記されます） | 投票・結果フェーズ、過去の結果 |
| ☝ **自コメントフィルター** | 自分がコメントした回答 | 結果フェーズ、過去の結果 |

3つのフィルターは互いに組み合わせて使用できます。また、下方にスクロールしてもフィルターボタンは表示され続けます。

### 11.3 セカンダリーフィルター

プライマリーフィルターと併用できる、詳細な絞り込み機能です。

- **グループフィルター:** 結果フェーズおよび過去の結果画面で、回答に表示されたグループ名を押すと、そのグループの回答だけが表示されます
- **回答ピックアップ:** 各回答の目のアイコン（👁）を押すと、その回答だけが表示されます。もう一度押す（👁）と元の表示に戻ります

### 11.4 回答毎の自投票フィルター

各回答の得票数（👍n）を押してオンにすると、その回答の投票の中から自分の投票だけが表示されます。投票の確認に利用できます。

### 11.5 入室者の表示順

「入室者を見る」画面では、ドロップダウンリストから全10種類の並び順を選べます。

| 表示順 | 並び方 |
| :--- | :--- |
| **先入順** | 部屋に入室した日時の早い順 |
| **後入順** | 部屋に入室した日時の遅い順（既定値） |
| **多🦄順** | ユニコーン🦄の獲得数が多い順 |
| **少🦄順** | ユニコーン🦄の獲得数が少ない順 |
| **昇名順** | 名前の文字コード昇順 |
| **降名順** | 名前の文字コード降順 |
| **昇Di順** | ディスクリミネーター（トークン）の文字コード昇順 |
| **降Di順** | ディスクリミネーター（トークン）の文字コード降順 |
| **古サ順** | サインイン登録日時の古い順 |
| **新サ順** | サインイン登録日時の新しい順 |

## 12. 入室者を見る（ロール管理・受刑者）

部屋画面の「入室者を見る」ボタンから、入室者の一覧を確認できます。

**一覧の表示内容:**

- 入室者数（🖖アイコン付き）
- 各入室者の名前（自分の名前は強調表示）・グループ名・プロフィール画像・ソーシャルアイコン・ユニコーン🦄の累計・トークン
- 名前をクリックすると、名前とトークンの表示が切り替わります
- 退室した出題者・回答者・投票者も一覧に含まれます
- **受刑者**は取り消し線付きで表示されます
- ブラウザーの幅が狭い場合は、操作ボタン群を「…」ボタンで開閉できます

**ロール管理（部屋作成者のみ）:**

各入室者について、以下のボタンで権限を個別に追加・削除できます。

- 「出題者へ追加する」／「出題者から削除する」
- 「回答者へ追加する」／「回答者から削除する」
- 「投票者へ追加する」／「投票者から削除する」

**受刑者（部屋作成者のみ）:**

- 「受刑者へ追加する」を選ぶと、その入室者は強制退室となり、部屋での出題・回答・投票・コメントができなくなります。「受刑者から削除する」で解除できます
- 不正なアクセスによって出題・回答・投票・コメントを行おうとした入室者は、システムによって自動的に受刑者へ追加される場合があります
- 入室者を受刑者に追加した場合、同一の発信元からそれらの操作を行う入室者もあわせて追加されます

- メイン画面の結果フェーズと同様に、表示順の変更（11.1節）・各種フィルター（11.2節〜11.4節）・Zスコアやユニコーン🦄の表示・コメントの閲覧ができます

## 14. ログ（CSV）

部屋画面の「ログ（CSV）」タブから、対戦ログのCSVファイルをダウンロードできます。

- ログはURLリンク形式で提供されます。**ダウンロードにはその部屋への入室が必要です**
- URLを選択するとダウンロードが始まります。ダウンロード時にサーバーが処理中であることが表示される場合があります
- 「ディスクリミネーター付き」チェックボックスをオンにすると、名前にディスクリミネーター（トークン）が付加されたCSVファイルをダウンロードできます。名前とディスクリミネーターは改行で区切られます（例: 同名の入室者を厳密に区別した集計・分析に利用できます）
- CSVには出題・回答・投票の記録に加えて、回答者のグループ名も出力されます
- ダウンロードできるログの範囲は**34.5日以内**の出題です

> [!TIP]
> 部屋は一定期間で自動的に削除されます（17章）。イベントや大会の記録を残したい場合は、期間内にCSVをダウンロードして保存してください。

## 16. タイマーと時間制限

時間制限が設定されている場合、円形のカウントダウンタイマーで残り時間が表示されます。残り時間が少なくなるとタイマーが赤く表示されます。

| タイマー | 計算・開始タイミング |
| :--- | :--- |
| **回答時間制限** | 出題が投稿された時点からカウントダウンします。メイン画面・回答フォーム・自分の回答カードに表示されます |
| **投票時間制限** | 「出題毎の秒数＋回答毎の秒数×回答数」の合計時間になります。投票グループ制限を設定した場合は、表示対象の回答数が最も多いグループの回答数が用いられます。投票フォーム・回答一覧に表示されます |
| **出題優先時間** | 結果フェーズの開始時点からカウントダウンします |

制限時間を過ぎると、フェーズは自動的に次へ進みます。

## 18. よくある質問（FAQ）

**Q1. 部屋に入室したのに、出題・回答・投票ができません。**

以下の原因が考えられます。

1. 部屋設定の制限（出題者制限・回答者制限・投票者制限）が「有り」または「有り（ソーシャルサインイン）」になっている → 部屋作成者への権限付与の依頼、またはTwitter・Blueskyでのサインインをお試しください
2. 回答数制限・投票数制限（出題毎・回答毎）の上限に達している
3. 回答時間制限・投票時間制限の時間外、またはフェーズが進行中（フェーズ途中にサインインした入室者には制限がかかる場合があります）
4. 受刑者として登録されている（心当たりのある入室者は部屋作成者にご確認ください）

**Q2. 名前のなりすましを防ぎたいです。**

サインイン時の名前に `#パスフレーズ` を付けてください（4.3節）。暗号学的ハッシュ値が名前に付加され、同じ名前とハッシュの組み合わせを他人が再現することはできません。

**Q3. 部屋のデータが消えてしまいました。**

部屋は最終更新から11.5日、過去の結果とログ（CSV）は34.5日で自動的に削除されます。継続的に利用する部屋は定期的にアクセスし、記録を残す場合は期間内にCSVをダウンロードしてください。

**Q4. 長いお題や回答が途中で切れて表示されます。**

150文字または10行を超えるお題・回答は自動的に折りたたまれます。「…（残文字数）」ボタンを押すと、残りの部分が表示されます。

**Q5. サインイン状態を別の端末に引き継ぎたいです。**

「サインオーバー」を利用してください（4.5節）。発行されたURLまたはQRコードを、引き継ぎ先の端末で1時間以内に開きます。

**Q6. 部屋の中だけで別の名前を使いたいです。**

部屋画面のメニューバーの名前を押して「名前やリンクを変更する」から変更できます（4.6節）。この変更はその部屋内でのみ有効です。

**Q7. 投票の誤操作を防ぎたいです。**

投票フォームはキーボード操作（スペース＝増票・デリート＝減票・エンター＝送信）に対応しています。誤送信が心配な場合は、エンターではなく画面の「投票する」ボタンをマウスで押す運用をおすすめします。ダイアログはエスケープキーで閉じられます。

**Q8. 手描きの回答（描画）はどこで使えますか？**

回答フォームの「描画有り」で利用できます（8.3節）。ただし、部屋設定の回答描画制限が「有り（禁止）」の場合は使用できません。描画は黒い線画で、取り消し（undo）・やり直し（redo）に対応しています。

**Q9. 大人数の部屋で自分の回答や投票だけを確認したいです。**

✋自回答フィルター・👍自投票フィルター・☝自コメントフィルターを利用してください（11.2節）。回答毎の得票数（👍n）を押すと、その回答への自分の投票だけが表示されます（11.4節）。

**Q10. 同点の順位はどのように決まりますか？**

得票数が同じ場合は、回答者の投票数が多い方、さらに同じ場合は回答の早い方が上位になります（8.5節）。
