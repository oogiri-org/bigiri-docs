## 1. bǃgǃrǃ の概要

bǃgǃrǃ（ビギリ）は、Web ブラウザー上で大喜利を遊ぶためのアプリケーションです。サブタイトルは「For Beautiful Oogiri Life」。利用者は「部屋」と呼ばれる単位に集まり、次のサイクルを繰り返します。

1. **出題** — 出題者がお題を投稿する
2. **回答** — 参加者がお題への回答（ボケ）を投稿する
3. **投票** — 参加者が面白い回答に票を入れる
4. **結果** — 得票数と順位が発表され、コメントやリアクションで交流する

最大の特徴は、**ルールを部屋ごとに細かく決められる**ことです。誰が出題・回答・投票できるか、名前を表示するか、投稿をリアルタイムで見せるか一斉に見せるか、制限時間や票数の上限、参加者のグループ分けなどを部屋の作成者が設定できます。少人数の気軽な大喜利から、グループ対抗戦や大会形式まで幅広く運用できます。

### 利用前に知っておきたいこと

- ほぼすべての操作に**サインイン**が必要です。
- ルールは部屋ごとに異なります。「ボタンが押せない」「回答が見えない」場合は、まずその部屋の設定と現在のフェーズを確認してください。
- 部屋は**最終更新から 11.5 日**で終了します。
- 過去の結果の閲覧とログ（CSV）のダウンロードは**34.5 日以内の出題**が対象です。
- スマートフォンなど画面幅の狭い端末にも対応しています。
- トップ画面にはクリエイティブ・コモンズ・ライセンスが掲示されています。

## 2. ゲームの進行（フェーズ）

部屋は常に次のいずれかのフェーズにあります。

| フェーズ | 状態 | できること |
|---|---|---|
| 出題待ち | お題がまだない（部屋作成直後・前回の結果確定後） | 出題する |
| 回答フェーズ | お題が出ている | 回答の投稿・変更・削除 |
| 投票フェーズ | 回答が締め切られた | 投票の投稿・変更・削除 |
| 結果フェーズ | 投票が締め切られた | 順位の閲覧・コメント・リアクション・次の出題 |

### フェーズが切り替わる条件

- **時間による自動締め切り** — 部屋設定で「回答時間制限」「投票時間制限」が定められている場合、残り時間がなくなると自動で次のフェーズへ進みます。残り時間は画面のタイマーおよびダイアログウィンドウ上の「回答する」「投票する」ボタンに表示されます。
- **部屋作成者による手動締め切り** — 部屋作成者は、回答・投票・出題優先時間をいつでも締め切ることができます。
- 集計に時間がかかるときは「集計中」「処理中」の表示が出ます。消えるまで操作せず待ってください。

### 投稿の表示タイミング

部屋設定の「回答表示」「投票表示」で、他の参加者の投稿がいつ見えるかが決まります。

- **即時** — 投稿されるたびにリアルタイムで表示されます。回答数もリアルタイムに表示されます。
- **一斉** — 締め切り後にまとめて表示されます。「投票表示」が一斉の部屋では、**投票フェーズが始まってから**投票できるようになります。

## 3. サインインと利用者名

### 3.1 新規サインイン

サインイン画面で「**新規サインイン**」ボタンを押し、名前を入力してサインインします。

- 名前の初期値は「**お客さん**」です。
- サインイン時には reCAPTCHA による確認が行われます。
- 入力欄で改行キーを押しても送信されません。ボタンで送信してください。

### 3.2 名前にハッシュ値を付ける

名前の末尾に `#` と任意の文字列を付けると、`#` 以降が **8 文字のハッシュ値**に変換されて表示されます。元の文字列は表示されません。

```text
びぎりちゃん            → びぎりちゃん
びぎりちゃん#abc        → びぎりちゃん#DnbJh2JQ
風祭ビギリマナ春子#abc  → 風祭ビギリマナ春子#C2GkNEL6
```

同じ入力からは常に同じハッシュ値が生成されるため、同名の利用者との区別や、セッションをまたいだ同一人物の目印として使えます。推測されやすい文字列は避けてください。ハッシュ値を付けていても、後述のソーシャルリンクは表示できます。

### 3.3 ソーシャルサインイン

#### Twitter（X）でサインイン

- 画面上部右端にプロフィール画像が表示されます。画像を読み込めない場合はデフォルト画像が表示されます。
- 入室者一覧にプロフィール画像とアカウントへのリンクを表示できます（第 3.5 節）。
- ナビゲーションメニューに Twitter リンクが表示されます。
- 通常のサインインでは未出題の部屋を 1 つしか作成できませんが、Twitter サインイン時は**未出題の部屋を複数作成できます**。
- 現在、Twitter サインインの画面遷移には暫定的な措置が適用されています。予告なく終了する場合があります。

#### Bluesky でサインイン

Bluesky アカウントによる OAuth サインインが利用できます。サインイン画面の「Bluesky でサインイン」ボタンから認証します。**試験稼動中**の機能です。トップ画面や部屋画面には Twitter と同等の Bluesky の投稿・検索リンクも表示されます。

### 3.4 名前を変更する

トップ画面または部屋画面のメニューに表示されている**自分の名前そのものを押す**と、サインアウトせずに名前を変更できます。

- **部屋画面から変更した名前は、その部屋の中だけで有効**です。
- ハッシュ値を付けている場合は、変更後の名前でハッシュ値が再計算されます。

### 3.5 ソーシャルリンクの表示設定

部屋画面のメニューで自分の名前を押すと、**入室者一覧に表示するソーシャルリンクの URL と表示の有無**を設定できます。部屋内で名前を変更している場合や、名前にハッシュ値を付けている場合でも、この設定に従って表示されます。

### 3.6 サインオーバー（別ブラウザーへの引き継ぎ）

サインイン状態を別のブラウザーや端末へ引き継ぐ機能です。

1. トップ画面または部屋画面のメニューから「サインオーバー」を選びます。
2. 表示された URL を「URL をコピーする」ボタンでコピーするか、QR コードを読み取ります。
3. **1 時間以内**に引き継ぎ先のブラウザーでその URL を開きます。

> **注意:** この URL を知っていれば誰でもサインイン状態を引き継げます。第三者に教えないでください。

## 4. トップ画面の使い方

トップ画面には、公開中の部屋一覧・更新情報・各種メニューが表示されます。

### 4.1 部屋一覧

各部屋について次の情報が表示されます。

- 部屋名（ハッシュタグ検索・投稿用の Twitter / Bluesky リンク付き）
- 説明
- アイコン画像
- 出題日時
- 入室者名（自分の名前は識別できるように表示されます）

#### 表示順の切り替え

ドロップダウンリストから選べます。いずれも日時の降順です。

| 表示順 | 基準 |
|---|---|
| 作成順 | 部屋の作成日時が新しい順 |
| 更新順 | 部屋の更新日時が新しい順 |

#### 自入室フィルター

部屋一覧の先頭にあるボタンを押してオンにすると、**自分が入室している部屋だけ**が表示されます。もう一度押すとオフに戻ります。

### 4.2 更新情報

「**更新情報を見る**」ボタンを押すと、これまでの更新履歴がダイアログウィンドウで表示されます。更新情報には、AI で試験的に生成された「bǃgǃrǃ ユーザーマニュアル」へのリンクも含まれます（本書もその仕組みで生成されています）。

### 4.3 メニュー

トップ画面のメニューからは次の操作ができます。

- 名前の変更（自分の名前を押す）
- サインオーバー
- サインアウト
- 部屋を作成する
- GitHub ディスカッションへのリンク（要望・質問はこちら）
- Atom フィード（第 20 章）

## 5. 部屋に入室する

1. トップ画面の部屋一覧から参加したい部屋を選びます。
2. パスワードが設定されている部屋では、入室時にパスワードを入力します。
3. 部屋にグループが設定されている場合は、**グループを選ぶ画面**が表示されます（第 13 章）。
4. 入室すると、現在のフェーズに応じた画面が表示されます。

部屋作成者が出題者・回答者・投票者を限定している部屋では、指定されていない利用者はその操作を行えません。参加方法が分からないときは部屋の説明や部屋コメントを確認してください。

## 6. 部屋を作成する

トップ画面から部屋作成画面を開き、部屋名・説明・アイコン画像とゲームのルール（第 7 章）を設定します。

### 6.1 基本項目

| 項目 | 内容 |
|---|---|
| 部屋名 | 部屋一覧や部屋画面に表示される名前。ハッシュタグの検索・投稿リンクにも使われます |
| パスワード | 設定すると入室に合言葉が必要になります |
| 説明 | 部屋の目的やローカルルールを記述。**文中の URL は自動的にリンクになります** |
| アイコン画像 | 部屋画面の右下に常時表示される画像。部屋一覧にも表示されます。容量制限があります |

### 6.2 作成履歴の再利用

部屋名の横の**履歴ボタン**から、同じブラウザーで以前作成した部屋の設定を呼び出せます。

- 履歴には作成日時と部屋名が一覧表示されます。
- 「読み込む」で設定をフォームに反映、「削除する」で履歴を削除できます。
- 同じ部屋名で複数回作成した場合、履歴には**最新の設定だけ**が残ります。
- アイコン画像を含む直近の設定値が、次回作成時の初期値になります。

### 6.3 未出題の部屋の作成制限

- 通常のサインインでは、**まだ出題していない部屋は 1 つまで**しか作成できません。
- Twitter サインイン時は複数作成できます。

「部屋を作成できない」場合は、未出題の部屋が残っていないか確認してください。

## 7. 部屋設定の全項目

部屋作成画面の設定は、権限・表示・進行に直接影響します。開始前に参加者へルールを案内することをおすすめします。

なお、設定に従わないアクセス（役割・回答数制限・投票数制限に反する操作）はサーバー側でブロックされ、場合によっては**自動的に受刑者へ追加**されます（第 15.4 節）。

### 7.1 出題者制限・回答者制限・投票者制限

それぞれの役割について、初期値としての制限を設定します。

| 設定値 | 動作 |
|---|---|
| 無し | 誰でもその操作を行えます |
| 有り | 制限が有効になります（入室者一覧での個別指定が前提） |
| 有り（Sign in with Twitter） | Twitter サインインしている入室者に限定されます |

> **重要:** 部屋作成後に入室者一覧で出題者・回答者・投票者を個別に追加・削除した場合、**その役割については個別指定が優先され、部屋作成画面の設定は無視されます。**

### 7.2 出題に関する設定

| 項目 | 内容 |
|---|---|
| 出題画像制限 | お題への画像添付を禁止できます |
| 出題優先時間 | 結果発表後の一定時間、特定の人だけが出題できるようにします。設定値は「無し」「有り（投票者内 1 位）」「有り（部屋作成者）」 |

出題優先時間の詳細:

- 「有り（投票者内 1 位）」— **前回の投票者のうち 1 位だった回答者**が優先されます。投票していない回答者は優先されません。
- 「有り（部屋作成者）」— 指定時間の間、部屋作成者のみが出題できます。
- 優先時間中は、優先される人の「**出題する**」ボタンが明滅します。
- 部屋作成者は優先時間を途中で締め切れます。

### 7.3 回答に関する設定

| 項目 | 内容 |
|---|---|
| 回答数制限 | 1 つのお題に 1 人が投稿できる回答数を制限します |
| 回答時間制限 | 回答フェーズの制限時間を設定します |
| 回答者名表示 | 回答者名の表示方法（記名・匿名・締切後表示など）。**どの設定でも自分の回答の名前は自分に常に表示されます** |
| 回答表示 | 「即時」= 都度表示 / 「一斉」= 締切後に一括表示 |
| 回答シャッフル時間 | 有り（秒）にすると、指定時間内の回答が投票フェーズで**入室者ごとに異なるランダムな順序**で表示されます。秒数を空にすると全回答が対象です。結果フェーズの順序には影響しません |
| 回答描画 | 回答への手描き線画の利用を制限できます |
| 回答コメント制限 | 「制限無し」または「部屋作成者のみ」の 2 択です |

### 7.4 投票に関する設定

| 項目 | 内容 |
|---|---|
| 投票時間制限 | 投票フェーズの制限時間。「回答毎 × 秒」を設定すると回答数に比例した時間が加算されます |
| 投票者名表示 | 投票者名の表示方法（常に非表示・締切後表示・記名など）。**自分の投票の名前は自分に常に表示されます** |
| 投票表示 | 「即時」= 都度反映 / 「一斉」= 締切後に反映。一斉の場合は投票フェーズ開始後に投票できます |
| 投票数制限（出題毎） | 1 つのお題全体で 1 人が使える票数。「有り（超過可）」を選ぶと、制限到達後も投票画面から超過投票できます（ボタン表記は変わります） |
| 投票数制限（回答毎） | 1 つの回答に入れられる票数を制限します |
| 自回答投票 | 自分の回答への投票を許可するかどうか |
| 投票グループ | 投票フェーズで表示する回答の範囲をグループ単位で決めます（第 13.5 節） |

### 7.5 コメント・表示に関する設定

| 項目 | 内容 |
|---|---|
| 出題コメント制限 | 「制限無し」または「部屋作成者のみ」の 2 択です |
| カラースキーム | 部屋のデフォルト配色を「ライト」「ダーク」から選びます（第 17 章） |

## 8. 出題する

部屋の作成直後、または前回の結果が確定した後に「**出題する**」ボタンからお題を投稿します。

### 8.1 本文の入力

- 本文は**最大 1500 文字**です。
- 複数行の入力フィールドは、入力行数に応じて自動的に伸びます。
- 投稿されたお題は、**150 文字を超えた位置**と **10 行を超えた位置**で折りたたまれ、残りを表すボタンが表示されます。押すと続きが開きます。
- 文字数を超過するとエラーメッセージが表示されます。

### 8.2 画像を付ける

部屋設定の「出題画像制限」で禁止されていなければ、お題に画像を添付できます。

- 本文が未入力の場合、**画像のファイル名が本文の初期値**になります。
- 出題画像の背景色は白（ライト配色の背景色と同じ）です。

### 8.3 出典を入力する

お題には**出典**欄があります。著作物をお題に使う場合は、適切な出典を入力してください。

### 8.4 送信する

送信ボタンのほか、入力欄で次のキー操作でも送信できます。

- `Ctrl` + 改行
- メタキー（`Windows` / `Command`）+ 改行

改行キー単独では送信されません。複数の利用者が同時に出題した場合は競合処理が行われるため、投稿後に現在のお題を確認してください。

## 9. 回答する

回答フェーズで「**回答する**」ボタンを押して回答を投稿します。

### 9.1 本文の入力

- 回答は**最大 1500 文字**です。入力フィールドは行数に応じて伸張します。
- 投稿された回答は 150 文字・10 行を超えた位置で折りたたまれ、残りを表すボタンで全文を表示できます。
- `Ctrl` + 改行、またはメタキー + 改行でも送信できます。
- 回答表示が「即時」の部屋では、回答数がリアルタイムに表示されます。
- 回答フェーズでは、自分の回答数が画面に併記されます。

### 9.2 回答描画（手描き線画）

部屋設定で許可されている場合、回答に**手描きの線画**を添えられます。スマートフォンなどのタッチ操作にも対応しています。描画データのサンプルレートは毎秒 30 ポイント以下に抑えられています。

### 9.3 回答の変更と削除

- 「**回答を変更する**」ボタンで投稿済みの回答を編集できます。変更すると**回答時刻も更新**されます。
- 回答を削除した直後に再び回答する場合、**削除した内容が回答欄の初期値**として設定されます。書き直しに便利です。
- 回答表示が「一斉」の部屋では、締め切りまで他の参加者の回答は見えません。

## 10. 投票する

投票フェーズで回答を確認し、「**投票する**」ボタンから票数を指定して投票します。使える総票数・1 回答あたりの票数・自回答への投票可否は部屋設定によって異なります。

### 10.1 通常の投票

1. 投票したい回答の「投票する」ボタンを押します。
2. ダイアログウィンドウの**投票数ボタン**で票数を指定します。
3. 送信して確定します。

投票画面を開くと投票数ボタンに**初期フォーカス**が当たっています。フォーカス中は次のキー操作が使えます。

| キー | 操作 |
|---|---|
| スペース | 1 票増やす |
| デリート | 1 票減らす |
| 改行 | 送信する |

ダイアログ上のボタンにもタイマーが表示されるため、残り時間を確認しながら投票できます。

### 10.2 0 票クイック投票

「投票する」ボタンの横にある「**0**」ボタンを押すと、画面を開かずに **0 票を投票**できます。「読んだことを示したい」場合などに使えます。投票画面から 0 票を指定して投票することもできます。

### 10.3 投票の変更と削除

- 「**投票を変更する**」ボタンから、既存の投票を削除せずに票数を増減できます。
- 投票を削除することもできます。
- 投票数制限（出題毎）を使い切ると、「投票する」ボタンが**投票一覧（投票を見る）ボタン**に変わります。不要な投票を削除して配分し直してください。
- 「有り（超過可）」の部屋では、制限到達後も投票画面から制限を超えて投票できます。

### 10.4 投票を見る

- 回答一覧の上部にある「**投票を見る**」ボタンを押すと、**自分が投票した回答だけ**が表示されます（自投票フィルターと同等です）。
- この画面には**投票数の合計**と、その横に**投票数制限（出題毎）**が表示されます。お題も表示されます。
- 回答ごとの得票数の表示を押すと、その回答について**自分が入れた投票だけ**が表示されます（回答毎の自投票フィルター）。
- 0 票を投票した場合、および投票数制限（出題毎）が「有り（超過可）」の場合は、投票を見る画面が末尾までスクロールします。

### 10.5 投票の表示順

回答ごとに表示される投票は**投票数の降順**です。投票数が同じ場合は投票順（早い順）です。

## 11. 結果・順位・Zスコア

投票が締め切られると結果フェーズになります。回答・得票数・順位・回答者名・投票者名が部屋設定に従って表示されます。

### 11.1 順位の決まり方

次の優先順位で比較されます。

1. **得票数**が多い回答が上位
2. 得票数が同じ場合、その**回答者自身の投票数**が多い回答が上位
3. それも同じ場合、**回答時刻が早い**回答が上位

### 11.2 Zスコアによる順位の装飾

回答者の投票数で補正した得票数（補正得票数）の **Zスコア**に応じて、順位に装飾が付きます。

| Zスコア | 表示 |
|---|---|
| +1 以上 | 順位に**下線** |
| +2 以上 | **ユニコーン🦄** 1 つ。さらに 1 上がるごとに 1 つ増加 |
| −1 以下 | 順位に**上線** |
| −2 以下 | **アイスクリーム🍦** 1 つ。さらに 1 下がるごとに 1 つ増加 |

Zスコアは、その回の中で自分の回答がどれだけ際立っていたか（埋もれていたか）を示す指標です。参加人数や総票数が異なる回同士でも比較できます。

### 11.3 ユニコーンの累計

その部屋で獲得したユニコーン🦄の累計は、**部屋画面のメニューバー**と**入室者一覧**に表示されます。入室者一覧では「多🦄順」「少🦄順」での並べ替えもできます。

## 12. コメントとリアクション

### 12.1 部屋コメント

部屋作成者が部屋トップの上部に表示するコメントです。

- 部屋作成者はいつでも投稿・表示できます。
- 削除操作を行うと、全件ではなく**最新の 1 件だけ**が削除されます。

### 12.2 出題コメント・回答コメント

**結果フェーズ**に、お題や個々の回答へコメントできます。

- 投稿できる人は部屋設定の「出題コメント制限」「回答コメント制限」に従います（制限無し / 部屋作成者のみ）。
- 過去の結果画面でも閲覧・投稿できます。
- **投稿した出題コメント・回答コメントは削除できません。**
- 空文字列のコメントも投稿できます。

### 12.3 クイックコメント（リアクション）

コメントボタンの横にある**スマイルボタン**を押し、ドロップダウンリストから絵文字を選ぶと、その絵文字をコメントとして素早く投稿できます。

- 絵文字は現在 8 種類。更新で入れ替わることがあります。
- 出題コメント・回答コメントのどちらでも使えます。

## 13. グループ機能

グループは、部屋の入室者をチームのようにまとめる機能です。**作成された部屋の中でのみ有効**です。

### 13.1 グループの作成と管理

部屋作成者は「**グループを選ぶ**」画面からグループを追加・削除できます。

- グループ名は**重複可能**で、**空文字列も許可**されます。
- グループには**説明**を設定できます。
- グループ名の横の**履歴ボタン**から、同じブラウザーで作成したグループ設定の一覧を表示し、「読み込む」「削除する」を実行できます。同じグループ名の履歴は最新の設定だけが残ります。
- グループを選ぶ画面には、各グループに入っている入室者名が表示されます。

### 13.2 グループを選ぶ

次の場合、入室者にグループを選ぶ画面が表示されます。

- 部屋作成者がグループを追加した時点で、どのグループにも入っていない場合
- グループ追加後に部屋へ入室した場合
- 自分が入っていたグループが削除された場合

自分のグループは、グループを選ぶ画面から**いつでも変更できます**。

### 13.3 グループ分離

**部屋作成者がグループを追加すると、常にグループ分離が有効になります。**

- 回答・投票フェーズでは、**自分のグループ以外の回答者の回答は表示されません**。
- 投票時間制限の「回答毎 ×」には、全体の回答数ではなく**最も回答数の多いグループの回答数**が使われます。
- グループが 1 つもない場合は、分離なしと同じ動作になります。
- 結果フェーズでは全グループの回答が表示されます（グループフィルターで絞り込み可能）。

### 13.4 グループ名が表示される場所

| 場所 | 表示 |
|---|---|
| メニューバー | 自分の名前の前に自分のグループ名 |
| メイン画面・過去の結果画面 | 回答者名の前に回答者のグループ名 |
| 入室者一覧 | 入室者名の前に入室者のグループ名 |
| ログ（CSV） | 回答者名カラムで名前の前にグループ名と改行。さらに 9 番目のカラムにグループ名 |

### 13.5 投票グループ

部屋設定の「投票グループ」で、投票フェーズに表示される回答の範囲を変えられます。

| 設定値 | 投票フェーズに表示される回答 |
|---|---|
| 無し | 通常の範囲（グループ分離に従う） |
| グループ内に投票 | 自分と**同じ**グループの回答だけ |
| 有り（次グループに投票） | **自分のグループの直後に作成されたグループ**の回答だけ |

- 「有り（次グループに投票）」で自分のグループが最後の場合は、**最初に作成されたグループ**が対象になります。
- グループを選んでいない場合は、グループ未選択の人の回答だけが表示されます。
- この設定時、投票時間制限の「回答毎 ×」には**表示される回答数が最も多いグループの回答数**が採用されます。
- グループが作成されていなければ、設定なしと同じ動作になります。
- 投票グループが「無し」の部屋では、部屋画面にグループ毎の回答数は表示されません。

### 13.6 グループフィルター

結果フェーズと過去の結果画面で**グループ名を押す**と、そのグループの回答だけが表示されます（セカンダリーフィルター。第 14 章）。

## 14. フィルターと表示順

フィルターは**表示だけを切り替える**機能です。回答・投票・コメントそのものが消えることはありません。

### 14.1 プライマリーフィルター

自回答・自投票・自コメントの 3 つはプライマリーフィルターとして動作します。

| フィルター | 表示内容 | 使える画面 |
|---|---|---|
| 自回答フィルター | 自分の回答だけ | 回答・投票・結果フェーズ、過去の結果 |
| 自投票フィルター | 自分が投票した回答だけ | 投票・結果フェーズ、過去の結果 |
| 自コメントフィルター | 自分がコメントした回答だけ | 結果フェーズ、過去の結果 |
| 回答毎の自投票フィルター | 押した回答について自分の投票だけ | 投票の表示 |

- フィルターボタンは回答一覧の先頭にあり、**下方へスクロールしても表示され続けます**。
- 回答フェーズでは自回答数、投票フェーズでは自投票数が併記されます。
- 投票フェーズでは回答一覧上部の「投票を見る」ボタンも、自投票フィルターと同等に機能します。

### 14.2 セカンダリーフィルター

プライマリーフィルターと**併用できる**フィルターです。

- **グループフィルター** — 結果フェーズ・過去の結果でグループ名を押し、そのグループの回答だけを表示します。
- **回答ピックアップ** — 回答のボタンを押すとその回答だけの表示になり、もう一度押すと元に戻ります。結果フェーズと過去の結果画面で使えます。

フィルターボタンや「URL をコピーする」ボタンは**オンとオフでデザインが異なります**。現在の状態を確認してから操作してください。「回答が表示されない」ときは、フィルターがオンになっていないかをまず確認してください。

### 14.3 回答の表示順

回答一覧のドロップダウンリストから選べます。

| 表示順 | 基準 | 使える画面 |
|---|---|---|
| 設定順 | 部屋設定のデフォルト | 全フェーズ |
| 先着順 / 後着順 | 回答時刻 | 全フェーズ |
| 上位順 / 下位順 | 順位 | 全フェーズ |
| コ多順 / コ少順 | コメント数 | 結果フェーズ、過去の結果 |

## 15. 入室者一覧と部屋の管理

部屋画面の「**入室者を見る**」ボタンから入室者一覧を開きます。

### 15.1 一覧で確認できる情報

- **入室者数**
- 名前（グループ名が前に付きます）
- **ディスクリミネーター** — 入室者ごとに割り当てられる 8 文字の英数字。同名の入室者を区別できます
- その部屋で獲得した**ユニコーン🦄の累計**
- ソーシャルサインインしている入室者のプロフィール画像とリンク（各入室者の設定に従います）
- **受刑者**は取り消し線付きで表示されます

退室した入室者でも、その部屋で出題・回答・投票を行っていれば一覧に残ります。名前を押すと、その入室者の**トークン**（一覧右側に表示される文字列）を確認できます。

### 15.2 入室者の表示順

ドロップダウンリストから選べます。

| 表示順 | 基準 |
|---|---|
| 先入順 / 後入順 | 入室日時（古い順 / 新しい順） |
| 古サ順 / 新サ順 | サインイン日時（古い順 / 新しい順） |
| 多🦄順 / 少🦄順 | ユニコーン獲得数 |
| 昇名順 / 降名順 | 名前の Unicode 値 |
| 昇Di順 / 降Di順 | ディスクリミネーターの Unicode 値 |

### 15.3 出題者・回答者・投票者の指定

部屋作成者は、入室者を**出題者・回答者・投票者**に追加・削除できます。部屋作成者自身も指定の対象です。

- 個別指定を行った役割については、**部屋作成画面の制限設定は無視されます**。
- どの役割にも誰も設定しなければ、制限なしの状態に戻ります。
- 画面幅の狭いブラウザーでは、操作ボタン群を開閉して使えます。

### 15.4 受刑者（強制退室）

部屋作成者は入室者を**受刑者**に追加して強制退室させられます。解除も可能です。

- 受刑者は一覧で取り消し線付きになります。
- 受刑者に追加すると、**同一の発信元から出題・回答・投票・コメントする入室者も追加**されます。
- 部屋設定に従わない不正なアクセスで出題・回答・投票・コメントを行おうとした入室者は、**自動的に受刑者に追加**されます。

## 16. 過去の結果とログ（CSV）

### 16.1 過去の結果

部屋のメニューから「過去の結果」を開くと、**34.5 日以内の出題**について、お題・回答・得票数・順位・コメントを確認できます。表示順・プライマリーフィルター・グループフィルター・回答ピックアップも利用できます。

### 16.2 ログ（CSV）のダウンロード

1. 部屋のログ（CSV）画面を開きます（**その部屋に入室している必要があります**）。
2. ダウンロードしたい CSV の **URL を選択**します（選択するまでダウンロードは始まりません）。
3. サーバーが処理中の場合は処理中の表示が出ます。完了まで待ってください。
4. ダウンロードしたファイルを表計算ソフトなどで開きます。

対象は 34.5 日以内の出題です。部屋自体は最終更新から 11.5 日で終了するため、記録が必要な場合は早めに取得してください。

### 16.3 CSV の識別情報

ダウンロードできる CSV は 2 種類です。

- **通常の CSV** — 名前をそのまま出力します。
- **ディスクリミネーター付き CSV** — 名前の後に改行とディスクリミネーターを付けて出力します。名前にハッシュ値を付けている場合は、ハッシュ値の後にディスクリミネーターが付きます。

グループを使っている場合、回答者名カラムでは名前の前にグループ名と改行が入り、さらに**9 番目のカラム**にグループ名が出力されます。

## 21. 動作環境とトラブルシューティング

### 21.1 対応環境

- 対象ブラウザーの言語仕様は **ECMAScript® 2022** です。
- 次のブラウザーは非対応です。
  - Internet Explorer 10 / 11
  - Microsoft Edge 16 未満（Legacy Edge）
  - Firefox 60 未満
  - Safari 12 未満
  - iOS Safari 12 未満
  - Chrome 60 未満
- 対応バージョンは随時引き上げられています。最新版のブラウザーの利用を推奨します。

### 21.2 現在の暫定措置・お知らせ

- **Safari 26.4 / 26.5** — 不定期のデータ取得遅延に対処するため、Safari について一時的に通信機能を変更しています。
- **Twitter サインイン** — 画面遷移に暫定的な措置が適用されています。予告なく終了する場合があります。
- **Bluesky サインイン** — 試験稼動中です。

### 21.3 操作できないときのチェックリスト

1. 対応ブラウザーの最新版を使っていますか。内部構成が変わる更新の後は**ブラウザーのリロード**が必要な場合があります。
2. サインインと入室が完了していますか（パスワード付きの部屋ではパスワードが必要です）。
3. 現在のフェーズは目的の操作に合っていますか（回答は回答フェーズ、投票は投票フェーズ、コメントは結果フェーズ）。
4. 回答時間制限・投票時間制限が終了していませんか。
5. 出題者・回答者・投票者として許可されていますか。入室者一覧での個別指定は部屋設定より優先されます。
6. 回答数制限・投票数制限の上限に達していませんか。投票一覧から削除して配分し直せます。
7. 出題優先時間中ではありませんか。優先される人以外は出題できません。
8. グループ分離や投票グループにより、対象の回答が非表示になっていませんか。
9. フィルター（自回答・自投票・自コメント・グループ・ピックアップ）がオンになっていませんか。ボタンのデザインでオン・オフを確認できます。
10. 「集計中」「処理中」の表示が出ていませんか。完了まで待ってください。

### 21.4 受刑者にされた場合

部屋作成者が解除するまで、その部屋には入室できません。設定に反する操作や、受刑者と同一の発信元からの操作でも自動的に追加されることがあります。
