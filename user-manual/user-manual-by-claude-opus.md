## 1. bǃgǃrǃ の概要

### 1.1 できること

- 誰でも**部屋**を作って、大喜利の会を開けます。
- 部屋の中で**出題**（お題の投稿）、**回答**（ボケの投稿）、**投票**、**結果発表**を繰り返せます。
- お題に画像を付けたり、回答に手描きの線画（**回答描画**）を付けたりできます。
- 時間制限、回答数・投票数の制限、匿名表示、グループ分けなど、細かいルールを部屋ごとに設定できます。
- 結果には順位と、統計的に目立った回答に付くマーク（🦄 ユニコーン / 🍦 アイスクリーム）が表示されます。
- 過去の結果の閲覧やログ（CSV）のダウンロードができます。

### 1.2 必要なもの

- 最近のウェブブラウザー（詳しくは [18.5 動作環境](#185-動作環境)）
- アカウント登録は不要です。名前を決めるだけで「新規サインイン」できます。Twitter または Bluesky のアカウントを使う「ソーシャルサインイン」も使えます。

### 1.3 お問い合わせ・情報源

トップ画面の上部に、次の連絡先とリンクが並んでいます。

- メールアドレス
- Bluesky アカウント
- Twitter アカウント
- 「使用方法」欄: AI が生成した「bǃgǃrǃ ユーザーマニュアル」へのリンクと、質問・提案を受け付ける GitHub の「ディスカッション」へのリンク

## 2. ゲームの流れと役割

### 2.1 1回の出題の流れ

1回の出題（画面では「第n回」）は、次の3つのフェーズで進みます。

```
 ┌────────────┐   締め切り   ┌────────────┐   締め切り   ┌────────────┐
 │ 回答フェーズ │ ─────────→ │ 投票フェーズ │ ─────────→ │ 結果フェーズ │
 └────────────┘ (集計中…)   └────────────┘ (集計中…)   └────────────┘
       ↑                                                       │
       └──────────────── 次の出題（第n+1回）───────────────────┘
```

| フェーズ | 何をするか | 締め切り方 |
|---|---|---|
| **回答フェーズ** | 出題に対して回答を投稿します。 | 部屋作成者の「回答を締め切る」ボタン、または回答時間制限の経過 |
| **投票フェーズ** | 回答に票を入れます。 | 部屋作成者の「投票を締め切る」ボタン、または投票時間制限の経過 |
| **結果フェーズ** | 順位と投票者が公開され、コメントやリアクションができます。 | 誰か（出題できる人）が次の出題をすると、次の回の回答フェーズが始まります |

フェーズが切り替わる間は、フェーズ名の位置に処理中を表すスピナー（くるくる回るマーク）が表示されます。

> **補足**: 部屋の設定で「回答表示」「投票表示」をどちらも「即時」にした場合は、回答フェーズのうちから投票できます。詳しくは [10.6 即時表示の部屋での投票](#106-即時表示の部屋での投票) を参照してください。

### 2.2 役割

| 役割 | 説明 |
|---|---|
| **部屋作成者** | 部屋を作った人です。締め切りの操作、部屋コメント、グループの作成・削除、入室者の役割設定、部屋の削除ができます。 |
| **出題者** | 出題できる人です。「出題者制限」で絞り込めます。 |
| **回答者** | 回答できる人です。「回答者制限」で絞り込めます。 |
| **投票者** | 投票できる人です。「投票者制限」で絞り込めます。 |
| **受刑者** | 部屋作成者によって出入りを禁止された人です。強制的に退室させられます。 |
| **入室者** | 部屋に入った人全員です。 |

制限を設けなければ、入室者は誰でも出題・回答・投票ができます。

## 3. サインインとアカウント

### 3.1 サインイン方法の種類

トップ画面右上の「サインイン」を押すと「サインイン」画面が開きます。

| 区分 | ボタン | 説明 |
|---|---|---|
| サインイン | **新規サインイン** | 名前を入力するだけでサインインします。 |
| ソーシャルサインイン | **Twitterでサインイン** | Twitter のアカウントでサインインします。 |
| ソーシャルサインイン | **Blueskyでサインイン** | Bluesky のアカウント（OAuth）でサインインします。 |

#### 新規サインイン

1. 「新規サインイン」ボタンを押します。
2. 「名前を設定する」画面が開きます。名前欄には最初から「お客さん」と入っています。
3. 好きな名前に書き換えて「設定する」を押します。
4. 状況によっては reCAPTCHA（ロボットでないことの確認）が表示されます。案内に従ってください。

#### Twitterでサインイン

「Twitterでサインイン」を押し、Twitter の認証画面で許可します。

- Twitter でのサインインについては、画面遷移を変える一時的な措置が取られています。この措置は予告なく終わることがあります。
- うまくいかない場合は [20章](#20-よくある質問トラブルシューティング) を参照してください。

#### Blueskyでサインイン

1. 「Blueskyでサインイン」を押します。
2. 「Blueskyでサインイン」画面の「ハンドル」欄に、@ より後ろの部分（例: `alice.bsky.social`）を入力します。
3. 「サインイン」を押し、Bluesky 側の画面で許可します。

Bluesky サインインは試験稼動として始まった機能です。

### 3.2 ソーシャルサインインの利点

- 画面右上の名前の横に、Twitter / Bluesky のアイコンとプロフィール画像が表示されます。
- 「入室者を見る」画面で、名前の横にアカウントへのリンクが表示されます。
- 部屋の設定で「有り（ソーシャルサインイン）」に制限された出題・回答・投票に参加できます。
- 出題していない部屋を複数持てます（新規サインインでは1つまで。[5.1](#51-部屋を作成できる条件) を参照）。
- サインアウトした後も、同じアカウントで再びサインインすれば同じ状態に戻れます。

### 3.3 名前を変更する

名前は2か所で変えられます。

| 変更する場所 | 操作 | 効果が及ぶ範囲 |
|---|---|---|
| トップ画面 | 右上の**自分の名前**を押す →「名前を変更する」画面 | サインインでの名前（全体） |
| 部屋画面 | メニューバーの**自分の名前**を押す →「名前やリンクを変更する」画面 | その部屋の中だけ |

#### 部屋ごとの名前とリンク

「名前やリンクを変更する」画面では次のことができます。

- **名前**: その部屋だけで使う名前を入力します。空欄にするとサインインでの名前が使われます（欄内に薄く表示されています）。
- **リンク**: 「入室者を見る」画面で名前の横に出すリンクを設定します。
  - 「無し」: リンクを表示しません。
  - 「有り（URL）」: 入力した URL を表示します。Twitter・Bluesky・X の URL にはそれぞれのアイコンが、それ以外の URL には人型のアイコンが付きます。

### 3.4 名前にハッシュ値を付ける（なりすまし対策）

名前の後ろに `#` と好きな文字列（合言葉）を付けると、`#` 以降が8文字のハッシュ値（暗号学的ハッシュ関数の値）に変換されて表示されます。

```
びぎりちゃん        → びぎりちゃん
びぎりちゃん#abc    → びぎりちゃん#DnbJh2JQ
```

同じ合言葉を使えば毎回同じハッシュ値になるので、他の人が同じ名前を名乗っても本人かどうか見分けられます。合言葉そのものは表示されません。

### 3.5 サインオーバー（別のブラウザーへの引き継ぎ）

パソコンで使っていたサインイン状態をスマートフォンへ移す、といったときに使います。

1. トップ画面または部屋画面のメニューから「**サインオーバー**」を押します。
2. 引き継ぎ用のリンクと QR コードが表示されます。「**URLをコピーする**」ボタンでリンクをコピーできます（コピーするとアイコンが塗りつぶし表示に変わります）。
3. 引き継ぎ先のブラウザーで、**1時間以内**にリンクまたは QR コードを開きます。
4. 「サインオーバー元からサインイン状態を引き継いでサインインします。」と表示されたら「サインイン」を押します。

> **注意**: 引き継ぎ用のリンクを知っている人は、あなたとしてサインインできます。他人に見せないでください。

### 3.6 サインアウト

トップ画面右上の「サインアウト」を押し、確認画面で「サインアウト」を押します。

> **重要**: 新規サインインの場合、サインアウトすると**同じサインイン状態には戻れません**。後でまた使いたい場合は、先に「サインオーバー」で別のブラウザーへ引き継いでおくか、ソーシャルサインインを使ってください。

## 4. トップ画面

### 4.1 画面の構成

上から順に次のものが並んでいます。

1. **ナビゲーションバー**: 左に「bǃgǃrǃ」のロゴ、右にサインイン関連のメニューと自分の名前・プロフィール画像
2. **ヘッダー**: ロゴ、サブタイトル、連絡先
   - **更新情報**: 最近の更新の一覧と「**全更新情報を見る**」ボタン（全履歴をダイアログで表示）
   - **使用方法**: ユーザーマニュアルと GitHub ディスカッションへのリンク
3. **Atom フィード**: RSS アイコンのリンクで、新しい部屋の情報を購読できます（部屋作成者名も含まれます）。
4. **部屋一覧**: 見出し、「部屋を作成する」ボタン、ライセンス表記、部屋のカード

### 4.2 部屋一覧の並べ替え

一覧の右上にあるドロップダウンで表示順を選べます。どちらも新しいものが上に来ます。

| 表示順 | 意味 |
|---|---|
| 作成順 | 作成日時の新しい順 |
| 更新順 | 更新日時の新しい順（最近出題された部屋が上） |

### 4.3 自入室フィルター

並べ替えの横の**手のアイコン（🖖、バルカン式の挨拶の形）**を押すとオンになり、自分が入室している部屋だけが表示されます。オンのときはアイコンが塗りつぶし表示になります。もう一度押すと解除されます。

### 4.4 部屋カードの見方

部屋一覧の各カードには次の情報が表示されます。

- **共有リンク**
  - Twitter ボタン: 部屋名と説明の1行目、部屋へのリンク、ハッシュタグ（#bǃgǃrǃ と、空白を除いた部屋名）入りの投稿画面を開きます。
  - 隣の部屋名リンク: Twitter で部屋名を検索します。
  - Bluesky ボタンとリンク: 同じ内容を Bluesky で投稿・検索します。
- **部屋名**と**説明**（説明の中の URL は自動でリンクになります）
- **アイコン画像**（設定されている場合）
- **設定の一覧表**: 作成者、作成日時、入室制限、出題・回答・投票の各設定（内容は [6章](#6-部屋設定リファレンス) を参照）
- **ボタン**
  - 「**入室する**」: 部屋に入ります。
  - 「**部屋を削除する**」: 部屋作成者にだけ表示されます。
- **カード下部**: 更新日時と、入室者の名前の一覧（自分の名前は色が変わります）

### 4.5 ライセンス

部屋一覧の見出しの下に、クリエイティブ・コモンズ・ライセンスが掲示されています。部屋の中で特に注記がない作品は、**クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）**のもとで利用できます。

## 5. 部屋を作成する

### 5.1 部屋を作成できる条件

- サインインしていない場合は、「部屋を作成する」を押すとまずサインイン画面が開きます。
- **新規サインイン**の場合、**まだ一度も出題されていない部屋は1つまで**しか持てません。その部屋で出題すれば、次の部屋を作れるようになります。
- **ソーシャルサインイン**の場合は、未出題の部屋を複数作れます。

### 5.2 作成手順

1. トップ画面で「**部屋を作成する**」を押します。
2. 「部屋を作成する」画面で各項目を入力します（[6章](#6-部屋設定リファレンス)）。
3. 画面下の「**部屋を作成する**」を押します。

作成画面には、前回作成したときの設定（アイコン画像を含む）が最初から入っています。

### 5.3 履歴機能

部屋名の横の「**履歴を見る**」ボタンを押すと、**同じブラウザー**でこれまでに作った部屋の設定一覧が作成日時とともに表示されます。

- 「**履歴を読み込む**」: その設定を作成画面に読み込みます。
- 「**履歴を削除する**」: その履歴を消します。
- 同じ部屋名で作り直した場合、履歴には最新の設定だけが残ります。
- 履歴がないときは「履歴を見る」ボタンは押せません。

### 5.4 部屋を削除する

トップ画面の部屋カードにある「**部屋を削除する**」（部屋作成者のみ）を押し、確認画面で「削除する」を押します。

### 5.5 部屋の存続期間

部屋は**最終更新日時から11.5日間**存続します。出題が続いている部屋はその都度更新されます。

## 6. 部屋設定リファレンス

「部屋を作成する」画面の項目は、区切り線で「部屋の基本」「出題」「回答」「投票」の4つに分かれています。部屋画面や部屋一覧の設定表では「有り 30秒」のように短く表示されます。

### 6.1 部屋の基本

| 項目 | 選択肢・入力 | 説明 |
|---|---|---|
| **部屋名** | テキスト | 部屋の名前です。横に「履歴を見る」ボタンがあります。 |
| **説明** | 複数行テキスト | 部屋の説明です。URL は自動でリンクになります。1行目は共有リンクの本文にも使われます。 |
| **アイコン画像** | 画像ファイル | 部屋画面の右下に常に表示され、部屋一覧のカードにも表示されます。大きな画像は自動で縮小されます。容量制限を超える場合や無効な画像の場合はエラーになります。「削除する」で外せます。 |
| **カラースキーム** | 無し / ライト / ダーク | 部屋の既定の配色です。「無し」はブラウザーや OS の設定に従います。 |
| **入室制限** | 無し / 有り（パスワード） | 「有り」にすると、入室時にパスワードを求めます。 |

### 6.2 出題に関する設定

| 項目 | 選択肢 | 説明 |
|---|---|---|
| **出題優先時間** | 無し / 有り（部屋作成者）（秒） / 有り（首位回答者）（秒） | 結果フェーズになってから指定した秒数のあいだ、出題できる人を限定します。詳しくは [12章](#12-出題優先時間)。 |
| **出題者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 出題できる人を制限します。[6.5](#65-出題者回答者投票者制限の考え方) を参照してください。 |
| **出題画像制限** | 無し / 有り（禁止） | 「有り（禁止）」にすると、出題に画像を付けられなくなります。 |
| **出題コメント制限** | 無し / 有り（部屋作成者） | 「有り」にすると、出題へのコメント・リアクションができるのは部屋作成者だけになります。 |

### 6.3 回答に関する設定

| 項目 | 選択肢 | 説明 |
|---|---|---|
| **回答表示** | 即時 / 一斉（投票フェーズまで非表示） | 「即時」は投稿された回答がすぐ全員に見えます。「一斉」は投票フェーズになるまで他の人の回答が見えません。 |
| **回答時間制限** | 無し / 有り（秒） | 回答フェーズの制限時間です。 |
| **回答シャッフル時間** | 無し / 有り（秒） | 出題からこの秒数以内に投稿された回答は、投票フェーズで**入室者ごとにランダムな順番**で表示されます。秒数を空欄にすると（表示は「∞」）すべての回答がシャッフルされます。結果フェーズでの順位には影響しません。 |
| **回答数制限** | 無し / 有り（答） | 1人が1回の出題に投稿できる回答の数です。 |
| **回答者名表示** | 表示 / 非表示 / 一斉（結果フェーズまで非表示） | 回答者の名前を表示するかどうかです。「非表示」は常に隠し、「一斉」は結果フェーズで公開します。 |
| **回答者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 回答できる人を制限します。 |
| **回答コメント制限** | 無し / 有り（部屋作成者） | 「有り」にすると、回答へのコメントは部屋作成者だけができます。 |
| **回答描画制限** | 無し / 有り（禁止） | 「有り（禁止）」にすると、回答に手描きの線画を付けられなくなります。 |

> **自分の名前は常に見えます**: 「回答者名表示」「投票者名表示」の設定にかかわらず、自分の回答・自分の投票に付く自分の名前は、自分の画面では常に表示されます。

### 6.4 投票に関する設定

| 項目 | 選択肢 | 説明 |
|---|---|---|
| **投票表示** | 即時 / 一斉（結果フェーズまで非表示） | 「即時」は票がすぐ反映されて見えます。「一斉」は結果フェーズまで票が見えず、投票は投票フェーズになってからできます。 |
| **投票時間制限** | 無し / 有り（出題毎+回答毎×）（秒） | 投票の制限時間を「基本の秒数 ＋ 回答1件あたりの秒数 × 回答数」で決めます。回答毎の欄を空にすると 0 秒として扱われます。 |
| **投票数制限（出題毎）** | 無し / 有り（票） / 有り（超過可）（票） | 1人が1回の出題で入れられる票の合計です。「超過可」については [10.4](#104-投票数の制限) を参照してください。 |
| **投票数制限（回答毎）** | 無し / 有り（票） | 1人が1つの回答に入れられる票の上限です。 |
| **投票者名表示** | 表示 / 非表示 / 一斉（結果フェーズまで非表示） | 誰がどの回答に投票したかを表示するかどうかです。 |
| **投票者制限（初期値）** | 無し / 有り / 有り（ソーシャルサインイン） | 投票できる人を制限します。 |
| **投票グループ制限** | 無し / 有り（自グループに投票） / 有り（次グループに投票） | グループがある場合に、投票フェーズで表示する回答を絞り込みます。詳しくは [15.4](#154-投票グループ制限) を参照してください。 |

#### 投票時間制限の計算例

「有り」で出題毎 60、回答毎 2 と入力し、回答が 25 件集まった場合:

```
60 + 2 × 25 = 110 秒
```

投票グループ制限を使っていてグループがある場合、「回答数」には全体の回答数ではなく、**各グループのうち表示される回答数が最も多いグループの回答数**が使われます。

### 6.5 出題者・回答者・投票者制限の考え方

これらの項目には「（初期値）」と付いています。部屋作成者は、後から「入室者を見る」画面で入室者を個別に出題者・回答者・投票者へ追加・削除できます（[16.3](#163-部屋作成者の管理操作)）。

| 設定値 | 誰ができるか |
|---|---|
| **無し** | 入室者全員 |
| **有り** | 最初は**誰もできません**。「入室者を見る」画面で追加した人だけができます。 |
| **有り（ソーシャルサインイン）** | Twitter または Bluesky でサインインしている人 |

- 「入室者を見る」画面で一度でも個別に追加すると、その項目は**追加した人だけ**に限定され、作成画面での設定は無視されます。
- 部屋作成者も自動では含まれません。「有り」にした場合、部屋作成者自身も必要に応じて自分を追加してください。
- 部屋画面の設定表では、個別に指定された人の名前、またはソーシャルサインインを表す Twitter・Bluesky のアイコンが「有り（…）」の中に表示されます。

## 8. 出題する

### 8.1 出題できるとき

「**出題する**」ボタンは次の場所に表示されます。

- 部屋にまだ出題がないとき（「出題はありません」の下）
- 結果フェーズのとき（画面上部）

出題者制限や出題優先時間によって、ボタンが表示されない、または押せないことがあります。

### 8.2 出題画面

「出題する」を押すと、次の項目がある画面が開きます。

| 項目 | 説明 |
|---|---|
| **出典** | お題の出典を入力します。URL は自動でリンクになります。 |
| **画像** | 「画像有り」ボタンを押して画像ファイルを選ぶと、お題に画像を付けられます。大きな画像は自動で縮小されます。「削除する」で外せます。出題画像制限が「有り（禁止）」の部屋では付けられません。 |
| **出題** | お題の本文です（最大1500文字）。 |

入力が終わったら「**出題する**」を押します。**Ctrl+Enter**（Windows キー／Command キー+Enter でも可）でも送信できます。

> **著作物の扱い**: 出題に著作物（画像や文章）を使う場合は、現行の著作権制度で許される形になるよう配慮し、適切な出典を入力してください。

### 8.3 長い出題の表示

10行または150文字を超える出題は、途中で折りたたまれます。続きの位置に表示される**⊞と残りの文字数**のボタンを押すと全文が表示され、⊟ を押すと再び折りたたまれます。

### 8.4 出題画像の表示

出題画像は白い背景の上に表示されます（ダーク配色でも透過部分が見やすいようにするためです）。画像を押すと拡大表示されます。

## 9. 回答する

### 9.1 回答の手順

1. 回答フェーズ中に「**回答する**」ボタンを押します。横には回答時間制限の残り時間を示す円形のタイマーが表示されます。
2. 「回答する」画面の上部にお題（長い場合は省略）と出題画像が表示されます。
3. 「回答」欄に入力します（最大1500文字）。入力欄は行数に合わせて自動で伸びます。
4. 「**回答する**」を押すか、**Ctrl+Enter**（Windows キー／Command キー+Enter でも可）で送信します。

直前に削除した回答があると、その内容が最初から回答欄に入っています。

### 9.2 回答描画（手描きの線画）

回答描画制限が「無し」の部屋では、回答に手描きの線画を付けられます。

1. 「回答する」画面で「**描画有り**」を押します。
2. 表示されたキャンバスに、マウス・指・ペンで線を描きます。
3. キャンバスの下のボタンで操作します。
   - **↶（元に戻す）**: 直前の線を取り消します。
   - **数字**: 描画の要素数です。
   - **↷（やり直す）**: 取り消した線を戻します。
4. 描画をやめるときは「**描画無し**」を押します。

描画付きの回答は、回答一覧で線画と文章が並んで表示されます。線画を押すと拡大表示されます。

### 9.3 回答の変更・削除

回答表示が「**一斉**」の部屋では、回答フェーズ中、自分の回答カードに次のボタンが表示されます。

- 「**回答を変更する**」: 内容を書き換えます。回答時刻も更新されます。
- 「**回答を削除する**」: 確認画面で「削除する」を押すと削除されます。

### 9.4 回答数の表示

- 回答一覧の右下に、✋ と回答の件数が表示されます。投票グループ制限で絞り込まれているときは「表示中の件数/全体の件数」になります。
- 回答フェーズでは、自回答フィルター（✋）ボタンの横に自分の回答数が表示されます。

### 9.5 回答カードの見方

| 部分 | 内容 |
|---|---|
| 左上 | 回答者名（回答者名表示の設定による。自分の回答は色が変わります） |
| 右上 | 回答番号 |
| 本文 | 回答（10行または150文字を超えると ⊞ で折りたたみ） |
| 右下 | 👍 と得票数、投票者の一覧、投票ボタン類 |
| 下部 | 結果フェーズではコメント欄 |

回答者名・投票者名・出題者名・コメント投稿者名を押すと、その人の**トークン**（入室者ごとに割り当てられた8文字の英数字）に切り替わります。もう一度押すと名前に戻ります。同じ名前の別人を見分けるときに便利です。

## 10. 投票する

### 10.1 投票の手順

1. 回答カードの「**投票する**」ボタンを押します。
2. 「投票する」画面に回答が表示されます。右側の投票数ボタンで票数を決めます。
   - **＋**: 1票増やします。
   - **－**: 1票減らします。
   - 中央の数字が現在の票数です。
3. 「**投票する**」を押します。

投票数の初期値は、制限の範囲内で投票できる場合は **1**、制限に達している場合は **0** です。既に投票している回答では、今の票数が初期値になります。

#### キーボード操作

「投票する」画面を開くと、投票数ボタンにフォーカスが当たっています。

| キー | 動作 |
|---|---|
| **スペース** | 1票増やす |
| **Delete** | 1票減らす |
| **Enter** | 投票を送信する |
| **Esc** | 画面を閉じる |

### 10.2 0票クイック投票

「投票する」ボタンの横にある「**👍0**」ボタンを押すと、画面を開かずにその回答へ **0票** を投票できます。「読んだ」という記録を残したいときなどに使えます。

### 10.3 投票の変更・削除

投票済みの回答には次のボタンが表示されます。

- 「**投票を変更する**」: 票数を増減します。いったん削除しなくても票を減らせます。
- 「**投票を削除する**」: 投票を取り消します。

### 10.4 投票数の制限

- **投票数制限（出題毎）「有り」**: 合計票数が上限に達すると、まだ投票していない回答の「投票する」ボタンが「**投票を見る**」ボタンに変わります。票を別の回答に移したいときは、「投票を見る」から既存の投票を減らしたり削除したりしてください。
- **投票数制限（出題毎）「有り（超過可）」**: 上限に達すると同じく「投票を見る」ボタンに変わりますが、「投票する」画面の中では上限を超えて票を入れられます。
- **投票数制限（回答毎）**: 1つの回答に入れられる票の上限です。上限に達すると ＋ ボタンが押せなくなります。

### 10.5 「投票を見る」画面

自分が投票した回答の一覧を確認できます。次の場所から開きます。

- 投票フェーズで回答一覧の上にある「**投票を見る**」ボタン（どれかの回答に投票すると押せるようになります）
- 上限に達した後の各回答の「投票を見る」ボタン

画面の内容:

- 投票した回答が票数の多い順に並びます。
- 各回答から「投票を変更する」「投票を削除する」「👍0」を操作できます。
- 一覧の末尾に**投票数の合計**が表示され、投票数制限（出題毎）がある場合は「合計/上限」の形になります。
- 回答ごとの投票者は票数の多い順に並び、票数が同じなら投票した順に並びます。

### 10.6 即時表示の部屋での投票

投票ボタンが使えるタイミングは、部屋の設定によって変わります。

| 回答表示 | 投票表示 | 投票できるタイミング | 投票時間制限の起点 |
|---|---|---|---|
| 即時 | 即時 | 回答フェーズ中から（回答が投稿された直後から） | **各回答の投稿時刻** |
| 即時 | 一斉 | 投票フェーズになってから | 投票フェーズの開始 |
| 一斉 | 即時／一斉 | 投票フェーズになってから | 投票フェーズの開始 |

投票時間制限がある場合、投票ボタンの横に小さな円形タイマーが表示されます。自分の回答（一斉表示の部屋で非公開中のもの）には投票できません。

### 10.7 投票者の表示

回答カードの右下に投票者の名前と 👍 が並び、2票以上の場合は票数も表示されます。0票の投票は 👍 なしで名前だけ表示されます。投票者名表示の設定によっては名前が表示されません。

回答の得票数（**👍n**）を押すと、その回答に付いた**自分の投票だけ**に絞り込めます（回答毎の自投票フィルター）。

## 11. 結果フェーズと順位の見方

### 11.1 順位

結果フェーズでは、各回答の上に「**n位**」が表示されます。順位は次のルールで決まります。

1. **補正得票数**（得票数に、回答者自身の投票状況に応じた補正を加えた値）の多い順
2. 同じ場合は、**回答者の投票数が多い**方が上位
3. それも同じ場合は、**回答が早い**方が上位

回答表示の設定（一斉・即時）や回答シャッフルは、結果フェーズの順位には影響しません。

### 11.2 Zスコアとマーク

各回答の補正得票数から、その回で平均からどれだけ離れているかを表す **Zスコア**（標準得点）が計算されます。順位の表示を押すと、Zスコアが小数点以下4桁で表示されます。もう一度押すと元に戻ります。

| Zスコア | 表示 |
|---|---|
| **2以上** | 順位の横に **🦄（ユニコーン）**。3以上で🦄🦄、以降1上がるごとに1つ増えます。 |
| **1以上** | 順位に**下線** |
| −1より大きく1未満 | 装飾なし |
| **−1以下** | 順位に**上線** |
| **−2以下** | **🍦（アイスクリーム）**。以降1下がるごとに1つ増えます。 |

### 11.3 ユニコーンの累計

獲得したユニコーンは部屋ごとに累計され、次の場所に表示されます。

- 部屋のメニューバーの自分の名前の横
- 「入室者を見る」画面の各入室者の横

ユニコーンの算定は、回答者の投票数で補正されています。

### 11.4 結果フェーズでできること

- 出題コメント・回答コメント・リアクション（[13章](#13-コメントとリアクション)）
- 並べ替えとフィルター（[14章](#14-並べ替えとフィルター)）
- 次の出題（[8章](#8-出題する)、[12章](#12-出題優先時間)）

## 12. 出題優先時間

結果フェーズが始まってから一定時間、**次の出題をできる人を限定**する仕組みです。

### 12.1 設定値

| 設定値 | 優先時間中に出題できる人 |
|---|---|
| **無し** | 出題者なら誰でもすぐに出題できます。 |
| **有り（部屋作成者）** | 部屋作成者だけ |
| **有り（首位回答者）** | その回で**投票した回答者の中で最も順位が高かった回答**の回答者だけ。該当する回答がない場合は誰でも出題できます。 |

### 12.2 画面での見え方

- 結果フェーズの「出題する」ボタンの横に、優先時間の残りを示すタイマーが表示されます。自分が出題できないあいだは、タイマーが赤く表示され、ボタンは押せません。
- 「有り（首位回答者）」の場合、優先される回答の**回答者名が明滅**します。誰に出題権があるかがひと目で分かります。
- 優先時間が過ぎると、出題者なら誰でも出題できるようになります。

### 12.3 途中で締め切る

部屋作成者には「**出題優先を締め切る**」ボタンが表示されます。押して確認画面で「締め切る」を押すと、残り時間にかかわらず優先時間が終わります。

## 13. コメントとリアクション

### 13.1 コメントの種類

| 種類 | 場所 | 投稿できる人 | 投稿できる時期 | 削除 |
|---|---|---|---|---|
| **部屋コメント** | 部屋の上部 | 部屋作成者 | いつでも | 部屋作成者が最新の1件から削除できます |
| **出題コメント** | 結果フェーズの画面上部 | 出題コメント制限による | 結果フェーズ | できません |
| **回答コメント** | 各回答カードの下部 | 回答コメント制限による | 結果フェーズ | できません |

### 13.2 コメントの投稿

1. 「**コメントする**」ボタンを押します。
2. 「コメント」欄に入力します。空欄のままでも投稿できます。
3. 「コメントする」を押します。

コメントは「投稿者名☝本文」の形で表示され、本文の URL は自動でリンクになります。自分のコメントの名前は色が変わります。

### 13.3 リアクション（クイックコメント）

「コメントする」ボタンの横にある**スマイル（😊）ボタン**を押すと絵文字の一覧が開き、選ぶとその絵文字がコメントとして投稿されます。出題にも回答にも使えます。

現在選べる絵文字は次の9種類です。絵文字の種類はときどき入れ替わります。

> 😂 🤣 🥰 🥹 😭 😳 🤔 😡 🫡

## 14. 並べ替えとフィルター

回答一覧の上には、下へスクロールしても表示され続けるツールバーがあります。

### 14.1 回答の並べ替え

ドロップダウンから表示順を選びます。

| 表示順 | 意味 | 使えるフェーズ |
|---|---|---|
| **設定順** | 部屋設定による既定の順（下の表） | すべて |
| **先着順** | 回答の古い順 | すべて |
| **後着順** | 回答の新しい順 | すべて |
| **上位順** | 得票の多い順 | すべて |
| **下位順** | 得票の少ない順 | すべて |
| **多コ順** | コメントの多い順 | 結果フェーズ・過去の結果 |
| **少コ順** | コメントの少ない順 | 結果フェーズ・過去の結果 |

「設定順」の中身:

| フェーズ | 並び方 |
|---|---|
| 回答・投票フェーズ（回答表示が一斉） | 古い順 |
| 回答・投票フェーズ（回答表示が即時） | 新しい順 |
| 投票フェーズ（回答シャッフル時間あり） | 対象の回答が入室者ごとにランダムに並びます |
| 結果フェーズ・過去の結果 | 順位の順 |

### 14.2 フィルター

フィルターは**プライマリーフィルター**と**セカンダリーフィルター**の2段構えです。ボタンのアイコンが塗りつぶし表示のときがオンです。

#### プライマリーフィルター（ツールバーのボタン）

| ボタン | 名前 | 表示される回答 | 使えるフェーズ |
|---|---|---|---|
| **✋** | 自回答フィルター | 自分の回答だけ（回答フェーズでは自分の回答数も表示） | すべて |
| **👍** | 自投票フィルター | 自分が投票した回答だけ（投票フェーズでは自分の投票数の合計も表示） | 投票・結果フェーズ、過去の結果 |
| **☝** | 自コメントフィルター | 自分がコメントした回答だけ（結果フェーズでは自分のコメント数も表示） | 結果フェーズ、過去の結果 |

プライマリーフィルターは同時に1つだけオンにできます。別のボタンを押すと切り替わります。

#### セカンダリーフィルター（回答の上の操作）

結果フェーズと過去の結果では、各回答の上に次の操作があります。

| 操作 | 名前 | 表示される回答 |
|---|---|---|
| **グループ名**を押す | グループフィルター | そのグループの回答だけ |
| **👁** を押す | 回答ピックアップ | その回答だけ |

セカンダリーフィルターは、プライマリーフィルターで絞り込んだ結果をさらに絞り込みます。同じ操作をもう一度押すと解除されます。プライマリーフィルターを切り替えると、セカンダリーフィルターは解除されます。

#### 回答ごとの自投票フィルター

回答カードの **👍n** を押すと、その回答に付いた投票のうち自分の投票だけが表示されます（[10.7](#107-投票者の表示)）。

## 15. グループ

入室者をチームやクラスのようにまとめる機能です。グループは作成した部屋の中だけで有効です。

### 15.1 グループを選択する

部屋画面の「**グループを選択する**」ボタンを押すと、グループの一覧が表示されます。

- 各グループには名前、説明、所属人数（🖖と人数）、所属している入室者の名前が表示されます。
- グループ名の横のラジオボタンを選ぶと、そのグループに移ります。
- 所属者の名前を押すとトークンに切り替わります。
- 自分が入っているグループは、メニューバーに「@グループ名」と表示されます。

グループがあるのにどのグループにも入っていない入室者（グループ作成後に入室した人、入っていたグループが削除された人など）には、グループを選択する画面が自動で表示されます。

### 15.2 グループを作成・削除する（部屋作成者）

- 「**グループを作成する**」: グループ名と説明を入力して作成します。グループ名は他と重複してもかまいませんし、空でもかまいません。
- 「**グループを削除する**」: 各グループの右下にあります。

#### グループの履歴

「グループを作成する」画面のグループ名の横にある「**履歴を見る**」を押すと、同じブラウザーで作ったグループの一覧が表示されます。

- 「履歴を読み込む」: その名前と説明を読み込みます。
- 「履歴を削除する」: 履歴から消します。
- 同じグループ名で作った場合は、最新の設定だけが残ります。

### 15.3 グループ名の表示

- 結果フェーズと過去の結果では、各回答の上に回答者のグループ名が表示されます。押すとグループフィルターになります。
- 部屋設定で投票グループ制限が「無し」の場合、部屋画面にグループごとの回答数は表示されません。

### 15.4 投票グループ制限

グループがある部屋で、投票フェーズに表示する回答を絞り込みます。

| 設定値 | 投票フェーズで表示される回答 |
|---|---|
| **無し** | すべての回答 |
| **有り（自グループに投票）** | 自分と同じグループの回答だけ |
| **有り（次グループに投票）** | 自分のグループの**直後に作られたグループ**の回答だけ。自分のグループが最後に作られたグループなら、**最初に作られたグループ**の回答が表示されます。 |

- グループを選んでいない場合は、グループを選んでいない人の回答だけが表示されます。
- 投票グループ制限を設定しても、グループを1つも作らなければ「無し」と同じ動作になります。
- この設定を使うと、投票時間制限の「回答毎×」には、表示される回答数が最も多いグループの回答数が使われます。
- 「次グループに投票」は、グループ同士で互いの回答を審査し合う形式に向いています。

## 16. 入室者を見る・入室者の管理

### 16.1 入室者一覧

部屋画面の「**入室者を見る**」を押すと、入室者の一覧が開きます。

各入室者のカードには次の情報が表示されます。

- 名前（自分は色が変わります）
- ソーシャルアカウントやリンクへのアイコン、プロフィール画像（押すと拡大）
- 🦄 の累計
- **トークン**（8文字の英数字。ディスクリミネーターとも呼びます）

表示のされ方:

- **退室した人**は薄く表示されます。退室した出題者・回答者・投票者も一覧に残ります。
- **受刑者**は取り消し線付きで表示されます。
- 一覧の末尾に🖖と入室者数が表示されます。

### 16.2 入室者の並べ替え

右上のドロップダウンで表示順を選べます。

| 表示順 | 意味 |
|---|---|
| 先入順 / 後入順 | 入室日時の古い順 / 新しい順 |
| 多🦄順 / 少🦄順 | ユニコーン獲得数の多い順 / 少ない順 |
| 昇名順 / 降名順 | 名前の Unicode 値の昇順 / 降順 |
| 昇Di順 / 降Di順 | ディスクリミネーター（トークン）の Unicode 値の昇順 / 降順 |
| 古サ順 / 新サ順 | サインイン日時の古い順 / 新しい順 |

### 16.3 部屋作成者の管理操作

部屋作成者には、各入室者のカードに次のボタンが表示されます。画面の幅が狭いときは「**⋯**」ボタンで開閉します。

| ボタン | 効果 |
|---|---|
| 出題者へ追加する / 出題者から削除する | 出題できる人を個別に指定します。 |
| 回答者へ追加する / 回答者から削除する | 回答できる人を個別に指定します。 |
| 投票者へ追加する / 投票者から削除する | 投票できる人を個別に指定します。 |
| 受刑者へ追加する / 受刑者から削除する | 受刑者にすると、その人は強制退室させられます。自分自身は受刑者にできません。 |

- 出題者・回答者・投票者を1人でも個別に指定すると、その項目は指定した人だけに限定されます（[6.5](#65-出題者回答者投票者制限の考え方)）。全員を削除すると初期値の設定に戻ります。
- 受刑者に追加すると、**同じ発信元から出題・回答・投票・コメントしている入室者**も受刑者に追加されます。
- 不正なアクセスで出題・回答・投票・コメントをしようとした入室者は、自動的に受刑者に追加されます。

## 17. 過去の結果とログ（CSV）

### 17.1 過去の結果

部屋のメニューバーの「**過去の結果**」タブで、以前の回の結果を閲覧できます。

- 上部のページ切り替えで回（第n回）を移動します。
- 表示できるのは**34.5日以内**の出題です。
- 結果フェーズと同じく、順位・🦄/🍦・Zスコア・コメントの表示、並べ替え（多コ順・少コ順を含む）、すべてのフィルターを使えます。
- コメントやリアクション、投票はできません（閲覧専用）。

### 17.2 ログ（CSV）

部屋のメニューバーの「**ログ（CSV）**」タブで、その部屋のログを CSV ファイルとしてダウンロードできます。

1. 表示された URL のリンクを押すとダウンロードが始まります。サーバーが処理している間はスピナーが表示されます。
2. 「**ディスクリミネーター付き**」スイッチをオンにすると、名前とディスクリミネーター（入室者ごとの8文字のトークン）を改行で区切って出力する CSV になります。同じ名前の人を区別したい集計に便利です。

- ダウンロードできるのは**34.5日以内**の出題です。
- ダウンロードするには、その部屋に入室している必要があります。
- 9番目のカラムにグループ名が出力されます。

> **ヒント**: 部屋の存続期間は最終更新から11.5日です。記録を残したい場合は早めに CSV を取っておきましょう。

## 18. 表示・操作のヒント

### 18.1 カラースキーム

- **部屋の既定**: 部屋作成時の「カラースキーム」で「ライト」「ダーク」を選べます。「無し」ならブラウザーや OS の設定に従います。
- **自分の画面だけ切り替える**: 部屋画面のメニューバーの配色ボタンから選びます。
  - ◐ **オート**: ブラウザーや OS の設定に従います。
  - ☀ **ライト**
  - 🌙 **ダーク**
- メニューバーでの選択は**保存されません**。部屋を開き直すと元に戻ります。

### 18.2 キーボードショートカット

| 場面 | キー | 動作 |
|---|---|---|
| 出題・回答の入力欄 | **Ctrl+Enter** / **Windows キー+Enter** / **Command キー+Enter** | 送信する |
| 投票画面 | **スペース** / **Delete** / **Enter** | 1票増やす / 1票減らす / 送信する |
| ダイアログ全般 | **Esc** | ダイアログを閉じる |

通常の Enter キーは改行になり、送信はされません。

### 18.3 長い文章の折りたたみ

10行または150文字を超える出題・回答は折りたたまれます。⊞ と残りの文字数が書かれたボタンで全文を表示し、⊟ で折りたたみます。

### 18.4 その他の小技

- **名前を押してトークン表示**: 出題者・回答者・投票者・コメント投稿者の名前や、グループの所属者名を押すとトークンに切り替わります。
- **画像の拡大**: 出題画像、回答描画、入室者一覧のプロフィール画像は押すと拡大表示されます。
- **実行中の表示**: ボタンを押して処理している間は、そのボタンの上にスピナーが重なって表示されます。
- **タイマー**: 円形タイマーは緑色で残り時間を示し、出題できないあいだの出題優先タイマーは赤色で表示されます。回答画面や投票画面の中にもタイマーが表示されます。

### 18.5 動作環境

- ECMAScript 2022 に対応した最近のブラウザーが必要です。
- Internet Explorer や古い Edge・Firefox・Safari・Chrome には対応していません。表示が崩れたり動かなかったりする場合は、ブラウザーを最新版に更新してください。
- Safari 26.4 / 26.5 でデータの取得がときどき遅れる問題に対処するため、Safari では一時的に通信方式を変えています。
- システムの大きな更新の後は、ブラウザーの再読み込み（リロード）をすると確実です。

## 20. よくある質問・トラブルシューティング

### サインイン・アカウント

**Q. サインアウトしたら前の名前・状態に戻れなくなりました。**
A. 新規サインインの状態は、サインアウトすると元に戻せません。次からは、サインアウトの前に「サインオーバー」で引き継ぎ用のリンクを作っておくか、ソーシャルサインインを使ってください。

**Q. スマートフォンとパソコンで同じ状態を使いたいです。**
A. 「サインオーバー」で表示される QR コードを、スマートフォンで1時間以内に読み取ってください（[3.5](#35-サインオーバー別のブラウザーへの引き継ぎ)）。

**Q. Twitter でサインインできません。**
A. Twitter でのサインインについては、画面遷移を変える一時的な措置が取られており、Twitter 側の事情で動作が変わることがあります。次の順に試してください。
1. 少し時間をおいて、もう一度試す。
2. 同じブラウザーで Twitter に正しいアカウントでログインしているか確認する。
3. Bluesky でのサインインや新規サインインを使う。

**Q. 自分の名前の後ろに見慣れない8文字が付いています。**
A. 名前に `#` を含めると、`#` 以降がハッシュ値に変換されます（[3.4](#34-名前にハッシュ値を付けるなりすまし対策)）。

### 部屋

**Q. 「部屋を作成する」ボタンが押せません。**
A. 新規サインインの場合、まだ出題していない部屋は1つまでしか持てません。作成済みの部屋で出題するか、その部屋を削除してください。ソーシャルサインインなら複数作れます。

**Q. 部屋が一覧から消えました。**
A. 部屋は最終更新から11.5日で存続期間が切れます。

**Q. 入室しようとするとパスワードを聞かれます。**
A. その部屋には入室制限が設定されています。部屋作成者からパスワードを教えてもらってください。

### 出題・回答・投票

**Q. 「出題する」ボタンがありません／押せません。**
A. 次の点を確認してください。
- 今が結果フェーズか（または部屋にまだ出題がないか）
- 出題者制限の対象に入っているか（部屋画面の設定表の「出題者制限」を確認）
- 出題優先時間中ではないか（ボタン横の赤いタイマーが出ていれば優先時間中です）

**Q. 「回答する」ボタンが押せません。**
A. 回答数制限の上限に達している可能性があります。回答者制限の対象かどうかも確認してください。

**Q. 「投票する」ボタンが「投票を見る」に変わりました。**
A. 投票数制限（出題毎）の上限に達しています。「投票を見る」から既存の投票を減らすか削除すると、別の回答に投票できるようになります。

**Q. 他の人の回答が見えません。**
A. 回答表示が「一斉」の部屋では、投票フェーズまで他の人の回答は表示されません。投票グループ制限がある部屋では、投票フェーズに一部のグループの回答しか表示されません。

**Q. 投票フェーズで回答の並び順が他の人と違います。**
A. 回答シャッフル時間が設定されている部屋では、対象の回答が入室者ごとにランダムな順で表示されます。

**Q. 回答が途中で切れています。**
A. 10行または150文字を超える部分は折りたたまれています。⊞ ボタンを押すと全文が表示されます。

### 表示

**Q. 画面が暗い／明るすぎます。**
A. 部屋のメニューバーの配色ボタンで「ライト」「ダーク」を選べます。この選択は保存されないので、開き直したら選び直してください。

**Q. 表示がおかしい、ボタンが反応しません。**
A. ブラウザーを再読み込みしてください。直らない場合は、ブラウザーを最新版に更新してください。

**Q. 質問や要望はどこに送ればいいですか。**

## 付録D 目的別の部屋設定例

あくまで一例です。参加人数や進め方に合わせて調整してください。

### D.1 気軽なリアルタイム大喜利

みんなの回答をすぐに見て、その場で盛り上がりたい場合。

| 項目 | 設定 |
|---|---|
| 回答表示 | 即時 |
| 投票表示 | 即時 |
| 回答者名表示 | 表示 |
| 投票者名表示 | 表示 |
| 投票数制限（出題毎） | 無し |
| 出題優先時間 | 無し |

### D.2 公平な審査を重視した大会

先入観を減らし、回答の中身だけで評価したい場合。

| 項目 | 設定 |
|---|---|
| 回答表示 | 一斉（投票フェーズまで非表示） |
| 回答時間制限 | 有り（例: 600秒） |
| 回答シャッフル時間 | 有り（空欄＝すべてシャッフル） |
| 回答数制限 | 有り（例: 3答） |
| 回答者名表示 | 一斉（結果フェーズまで非表示） |
| 投票表示 | 一斉（結果フェーズまで非表示） |
| 投票時間制限 | 有り（例: 120 + 3×） |
| 投票数制限（出題毎） | 有り（例: 5票） |
| 投票数制限（回答毎） | 有り（例: 1票） |
| 投票者名表示 | 一斉（結果フェーズまで非表示） |

### D.3 勝者が次のお題を出すリレー形式

| 項目 | 設定 |
|---|---|
| 出題優先時間 | 有り（首位回答者）（例: 180秒） |
| 回答表示 | 一斉 |
| 投票表示 | 一斉 |

首位回答者の名前が明滅するので、誰の番かすぐに分かります。

### D.4 主催者だけがお題を出す会

| 項目 | 設定 |
|---|---|
| 出題者制限（初期値） | 有り（その後「入室者を見る」で部屋作成者自身を出題者へ追加） |
| 出題コメント制限 | 有り（部屋作成者） |

主催者が毎回次のお題を出すなら、代わりに「出題優先時間: 有り（部屋作成者）」にする方法もあります。この場合、優先時間が過ぎれば他の人も出題できます。

### D.5 チーム対抗戦（相互審査）

| 項目 | 設定 |
|---|---|
| 投票グループ制限 | 有り（次グループに投票） |
| 回答表示 | 一斉 |
| 回答者名表示 | 一斉（結果フェーズまで非表示） |

部屋作成者がチーム数ぶんのグループを作り、各入室者にグループを選んでもらいます。各チームは別のチームの回答を審査します。結果フェーズではグループ名を押すと、チームごとの回答に絞り込めます。

### D.6 荒らし対策を強めた公開部屋

| 項目 | 設定 |
|---|---|
| 出題者・回答者・投票者制限（初期値） | 有り（ソーシャルサインイン） |
| 入室制限 | 必要に応じて有り（パスワード） |

問題のある入室者は、「入室者を見る」画面から受刑者へ追加できます。
