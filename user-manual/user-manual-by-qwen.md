## 1. bǃgǃrǃとは

bǃgǃrǃ（ビギリ）は、ブラウザーだけで大喜利を遊べる Web サービスです。サブタイトルは「**For Beautiful Oogiri Life**」です。

利用者は「**部屋**」と呼ばれる単位で集まり、各部屋で次のサイクルを繰り返し楽しみます。

1. **出題** — 出題者（または部屋作成者）がお題を投稿する
2. **回答** — 入室者がお題に対する回答を投稿する
3. **投票** — 面白いと思った回答に票を入れる
4. **結果** — 得票数と順位が発表され、コメントやリアクションで盛り上がる

bǃgǃrǃ の最大の特徴は、**ルールを部屋ごとに細かく設定できる**ことです。誰が出題・回答・投票できるか、記名か匿名か、回答や投票をリアルタイムに表示するか締め切りまで伏せるか（一斉表示）、制限時間や票数の上限、参加者をグループに分けるかどうか——といった項目を部屋作成時に選べます。少人数のゆるい大喜利から、グループ対抗の大会形式まで、同じサービス上で運用できます。

### 利用の前に知っておきたいこと

- ほとんどの操作には**サインイン**が必要です。
- ルールは部屋ごとに異なります。「ボタンが押せない」「回答が見えない」ときは、まず現在のフェーズ・制限時間・役割の指定・グループ設定を確認してください（第19章）。
- 部屋には**存続期間**があり、最終更新日時から **11.5日間**で終了します。
- **過去の結果**と**ログ（CSV）**は、**34.5日以内の出題**が対象です。記録を残したい場合は早めに保存してください。
- スマートフォンなど幅の狭い画面にも対応しています（必要に応じて操作ボタン群が開閉できます）。
- トップページにはクリエイティブ・コモンズ・ライセンスが掲示されています。

## 2. ゲームの流れとフェーズ

部屋は常に次のいずれかのフェーズにあり、順番に進みます。結果フェーズから次のお題が出題されると、再び回答フェーズに戻ります。

| フェーズ | 状態 | 主にできること |
|---|---|---|
| **出題待ち** | まだお題がない状態 | 出題する（出題者のみ） |
| **回答フェーズ** | お題が出ている | 回答する・回答を変更する・回答を削除する |
| **投票フェーズ** | 回答が締め切られた | 投票する・投票を変更する・投票を削除する |
| **結果フェーズ** | 投票が締め切られた | 順位を見る・コメントする・リアクションする・次の出題をする |

### フェーズが進む条件

- **制限時間による自動締め切り** — 部屋設定で「回答時間制限」「投票時間制限」が設定されている場合、時間切れで次のフェーズへ進みます。残り時間はタイマーとして表示され、ダイアログウィンドウ上の回答ボタン・投票ボタンにもタイマーが表示されます。
- **部屋作成者による手動締め切り** — 部屋作成者は回答・投票・出題優先時間を途中で締め切ることができます。
- フェーズの変わり目などで処理に時間がかかる場合は「集計中」「処理中」の表示が出ます。各種実行ボタンは**処理中にスピナーがボタンに重なって表示**されるため、連打せずに完了を待ってください。

### 回答・投票の表示タイミング

部屋設定の「回答表示」「投票表示」により、他の参加者の回答・投票が見えるタイミングが変わります。

- **即時** — 投稿・投票されるたびにリアルタイムで反映されます。回答数もリアルタイムで表示されます。
- **一斉** — 締め切り後にまとめて表示されます。投票表示が「一斉」の部屋では、**投票フェーズになってから**投票できます。

### 新規サインインした直後の制限

進行中の部屋に後から参加した場合、フェーズによってはすぐには参加できません。

- 回答フェーズ中に新たにサインインした利用者は**回答できません**。
- 投票フェーズ中に新たにサインインした利用者は**投票できません**。
- 結果フェーズ中に新たにサインインした利用者は**出題できません**。

## 3. サインイン・サインアウト・退室

### 3.1 サインインする

サインイン画面では、通常のサインインは「**新規サインイン**」ボタンを押して行います。名前欄の初期値は「お客さん」です。必要に応じて人の確認（reCAPTCHA など）が表示される場合があります。

ソーシャルサインインとして、次のアカウントが利用できます。

- **Twitter（X）アカウント**（Sign in with Twitter）— サインインした利用者は、入室者一覧の名前にリンクが設定されたり、プロフィール画像が表示されたりします。現在、Twitter でのサインインについては画面遷移を変更する措置が行われており、この措置は予告なく終了する場合があります。
- **Bluesky アカウント** — サインイン画面に「Blueskyでサインイン」ボタンがあります（試験稼動）。

サインイン後は、トップ画面や部屋画面のナビゲーションから各種操作が行えます。

### 3.2 名前とハッシュ値

サインイン時の名前は自由に設定できます。名前の末尾に `#` と任意の文字列を付けると、その部分が暗号学的ハッシュ関数値（8文字）に変換して表示されます。同じ名前の利用者と区別したい場合や、元の名前を伏せたい場合に便利です。

```
例:
びぎりちゃん        → びぎりちゃん
びぎりちゃん#abc    → びぎりちゃん#DnbJh2JQ
風祭ビギリマナ春子#abc → 風祭ビギリマナ春子#C2GkNEL6
```

### 3.3 名前を変更する

名前はサインアウトせずに変更できます。また、**部屋内でのみ**名前を変更することもできます。部屋内で名前を変更すると、その部屋でのみ変更後の名前が使われます。

現在の仕様では、トップ画面のメニューおよび部屋画面のメニューから「名前を変更する」メニューは廃止され、**名前自体がメニュー**になっています。名前を押すことで、名前の変更と、入室者一覧に表示するソーシャルリンクの設定が行えます。

### 3.4 ソーシャルリンクの設定

部屋画面のメニューで自分の名前を押すと、入室者一覧に表示する**ソーシャルリンクの URL** や表示の有無を設定できます。部屋一覧や部屋画面では、Twitter ポスト・検索リンクの横に同等の Bluesky リンクも表示されます。

なお、過去には「部屋内で名前を変更している場合」や「名前にハッシュ値を付加している場合」に入室者一覧でソーシャルリンクを表示しない機能がありましたが、これらは廃止されています。現在は表示設定に従って表示されます。

### 3.5 サインオーバー（サインイン状態の引き継ぎ）

**サインオーバー**を使うと、サインイン状態を別のブラウザー（別の端末）に引き継げます。

1. トップ画面または部屋画面のメニューから「サインオーバー」を選びます。
2. 表示された URL またはその QRコードを、引き継ぎ先のブラウザーで**1時間以内**に開きます。サインオーバー画面には URL をコピーするボタンがあります。
3. 引き継ぎ先のブラウザーでサインイン状態が有効になります。

### 3.6 退室とサインアウト

- 部屋から出る場合は**退室する画面**を利用します（退室した出題者・回答者・投票者も入室者一覧には含まれます）。
- サービスの利用を終える場合はサインアウトします。サインアウト時の最短時間制限は廃止されました。

## 4. トップ画面

トップ画面には、部屋の一覧と更新情報が表示されます。

### 4.1 部屋一覧

- 部屋ごとに**アイコン画像**と出題日時が表示されます。
- 表示順はドロップダウンリストから「**作成順**」・「**更新順**」（いずれも日時の降順）を選べます。
- 部屋一覧の先頭にある ✌ ボタンを押してオンにすると、**自分が入室している部屋のみ**が表示されます（自入室フィルター）。
- 部屋一覧の入室者名の中に、自分が分かる表示が含まれます。
- 部屋名をハッシュタグとして検索する Twitter リンクと、同等の Bluesky リンクが表示されます。
- Twitter の Sign in with Twitter でサインインしている場合、ナビゲーションメニューに Twitter リンクが表示されます。

### 4.2 更新情報

- トップ画面には**更新情報を見るボタン**があり、更新情報の履歴をダイアログウィンドウで確認できます。
- 更新情報の内容は「**更新情報**」と「**使用方法**」に分けて表示されます。
- 更新情報では、統計的な記述に**Zスコア**（旧表記「標準化変量」）が用いられています。
- AI で試験的に生成された「bǃgǃrǃ ユーザーマニュアル」へのリンクと、GitHub ディスカッションへのリンクが掲示されています。

## 5. 部屋を作成する

サインイン後、トップ画面から部屋を作成できます。

### 5.1 部屋作成画面の履歴機能

部屋名の横の**履歴ボタン**を押すと、同じブラウザーで作成した部屋の一覧が表示されます。

- 「読み込む」ボタンで過去の設定を読み込めます（作成日時も確認できます）。
- 「削除する」ボタンでその設定を削除できます。
- 同一の部屋名で部屋を作成した場合、履歴には最新の設定のみが残ります。
- アイコン画像についても、直近の設定値が初期値になります（アイコン画像には容量制限があります）。

### 5.2 未出題の部屋の作成制限

未出題の部屋の作成は**1つまで**です。ただし、Sign in with Twitter でサインインしている場合は、未出題のまま複数の部屋を作成できます。

部屋設定の詳細は次章を参照してください。

## 6. 部屋設定リファレンス

部屋作成時に設定できる主な項目です。項目名・設定値はバージョンによって整理されており、以下は現行仕様のまとめです。

| 項目 | 設定値 | 説明 |
|---|---|---|
| 部屋名 | 任意の文字列 | 部屋の一覧やハッシュタグ検索に使われます |
| 説明 | 任意の文字列 | 説明内に書かれた URL は自動でリンクになります |
| アイコン画像 | 画像 | 部屋の右下に常に表示されます。容量制限あり |
| カラースキーム | ライト／ダーク | 部屋の既定のカラースキーム（第18章） |
| 出題者制限（初期値） | 無し／有り／有り（Sign in with Twitter） | 出題できる人を制限します |
| 回答者制限（初期値） | 無し／有り／有り（Sign in with Twitter） | 回答できる人を制限します |
| 投票者制限（初期値） | 無し／有り／有り（Sign in with Twitter） | 投票できる人を制限します |
| 出題優先時間 | 無し／有り（投票者内1位）／有り（部屋作成者） | 出題できる順番・人を制御します（下記参照） |
| 回答時間制限 | 時間 | 回答フェーズの制限時間 |
| 回答数制限 | 数 | お題1つ当たりの回答数の上限 |
| 回答表示 | 即時／一斉 | 他の人の回答が見えるタイミング |
| 回答者匿名 | — | 回答者名を伏せます（自回答の回答者名は常に表示されます） |
| 回答シャッフル時間 | 無し／有り（秒） | シャッフル時間内の回答は投票フェーズで入室者毎にランダムな順番で表示されます。秒を空にすると全ての回答がシャッフルの対象になります。結果フェーズでの順番はこの設定と無関係に計算されます |
| 投票時間制限 | 時間 | 回答数に比例して投票時間が追加される設定ができます |
| 投票数制限（出題毎） | 無し／有り／有り（超過可） | お題1つ当たりで1人が使える票数の上限。「有り（超過可）」では制限に達した後も投票画面での投票数は超過できます（第10章） |
| 投票数制限（回答毎） | 数 | 回答1つ当たりで1人が使える票数の上限 |
| 投票表示 | 即時／一斉 | 他の人の投票が見えるタイミング。「一斉」では投票フェーズになってから投票します |
| 投票者匿名 | 常に非表示／締切後表示 | 投票者名を伏せます（自投票の投票者名は常に表示されます） |
| 出題コメント制限 | 制限無し／部屋作成者のみ | 出題コメントの投稿を制限します |
| 回答コメント制限 | 制限無し／部屋作成者のみ／有り（自回答） | 回答コメントの投稿を制限します。「有り（自回答）」では自分の回答にのみコメントできます |
| 出題画像制限 | — | 出題での画像の使用を禁止できます |
| 投票グループ | 無し／グループ内に投票／有り（次グループに投票） | 投票フェーズで表示される回答の範囲をグループで制御します（第13章） |

### 役割の指定について

部屋作成画面で出題者・回答者・投票者の制限を設定しても、**入室者一覧画面**で入室者ごとの設定を行っている場合は、その項目について部屋作成画面の設定は無視されます。入室者ごとの設定方法は第15章を参照してください。

### 出題優先時間の設定値

- **有り（投票者内1位）** — 前回の投票で1位だった入室者に、次の出題の優先権が与えられます（投票していない回答者は出題優先になりません）。優先時間中は、優先される出題者の「出題する」ボタンが**明滅**します。部屋作成者は出題優先を途中で締め切ることができます。
- **有り（部屋作成者）** — 部屋作成者のみが出題できます。
- 出題優先時間に該当しない時間帯は、通常どおり出題できます。

### 投票数制限（出題毎）の「有り（超過可）」

「有り（超過可）」を設定すると、投票数制限に達した場合に「投票する」ボタンは「投票一覧」ボタンに変わりますが、投票画面での投票数は同制限を超過できます。0票を投票した後に投票する場合や、超過可の部屋で投票する場合は、投票を見る画面で末尾にスクロールします。

### 投票時間制限の回答数について

投票グループを設定した場合は、投票時間制限の「回答毎×」には、全体の回答数ではなく、**表示された回答数が最も多いグループの回答数**が採用されます。

## 7. 部屋画面の構成

部屋画面は、メニューバーとメインの表示領域から構成されます。

### 7.1 メニューバー

- メニューバーには**タブ**があり、タブによって表示内容が切り替わります。表示を切り替えた際には、非共通部分まで自動的にスクロールします。
- メニューバーには、その部屋で獲得した**ユニコーン🦄の累計**が表示されます（第11章）。
- 自分の**名前**が表示されます。名前を押すと、名前の変更やソーシャルリンクの設定が行えます（第3章）。
- **カラースキームボタン**があり、「オート」・「ライト」・「ダーク」から選べます。オートではブラウザーや OS の設定に従います。なお、ここで選んだ内容は保存されません（第18章）。
- メニューからはサインオーバーや退室する画面なども利用できます。
- 部屋名には、部屋名をハッシュタグとしてツイートできる Twitter リンクが表示されます。ツイート本文には部屋名と説明の1行目が設定されます。また検索リンクの横に同等の Bluesky リンクが表示されます。

### 7.2 部屋コメント

部屋作成者は、部屋トップページの上部に**部屋コメント**を表示できます。部屋コメントは部屋作成者がいつでも投稿・表示でき、削除する場合は**最新の1件**が削除されます（全て削除されるわけではありません）。

### 7.3 アイコン画像

部屋作成時に設定したアイコン画像が、部屋の右下に常に表示されます。

### 7.4 出題と回答の表示に関する補助

- 出題・回答が長い場合、150文字を越えた位置や10行を越えた位置に「残り」を表すボタン（…）が表示され、押すと残りの部分が表示されます（第8章・第9章）。
- 出題画像の背景色は白（カラースキームがライトの場合の背景色と同一）です。

## 8. 出題する

### 8.1 出題の流れ

1. 部屋画面で「**出題する**」ボタンを押します（出題者が制限されている部屋では、出題者のみ押せます）。
2. お題の本文を入力します。入力文字数の上限は **1500文字**です。
3. 必要に応じて**出題画像**を添付します（部屋設定で禁止されている場合は添付できません）。画像お題の本文の既定値は画像のファイル名です。
4. 必要に応じて**出典**を入力します。出題に著作物を用いる場合は、適切な出典を入力してください。
5. **Ctrl キー＋改行キー**、または**メタキー（Windowsキー・Commandキー）＋改行キー**で送信できます（送信ボタンでも送信できます）。

150文字を越える出題は、越えた位置に残りを表すボタン（…）が表示され、押すと残りの部分が表示されます。出題優先時間中は、優先される出題者の「出題する」ボタンが明滅します。

### 8.2 出題コメント

結果フェーズでは、お題に対して**出題コメント**を投稿・表示できます。部屋作成者でなくても投稿できますが、削除はできません。投稿は部屋設定の「出題コメント制限」で制限できます。出題コメントにはクイックコメント（リアクション）も使えます（第12章）。

## 9. 回答する

### 9.1 回答の流れ

1. 回答フェーズ中に「**回答する**」ボタンを押します（回答者が制限されている部屋では、回答者のみ）。
2. 回答を入力します。入力文字数の上限は **1500文字**です。複数行の入力フィールドは、行数に従ってフィールドが伸張します。
3. **Ctrl キー＋改行キー**、または**メタキー（Windowsキー・Commandキー）＋改行キー**で送信できます。

150文字を越える回答は、越えた位置に残りを表すボタン（…）が表示され、押すと残りの部分が表示されます。10行を越える場合も同様にボタンが表示されます。

### 9.2 回答の変更・削除

- **回答を変更する**ボタンで、投稿済みの回答を修正できます。変更すると回答時刻も更新されます。
- 回答を削除できます。直前に削除された回答がある場合は、その内容が既定として回答欄に設定されます。
- 部屋設定の「回答表示」が一斉の部屋でも、自分の回答の投稿・削除は通常どおり行えます（処理は軽量化されています）。

### 9.3 回答描画（手描きの線画）

回答には**手描きの線画**を追加して表示できます（回答描画機能）。この機能は部屋設定により制限されている場合があります。

### 9.4 回答シャッフル

部屋設定の「回答シャッフル時間」が設定されている部屋では、シャッフル時間内に投稿された回答は、投票フェーズで**入室者毎にランダムな順番**で表示されます。結果フェーズでの順番はこの設定とは関係なく、従来どおりの方法で計算されます。秒数が空欄の場合は全ての回答がシャッフルの対象になります。

## 10. 投票する

### 10.1 投票の流れ

1. 投票フェーズ中に「**投票する**」ボタンを押します。
2. 投票画面では**投票数ボタンに初期フォーカス**が設定されています。投票数ボタンにフォーカスがある場合、次のキー操作が使えます。
   - **スペースキー** — 増票
   - **デリートキー** — 減票
   - **改行キー** — 入力内容を送信
3. 投票数の初期値は、部屋の設定等に応じて一部調整されています。

投票表示が「一斉」の部屋では、投票フェーズになってから投票できます。

### 10.2 投票の変更・削除・0票

- 「**投票を変更する**」ボタンにより、投票を一旦削除しなくても投票数を減らせます。
- 投票は削除できます。投票数を制限まで使い切った場合に備え、それまでの投票を削除しやすくするための「**投票一覧**」ボタンがあります。自投票一覧には投票数の合計が表示されます。
- **0票の投票**ができます。投票画面では「投票する」ボタンの横にある「👍0」ボタンを押すことで、0票を素早く投票できます（0票クイック投票）。

### 10.3 投票を見る

- 投票フェーズでは、回答一覧の上部にも「**投票を見る**」ボタンが表示されます（自投票フィルターと同等の機能です）。
- 投票を見る画面では、投票数の合計の横に**投票数制限（出題毎）**が表示されます。
- 部屋設定で投票数制限（出題毎）に「有り（超過可）」を設定した投票の場合、投票を見る画面で末尾にスクロールします。0票を投票した後の投票の場合も末尾にスクロールします。
- 回答毎の投票の表示順は、**投票数降順**です（投票数が同じ投票は投票順に表示されます）。

## 11. 結果と評価（順位・Zスコア・ユニコーン）

### 11.1 順位の決定

得票数が多い回答が上位になります。**得票数が同じ回答は、回答者の投票数が多い方を上位**とします。回答者の投票数も同じ場合は、回答の早い方を上位とします。

### 11.2 Zスコアによる評価マーク

回答の得票数（補正得票数）の **Zスコア** に応じて、順位に次のマークが表示されます。

| 条件 | 表示 |
|---|---|
| Zスコアが **1以上** | 順位に**下線** |
| Zスコアが **2以上** | 順位とともに**ユニコーン🦄**（さらに1上がるごとに1つ増える） |
| Zスコアが **-1以下** | 順位に**上線** |
| Zスコアが **-2以下** | **アイスクリーム🍦**（さらに1下がるごとに1つ増える） |

### 11.3 ユニコーン🦄

ユニコーンは、その部屋での活躍を示す指標です。算定には**回答者の投票数による補正**が用いられます。次の場所で確認できます。

- 部屋画面のメニューバー（その部屋で獲得したユニコーンの累計）
- 入室者一覧（入室者毎の累計）

入室者一覧の表示順として「多🦄順」・「少🦄順」が選べます（第15章）。

## 13. グループ

### 13.1 グループとは

グループは、部屋内の入室者をまとめる機能です。部屋にある「グループを見る」ボタンから確認でき、**部屋作成者**がグループの作成や削除を行えます。

- グループの名前は重複でき、空文字列も許されます。
- グループには**説明欄**があります。
- グループは作成された部屋内でのみ有効です。
- グループが追加されると、グループに入っていない入室者には**グループを選ぶ画面**が表示されます。グループが追加された後に入室した入室者には、最初にグループを選ぶ画面が表示されます。選んだグループが削除された入室者にも、再びグループを選ぶ画面が表示されます。

### 13.2 グループの表示

- ナビゲーションバーでは、自分の名前の前に自分が入っているグループ名が表示されます。
- メイン画面および過去の結果画面では、回答者名の前に回答者のグループ名が表示されます。
- 入室者一覧では、入室者名の前に入室者のグループ名が表示されます。
- ログ（CSV）では、回答者名カラムにグループ名と改行が追加されます（9番目のカラムにもグループ名が出力されます）。

### 13.3 グループ作成画面の履歴機能

グループ名の横の**履歴ボタン**を押すと、同じブラウザーで作成したグループの一覧が表示されます。「読み込む」ボタンで設定を読み込み、「削除する」ボタンで設定を削除できます。同一のグループ名で作成した場合、履歴には最新の設定のみが残ります。

### 13.4 グループ分離

部屋作成者がグループを選ぶ画面からグループを追加すると、**グループ分離が常に有効**になります。グループ分離が有効な部屋では、回答・投票フェーズにおいて**自分が入っているグループ以外の回答者の回答は表示されません**（自分のグループはグループを選ぶ画面からいつでも変えられます）。グループが存在しない場合は、グループ分離がない場合と同じ動作になります。

### 13.5 投票グループ

部屋設定の「投票グループ」で、投票フェーズに表示される回答の範囲を制御できます。

- **グループ内に投票** — 投票フェーズで、自分と同じグループの回答のみが表示されます。
- **有り（次グループに投票）** — 投票フェーズで、自分のグループの**直後に作成されたグループ**の回答のみが表示されます。自分のグループが最後の場合は、最初に作成されたグループの回答のみが表示されます。グループを選んでいない場合は、グループを選んでいない回答のみが表示されます。
- 投票グループを設定しても、グループを作成しなければ設定がない場合と同じ動作になります。

### 13.6 グループフィルター

結果フェーズおよび過去の結果画面で、**グループ名を押す**とグループフィルターが使えます。そのグループの回答に絞って表示されます（第14章）。

## 14. フィルターと表示順

### 14.1 プライマリーフィルターとセカンダリーフィルター

フィルターは2つのグループに分かれています。

- **プライマリーフィルター** — 自回答フィルター ✋・自投票フィルター 👍・自コメントフィルター ☝
- **セカンダリーフィルター** — グループフィルター・回答ピックアップ 👁

フィルターボタンおよび URL をコピーするボタンは、オン・オフのデザインが交換されています（オンとオフが見分けやすい表示になっています）。フィルターボタンは、下方にスクロールしても表示され続けます。

### 14.2 自回答・自投票・自コメントフィルター

- 結果フェーズおよび過去の結果画面で、回答一覧の先頭の ✋ を押すと**自分の回答のみ**、👍 を押すと**自分が投票した回答のみ**、☝ を押すと**自分がコメントした回答のみ**が表示されます。
- 回答フェーズでは自回答フィルターが使え、自回答数が併記されます。投票フェーズでは自投票フィルターが使え、自投票数が併記されます。
- **回答毎の自投票フィルター** — 回答の得票数（👍n）を押してオンにすると、その回答について自分の投票のみが表示されます。

### 14.3 回答ピックアップ

結果フェーズおよび過去の結果画面で、回答の 👁 を押すとその回答のみの表示になり、もう一度押すと元の表示に戻ります。自回答・自投票・自コメントフィルターとの**併用**もできます。

### 14.4 自入室フィルター

トップ画面の部屋一覧で、先頭の ✌ ボタンを押してオンにすると、自分が入室している部屋のみが表示されます。

### 14.5 回答の表示順

回答一覧の表示順は、フィルター横のドロップダウンリストから選べます。

| 表示順 | 意味 | 使える場所 |
|---|---|---|
| 設定順 | 部屋設定による既定の表示順 | 全てのフェーズ |
| 先着順／後着順 | 回答時刻の順 | 全てのフェーズ |
| 上位順／下位順 | 得票数の順 | 全てのフェーズ |
| コ多順／コ少順 | コメント数の順 | 結果フェーズ・過去の結果画面 |

## 15. 入室者を見る・管理する

### 15.1 入室者一覧の見方

部屋の「入室者を見る」画面には、次の情報が表示されます。

- **入室者数**
- 入室者名（先頭にグループ名、必要な場合はソーシャルリンク）
- 入室者毎の**トークン**（8文字の英数字。出題者・回答者・投票者の名前をクリックすることでも表示できます）
- その部屋で獲得した**ユニコーンの累計**
- 受刑者は**取り消し線**つきで表示されます（退室した出題者・回答者・投票者も一覧に含まれます）

表示順はドロップダウンリストから選べます。

| 表示順 | 意味 |
|---|---|
| 先入順／後入順 | 入室日時の順 |
| 古サ順／新サ順 | サインイン日時の古い順・新しい順 |
| 多🦄順／少🦄順 | ユニコーン獲得数の順 |
| 昇名順／降名順 | 名前の Unicode 値の順 |
| 昇Di順／降Di順 | ディスクリミネーターの Unicode 値の順 |

Twitter でサインインしている利用者は、プロフィール画像が表示されます。プロフィール画像を読み込めない場合は、既定の画像が表示されます。幅の狭いブラウザーでは、部屋作成者は操作ボタン群を開閉できます。

### 15.2 出題者・回答者・投票者の指定

部屋作成者は、入室者一覧から入室者を**出題者・回答者・投票者へ追加・削除**できます。入室者一覧で設定を行った場合、部屋作成画面での同項目の設定は無視されます。

### 15.3 受刑者（強制退室）

- 部屋作成者は、入室者一覧から入室者を**受刑者に追加・削除**できます。受刑者に追加された入室者は強制退室となります。
- 不正なアクセスによって出題・回答・投票・コメントを行おうとした入室者は、**自動的に受刑者に追加**されます。この場合、同一の発信元から出題・回答・投票・コメントする入室者も追加されます。
- 部屋設定の出題者優先・回答数制限・投票数制限に従っていないアクセスはブロックされます。

## 16. 過去の結果とログ（CSV）

### 16.1 過去の結果

部屋の結果は「過去の結果」画面で参照できます。対象は **34.5日以内の出題**です。過去の結果画面でも、フィルター（自回答・自投票・自コメント・グループフィルター・回答ピックアップ）や表示順の変更が使えます。

### 16.2 ログ（CSV）

- ログ（CSV）画面から、URL リンクで CSV ファイルをダウンロードできます。ダウンロードの際は**入室している必要があります**。
- URL を選択するまでダウンロードは始まりません。ダウンロード時にはサーバーが処理中であることが表示されます。
- CSV の名前カラムには、名前に改行とディスクリミネーター（入室者毎に割り当てられた8文字の文字列）が付加されます（名前にハッシュ値を付加している場合は、ハッシュ値の後にディスクリミネーターが付加されます）。
- 9番目のカラムにはグループ名が出力されます。

記録を長く残したい場合は、部屋の存続期間（11.5日）やログの対象期間（34.5日）に注意し、早めにダウンロードしてください。

## 18. 表示設定と動作環境

### 18.1 カラースキーム（ライト／ダーク）

- 部屋画面のメニューバーのカラースキームボタンで、「**オート**」・「**ライト**」・「**ダーク**」を選べます。オートではブラウザーや OS の設定に従います。選択は保存されません。

- 対象ブラウザーの言語仕様は **ECMAScript 2022** です。

- 絵文字のフォントは Noto Color Emoji に統一されています。日本語フォントや各種フォントも継続的に調整されています。

### 18.3 その他

- モバイルブラウザーでも利用できます。
- 更新後は、必要に応じてブラウザーのリロードを行ってください（大きな内部変更の際には更新情報でリロードが案内されます）。

## 19. トラブルシューティング（FAQ）

**Q. 「出題する」ボタンが押せません。**
A. 次の点を確認してください。出題フェーズではない（まだ回答・投票フェーズである）、出題者制限で自分が指定されていない、出題優先時間中である（優先される出題者のボタンが明滅します。「有り（部屋作成者）」の部屋では部屋作成者のみ出題できます）、結果フェーズ中に新たにサインインしたばかりである、のいずれかの可能性があります。

**Q. 回答・投票ができません。**
A. 回答者・投票者の制限で指定されていない、回答数・投票数の制限に達している、フェーズ中に新たにサインインしたばかりである、グループ分離や投票グループの設定で対象外のグループにいる、のいずれかの可能性があります。部屋設定と自分のグループを確認してください。

**Q. 他の人の回答が見えません。**
A. 部屋設定の「回答表示」が**一斉**の部屋では、回答は締め切り後にまとめて表示されます。また、グループ分離が有効な部屋では、自分と違うグループの回答は表示されません。投票グループが設定されている部屋では、投票フェーズで表示される回答の範囲が限定されます。

**Q. 画面が更新されない・データ取得が遅いです。**
A. ブラウザーのリロードをお試しください。Safari 26.4/26.5 ではデータ取得遅延への対処として、一時的に通信機能が変更されています。

**Q. プロフィール画像が表示されません。**
A. プロフィール画像を読み込めない場合は、既定の画像が表示されます。

**Q. 部屋が消えました。**
A. 部屋は最終更新日時から **11.5日間**で存続期間が終了します。過去の結果とログ（CSV）は **34.5日以内の出題**が対象です。必要な記録は早めに保存してください。

**Q. 別の端末で続きを遊びたいです。**
A. サインオーバーを使ってサインイン状態を引き継げます（第3.5節）。URL または QRコードを引き継ぎ先のブラウザーで**1時間以内**に開いてください。

**Q. 入力文字数が超過しているとエラーが出ます。**
A. 出題・回答の入力上限は **1500文字**です。超過時にはエラーメッセージが表示されます。

**Q. 更新情報の統計的な記述（Zスコア）とは何ですか？**
A. 更新情報の内容を統計的に表すための指標です。旧表記の「標準化変量」から「Zスコア」に表記が変更されました。
